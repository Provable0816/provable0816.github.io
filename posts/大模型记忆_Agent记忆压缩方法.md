## 0. 执行摘要

如果把 221 篇论文压成一句话：**记忆压缩不是一个"删减"问题，而是一个"在有限预算下分配保真度"的问题。**

本次调研覆盖 2024–2026 年 17 个会议场次的主会（ICLR/NeurIPS/ICML/ACL/EMNLP/NAACL/AAAI/IJCAI/CVPR/ICCV/COLING 等）上与"大模型 / Agent 记忆压缩"直接相关的论文，共精读 221 篇，其中**主会 207 篇**、按主题相关度额外保留 **14 篇 Findings/Demo**（均在索引与综述中显式标注为非主会）。按方向簇分布为：**KV 缓存压缩 93 篇**（42%）、**Agent 记忆 43 篇**、**上下文/提示压缩 29 篇**、**架构级记忆 24 篇**、**多模态记忆 23 篇**、**评测 6 篇**、**理论 3 篇**。

五条最重要的结论：

1. **压缩的收益来自数据冗余，不来自算法聪明。** 同一压缩率在数学推理上可能超过全缓存（P003、P139），在精确定位任务上可能直接归零（P003 的 SCBench Retr.KV 从 66.00 掉到 0.00）。任何"压缩率 X 保精度 Y%"的说法都必须绑定任务族，否则不可迁移。
2. **"重要性"是查询条件化且随时间演化的量**，因此一次性、静态、query-agnostic 的压缩存在结构性风险（P178 的注意力时变证据、P214 的页重要性漂移、P180 的层×步稀疏度热图、P177 的 prompt 扰动敏感性）。这直接催生了一批"可逆压缩"设计：合并账本（P178）、可召回淘汰（P214）、可恢复通道剪枝（P183）。
3. **主流方法的损失主要来自代理指标错位**：用注意力分数近似"重要性"，而注意力既不等于输出的因果贡献（P221、P199），也不等于长期价值（P003、P170）。把优化目标从"注意力近似"改成"输出重构 / 任务损失"，是本方向近年最有效的单一改进。
4. **压缩有六个正交的轴**：token 轴、位宽轴、特征维轴、层/头轴、时间轴、系统轴（复用/调度）。它们大多可叠加，但**预算在哪一轴分配最划算**几乎无人系统研究（P199、P183 各自指出这一空白）。
5. **系统级收益常常大于单点压缩收益**：跨模型共享 KV（P204 吞吐最高 3.5×）、工作流感知前缀缓存（P219）、缓存淘汰与路由联合优化（P207 命中率最高 6.92×）、子图级 KV 复用（P186 TTFT 降低 6.68×），其量级普遍超过把压缩率从 50% 提到 60% 所带来的收益。压缩研究必须放进 serving 语境才谈得上"有用"。

## 2. 第一性原理：记忆压缩到底在压缩什么

### 2.1 形式化

把任何"记忆"抽象为一组表示 $M=\{m_1,\dots,m_N\}$（可以是 KV 对、token、句子、事件、笔记、子图），下游算子 $f$（注意力、检索、生成、决策）在其上产生输出。记忆压缩是选择一个可用表示 $\hat M$ 与预算 $B$ 下的映射 $\pi$：

$$\min_{\pi}\ \underbrace{\mathbb E_{q\sim Q}\big[\,\mathcal L\big(f_q(\pi(M)),\ f_q(M)\big)\big]}_{\text{任务损失}}\quad \text{s.t.}\quad \mathrm{cost}(\pi(M))\le B$$

这个式子把本方向的全部争议暴露为四个问题：

1. **$Q$ 是什么？**（未来查询分布）——它决定"什么值得留"。P170 明确设定更新阶段看不到 $Q_{test}$，只能靠 $Q_{train}$ 泛化；这一假设是所有 query-agnostic 压缩的共同软肋。
2. **$\mathcal L$ 用什么代理？** 绝大多数方法把 $\mathcal L$ 替换为注意力分数（H2O 一脉），而 P221 用 CUR leverage score 证明**注意力近似不保证输出近似**，P199 用蒸馏替代 PCA 重构，P003 用任务信号替代注意力统计 —— 三篇独立工作指向同一结论：**代理指标与目标指标的错位，是压缩损失的主要来源**。
3. **$\mathrm{cost}$ 怎么算？** token 数、字节数、访存量、延迟、在线成本与离线成本并不等价。P210 不得不同时报告"总成本"与"纯在线成本"两本账；P206 在 GPU 与 CPU 上的加速比来源不同；P183 指出非结构化稀疏难以转化为真实加速；P220 强调边缘算力下压缩自身的计算代价也要计入预算。
4. **$\pi$ 可逆吗？** 丢掉的 $m_i$ 能否恢复，决定了误差是"有界"还是"永久"。P178（合并账本）、P214（可召回）、P183（可恢复通道）分别给出了三种可逆性实现，而它们是本方向 2025 年后最明显的新增设计维度。

### 2.2 压缩的三种基本操作

所有方法最终归结为三种原子操作，其失效模式完全不同：

| 操作 | 机制 | 误差形态 | 脆弱任务 |
| --- | --- | --- | --- |
| **降分辨率**（量化 / 低秩投影 / 合并） | 每个单位都保留，但保真度下降 | 弥散、小幅度 | 高精度数值读出、细粒度比较 |
| **减少单位**（淘汰 / 剪枝 / 摘要） | 少数单位完全消失 | 局部、大幅度 | 精确检索、标识符匹配、多跳桥接 |
| **外部化**（外置库 / 分层存储 / 复用） | 信息不丢，但访问代价上升 | 延迟与带宽 | 高并发、低延迟服务 |

这一区分解释了本领域大量看似矛盾的实验结论：P003 在数学任务上超过全缓存（降分辨率带来正则效应）、P174 的 1-bit 量化在长上下文通用任务上"不损精度"（弥散误差被平均吸收），但它们在精确定位任务上都更脆弱 —— 判据不是"压缩率"，而是**误差形态与任务敏感度是否匹配**。

## 3. 技术地图：七大族与 221 篇的定位

### 族 I｜KV 缓存压缩（93 篇，占 42%）——六轴分解

KV 张量形如（层数, 头数, 序列长度, 特征维），压缩即沿这些轴做取舍。

**轴 1：token 轴（减少单位）** —— 最拥挤的赛道。
- 淘汰类：H2O 谱系在本次语料中表现为 Ada-KV（P037）、CAKE（P083）、SnapKV 衍生（P039 ChunkKV、P042 KeyDiff）、LookaheadKV（P010）、DefensiveKV（P004）。
- 学习/可训练打分：**P177 Judge Q**（学 soft token 探针替代 prefill 末端窗口）、**P003 TRIM-KV**（retention gate + 容量损失）、**P221 CurDKV**（value 侧的 CUR leverage score）。
- 检索式（非淘汰）：FreeKV（P005）、LouisKV（P011）、RetrievalAttention（P051）、Spotlight Attention（P053）。
- 合并类：**P178 KeepKV**（Electoral Votes 记录合并历史 + 零扰动合并，给出单步无损与多步误差界）。
- 可召回：**P214 ArkVale**（页粒度淘汰 + 外部存储 + 按需召回）。
- 推理模型专用：R-KV（P050）、DesireKV（P151）、ThinKV（P016）、Lethe（P180）。

**轴 2：位宽轴（降分辨率）** —— 已从 4-bit 推进到 1-bit 区间。
- 低比特量化：KVQuant（P102）、ZipCache（P107）、KVTuner（P070）、RotateKV（P159）、NSNQuant（P048）、Channel-Aware MPQ（P034）、KVmix（P179，梯度式层间位宽分配）。
- 极限比特：**P101**（coupled quantization，1 bit/channel）、**P174 QJL**（JL 变换 + 符号位，无 per-block 常数开销）、**P171 CSR**（共享字典的稀疏表示，声称 1 bit 可用）。

**轴 3：特征维（换基）** —— 长期被忽视，2025 年后才被系统研究。
- **P199 MatryoshkaKV**（可训练正交投影 + Matryoshka 嵌套，一次训练覆盖多档压缩率）、Palu（P089 低秩投影）、ComVQ（P067 可交换向量量化）、P183 SPARK（通道级非结构化剪枝 + 打分时恢复）、P006 FreqKV（频域）、P009 KV Cache Transform Coding。

**轴 4：层 / 头轴（预算分配）** —— 承认"层与头不等价"。
- DuoAttention（P084 检索头 vs 流式头）、RazorAttention（P090）、Not All Heads Matter（P087）、SqueezeAttention（P091 二维最优预算）、PyramidKV 一脉、KVmix（P179）、Lethe（P180 层×步二维预算）、HACK（P190 VAR 的上下文头 vs 结构头）、AMS-KV（P189 按尺度）。

**轴 5：时间轴（何时压缩、是否重排）**
- **P180 Lethe** 把预算建成 (layer, step) 的函数、多轮重排；P038 AttentionPredictor（时间模式）；P041 Inference-Time Hyper-Scaling（压缩换更多采样）；**P178 / P214** 承认注意力漂移并提供补偿。

**轴 6：范式轴（自回归 vs 扩散）** —— 2026 年新战场。
- 扩散 LLM 的缓存：**P217 dKV-Cache**（延迟缓存）、**P202 Fast-dLLM v2**（块级 + 块内层级缓存）、**P203 FlashDLM**（FreeCache + Guided Diffusion）、**P185 Sparse-dLLM**（双向动态淘汰）、P001 Elastic-Cache（按去噪步与层深决定何时/何处重算）。

**理论刻画**：P002（attention sink 与 compression valley 是一枚硬币的两面）、P033（训练即损失压缩）、P098（提示压缩的率失真下界）。

## 4. 跨论文的第一性原理结论

以下 10 条结论在本次语料中被**多篇独立工作**从不同角度支持，因而可以作为阅读与设计本方向方法时的判据。

**结论 1：压缩的上限由数据冗余度决定，而非由算法决定。**
信息论意义上，固定码率的有损编码能否成功取决于被压对象的冗余。P098 用率失真框架给出提示压缩的下界；P033 把训练本身解释为损失压缩；P198 在 30–50% 保留率下保持 ≥95% 性能，这一数字本身就是**任务冗余度的测量**；P135 更进一步，用表示的稳定性直接反推可压缩性。**实践含义**：看到"压缩 X 倍无损"时，第一问应是"在什么冗余度的数据上"。

**结论 2：重要性是查询条件化且随时间演化的。**
四条独立证据：P178 Figure 2（保留 top-$k$ 无法保住大部分注意力质量；被淘汰 token 在后续步进入 top-20% 注意力；每个 token 的注意力方差很大）；P214 Figure 4（页重要性跨解码步漂移，并统计了逐步所需的页召回次数）；P180 Figure 1（层×步注意力稀疏度热图，早层随时间越来越稀疏）；P177 Figure 2（仅改变提示表述，剪枝方法性能即显著波动）。**实践含义**：静态、query-agnostic 的一次性压缩必然在长生成上退化；要么多次重排（P180），要么可逆（P178/P214/P183）。

**结论 3：用注意力近似重要性是主要误差来源。**
P221 明确给出反例与理论：注意力分数高 ≠ 淘汰后输出重构好，$QK^\top$ 的近似不保证 $\mathrm{softmax}(QK^\top)V$ 的近似；P199 发现 PCA（重构最优）在低压缩率下表现差而要改用蒸馏（行为最优）；P003 用任务信号替代注意力统计。三者共同说明：**代理指标越接近最终目标，方法的天花板越高**。这是本方向最可复用的方法论原则。

**结论 4：压缩有六个正交轴，但"预算分配"本身几乎无人研究。**
P199 明确指出既有工作聚焦前三个轴（层、头、序列长度）而忽略特征维；P183 指出通道轴被系统性忽视；P205 在层轴上选择；P182 在 token 轴上让压缩表示兼任索引。**然而**，当总预算固定时，"把预算花在 token 轴还是位宽轴还是特征维轴"这一决策没有一篇给出系统答案——这是本语料中最大的一致性空白。

**结论 5：压缩会带来正则效应，"不降分"不等于"没丢信息"。**
P003 报告在 AIME24 上 4096 token 预算的 pass@1（75.8）**高于** 32768 全缓存的 65.5；P188 观察到"有选择地移除与生成无关的 token 反而提升准确率"；P139、P050 在推理链上做冗余剪枝同样得益。**这提示评价陷阱**：用"精度不降"证明压缩安全是不可靠的 —— 降噪（有益）与信息损失（有害）在聚合指标上互相抵消。判据应当转向**逐任务最差值**与**精确检索类子任务**。

**结论 6：可逆性已成为与压缩率并列的设计维度。**
三种实现路径：**元数据账本**（P178 记录合并历史并校正注意力，给出单步无损与多步误差界）、**存储层级**（P214 页粒度淘汰到外部存储、按需召回，把"遗忘"变成"降级"）、**计算时恢复**（P183 存储时有损、打分时恢复）。**实践含义**：设计压缩方案时应先问"丢掉的能否按需找回、代价多大"，而非只问"能压多少"。

**结论 7：压缩的成本必须与它省下的成本一起记账。**
P210 被迫同时报告"总 token/调用"（38×/20.9×）与"纯在线成本"（106×/117×），说明**成本口径本身会改变结论**；P206 在 GPU 与 CPU 上加速来源不同（FLOPs vs 访存）；P183 承认非结构化稀疏在硬件上难以兑现；P220 以边缘算力约束为前提，明确把压缩自身的计算代价计入预算；P064/P068 从系统角度讨论"重算还是加载"。**实践含义**：接受任何加速数字前，先确认分母与口径。

**结论 8：系统级复用与调度的收益量级高于单点压缩率提升。**
对比一组数字：压缩类方法的质量改进通常在 1–10 个百分点（P177 LongBench +1、RULER +3；P221 准确率最高 +9.6%）；而复用/调度类方法的系统改进在倍数级（P204 8 模型吞吐 3.5×、P219、P207 命中率 6.92×、P186 TTFT 6.68×、P220 吞吐 +39.4%）。**实践含义**：在 agent 与多模型场景中，先把复用/调度做对，再谈压缩算子，是更优的投入顺序。

**结论 9：认知科学类比提供了丰富的设计语言，但不构成证据。**
本次语料中大量工作以神经科学或认知理论为蓝本：海马体—新皮层（P176、P099）、情节/语义记忆二分（P175、P191）、Atkinson–Shiffrin 三级结构（P210）、模糊痕迹理论（P197）、Zettelkasten（P215）、皮亚杰建构主义（P216）、星形胶质细胞（P021）、人类阅读的注意力模型（P192）。这些类比在**生成设计选项**（分层、巩固、同化/顺应、警戒拒答）上极富成效，但它们的证据强度取决于独立于类比的实验；对于 P194 这类用受控沙盒严格排除记忆影响的实验，其结论（瓶颈是深度而非记忆）反而比隐喻更有力。

**结论 10：自回归与扩散两套范式的缓存规则不可互相移植。**
自回归缓存的基本规则是"已生成即复用"，而扩散 LLM 的双向注意力使这一规则失效，必须改为**延迟**复用（P217）、**双向**淘汰（P185）、**块级**层级缓存（P202）、或在去噪步间复用稳定的 KV 投影（P203 的 FreeCache / P001 的 Elastic-Cache）。四篇工作独立确认了"KV 在去噪过程中变化很小但并非不变"这一时间维结构。**实践含义**：跨范式的结论（如"近因优先"）不能直接照搬。

## 5. 争议与张力：语料内部尚未收敛的对立

这些对立不是错误，而是**条件依赖的结论**；它们的边界正是最有价值的研究问题。

| 张力 | 一方 | 另一方 | 现有语料给出的裁决线索 |
| --- | --- | --- | --- |
| **要不要遗忘** | 保留并演化（P215 记忆演化、P146 时间线管理） | 主动遗忘（P125 从召回到遗忘、P196 记忆压力旋钮） | 取决于查询分布稳定性：分布稳定则保留更优，漂移则必须遗忘 |
| **注意力打分行不行** | H2O/SnapKV 一脉（实践有效） | P221、P199、P003（理论上错位） | 两者都成立：注意力是**廉价且有偏**的代理，偏差在长程检索与数值任务上放大 |
| **近因是否可信** | StreamingLLM 式滑窗 | P160 TreeKV、P180 RASR、P177 | 近因是**任务需求**还是**模型缺陷**尚未定论，是语料中最尖锐的开放问题 |
| **免训练 vs 训练式** | P214、P206、P211、P182、P188 等免训练 | P177、P003、P199、P198、P170 需轻量训练 | 训练式在同等预算下普遍更准，但代价是绑定模型与运维成本 |
| **"无损"的含义** | P178 单步无损、P203 近无损 | P003 的 SCBench Retr.KV = 0.00 | "无损"通常指**中间张量/注意力扰动为零**，不等于**任务输出等价** |
| **静态 vs 动态选择** | P221、P199（prefill 静态选择） | P178、P214、P180（承认并处理漂移） | P221 在 Limitations 中自陈这是其最大局限，说明该问题已被领域承认 |
| **压缩率口径** | cache budget / compression ratio 两种记法混用 | — | P221 明确说明"预算 30% 对应压缩率 70%"，跨论文比较前必须换算 |

## 6. 证据强度评估与常见缺口

### 6.1 语料整体的证据特征

- **模型覆盖面偏窄**：KV 类工作高度集中在 Llama 系列（2/3/8/70B）与 Mistral/Qwen；MoE、极端 GQA、多语言基座的验证明显不足。
- **长度覆盖偏短**：多数 KV 工作的评测序列停留 4K–32K（P179 明确因显存限制将序列上限设为 4096），而"长上下文"的真实收益场景是 128K 以上；P182 使用 Qwen2.5-14B-1M 属于少数例外。
- **基准高度同质**：LongBench + RULER + NIAH 构成事实标准，但其**平均分**会掩盖逐任务差异，而本方向最脆弱恰是其中少数子任务（精确检索、多跳、数值）。
- **"无损"缺乏统一定义**：重构无损 / 注意力无损 / 输出无损 / 任务无损四种口径被混用。

### 6.2 反复出现的四类缺口（写作与设计时的检查清单）

1. **缺少曲线，只有端点。** 大量工作只报告 2–3 个压缩率点，不给出"压缩率—精度"完整曲线，因而无法判断是否存在悬崖（P085、P172、P197 均有此问题）。
2. **缺少最坏情形。** 精确检索（NIAH 多针变体）、逐字复现（数字/ID/代码）几乎无人单独评测；P003 的 0.00 是语料中少见的诚实披露。P186 对"相似但不等价子图"的静默丢弃也没有最坏情形分析。
3. **缺少成本账。** 需要 LLM 参与写入/演化的记忆系统（P215 的链接生成与记忆演化）普遍不报告 token/调用开销随规模的增长率；对照 P210 的成本表可见这一缺口之明显。
4. **缺少误差界。** 近似性压缩（稀疏、合并、低比特、静态选择）多给出经验结果，只有 P178（多步误差界）、P174（无偏估计与 $m\sim1/\varepsilon^2$）、P221（重构损失最小化）提供了分析性刻画。

### 6.3 评测方法论上值得推广的三个做法

- **干预式验证机制假说**：P190 通过掩蔽 10% 的上下文头 / 结构头，直接证明两类头承担不同职责（而非只给相关性）；这类实验应成为"功能分工"类主张的标准配置。
- **机制指标而非只看端到端**：P177 报告"关键 KV 命中率"，P193 报告记忆占用增长曲线，P219（缺口）提示应报告缓存命中率 —— 机制指标才能区分"预测更准"与"预取更快"。
- **成本双账本**：P210 同时报告总成本与在线成本，这是记忆系统评测应当采纳的规范。

## 7. 开放问题与建议方向

按"问题价值 × 当前空白度"排序：

1. **跨轴预算分配（最紧迫）**。给定总预算，token / 位宽 / 特征维 / 层头 / 时间轴之间的最优分配是什么？现有方法是各自在自己的轴内优化，缺少统一的分配理论。P199 与 P183 分别点出了这一空白，P221 提供了"以输出保真度为目标"的候选框架。
2. **压缩的误差形态与任务敏感度的匹配理论**。§2.2 的三分表目前只是经验归纳；需要把"弥散误差 vs 局部误差"与任务的信息需求（定位 / 聚合 / 数值）形式化匹配，从而给出"某任务上应选哪类压缩"的判据。
3. **可逆压缩与无界上下文的接合**。P214（可召回）、P178（合并账本）、P183（可恢复）各自给出了可逆性的局部解，但没有一个方案同时处理"无界增长 + 可逆 + 成本可控"三者。P210 的离线巩固与 P219 的工作流预取分别从调度侧接近该问题。
4. **时间敏感的记忆评测协议**。现有对话记忆评测（LoCoMo、LongMemEval）在会话结束后统一提问，无法暴露"新鲜度延迟"这一睡眠期更新的固有代价（P210）。需要按"提问时刻相对信息写入时刻"分层的评测。
5. **压缩与安全的相互作用**。P200 证明淘汰可以**主动用于防御**（淘汰最低分 token 挤掉有害查询），这意味着任何压缩策略都在隐式地选择"保留哪部分意图"；压缩对对齐、越狱鲁棒性、知识编辑（P208）的副作用尚无系统研究。
6. **多模态与时序范式的记忆统一**。VAR（P189/P190）、视频流（P152/P162/P197）、扩散文本（P217 等）都在各自定义"尺度/片段/去噪步"的记忆单位；这些单位与 token 的关系、能否统一为一种"分层时间预算"框架，是跨领域的机会。
7. **Agent 记忆的成本与一致性**。P215 的"写入即重组"与 P216 的"同化/顺应"都缺少长期一致性分析（反复有损再编码的误差累积）与版本可追溯机制；P195 提供"规范学习"路径，但反馈获取成本未量化。
8. **可证保证的实用化**。P207 是语料中唯一给出竞争比保证的系统工作；把淘汰/路由/压缩的目标函数写成可分析的形式（P098 的率失真、P221 的重构损失）并保持工程可用，是被反复证明有效的方向。
