这是这个站点的第一篇文章。

在 GitHub 上安家的好处很朴素：文章就是仓库里的 `.md` 文件，用 Git 版本管理，写完推上去，页面就更新。不需要后台，不需要数据库，写作的门槛被压到最低 —— 一个编辑器就够了。

技术写作里最麻烦的其实是公式。推导一个算法的复杂度，或者记录一段概率论，`O(n log n)` 还能凑合，但遇到这样的式子就只能上真正的排版了：

$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n) \implies T(n) = O(n \log n)
$$

本站的每一篇文章都是 Markdown，公式直接用 LaTeX 语法写在正文里，渲染交给 KaTeX。

如果你想知道哪些格式都被支持，看上一篇《Markdown 与 LaTeX 公式完全演示》就够了 —— 它本身就是用这些格式写的。
