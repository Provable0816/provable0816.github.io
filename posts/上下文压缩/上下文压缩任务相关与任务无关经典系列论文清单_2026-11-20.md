# 上下文压缩「任务相关」与「任务无关」经典系列论文清单

**分类基准**：《面向智能体与API交互的上下文压缩_综述报告_2026-11-18.md》§1.1 式 2a/2b 与 §1.2「两类压缩任务（运行模式）」对照表。

- **任务无关（query-agnostic / 命令式）**：压缩发生时无当前请求 $q_t$ 可用；算子 $C_\varnothing(H_t, B_t)$ 或含 $A_t, R_t$；产物一次压缩、多次复用。
- **任务相关（query-aware / 请求驱动）**：$q_t$ 到达后触发，$q_t$ 作为**条件输入**进入 $C$，但主流设计 $q_t \notin \mathrm{Obj}(C_{\mathrm{lossy}})$（参与决策、不参与有损压缩），$\mathrm{prompt}_t = c_t \oplus q_t$。

**筛选原则**：(1) 报告附录 B 的 99 条参考文献中直接涉及或可延伸关联；(2) 每个系列取最经典/最具代表性的节点，按时间排列；(3) 依据摘要内容归类 —— 摘要中压缩决策是否以当前 query/question 为条件；摘要级证据不足的以报告正文归类为准并注明。(4) 排除：ACE [3]（context adaptation、报告 §1.3 明确「不压缩」）、ACBench [98]（模型权重量化）、纯 benchmark/综述条目（除非其压缩策略本身有明确归类）。

**摘要获取**：48 篇经 arXiv API（export.arxiv.org）批量获取，4 篇（Selective Context [61]、LLMLingua [62]、EXIT [59]、TACO-RL [38]）经 ACL Anthology 页面获取。**无摘要缺失项**，全部为原文，未改写。在此基础上为全部 52 条摘要补充了逐项对应的**中文摘要**（与英文版在段落、要点和顺序上一一对应，术语准确、表述自然）。

### **[61]** Compressing Context to Enhance Inference Efficiency of Large Language Models

- **出处**：Compressing Context to Enhance Inference Efficiency of Large Language Models ｜ EMNLP 2023 ｜ [链接](https://aclanthology.org/2023.emnlp-main.391/) ｜ 摘要来源：ACL Anthology 页面

- **系列**：A 压缩前史：Token 级任务无关

- **归类依据**：一切冗余剪枝路线的起点；摘要明确无 query 条件

- **摘要**：Large language models (LLMs) achieved remarkable performance across various tasks. However, they face challenges in managing long documents and extended conversations, due to significantly increased computational requirements, both in memory and inference time, and potential context truncation when the input exceeds the LLM's fixed context length. This paper proposes a method called Selective Context that enhances the inference efficiency of LLMs by identifying and pruning redundancy in the input context to make the input more compact. We test our approach using common data sources requiring long context processing: arXiv papers, news articles, and long conversations, on tasks of summarisation, question answering, and response generation. Experimental results show that Selective Context significantly reduces memory cost and decreases generation latency while maintaining comparable performance compared to that achieved when full context is used. Specifically, we achieve a 50% reduction in context cost, resulting in a 36% reduction in inference memory usage and a 32% reduction in inference time, while observing only a minor drop of .023 in BERTscore and .038 in faithfulness on four downstream applications, indicating that our method strikes a good balance between efficiency and performance.

- **中文摘要**：大语言模型（LLM）在各类任务中取得了卓越的性能。然而，由于内存和推理时间上的计算需求显著增加，且当输入超出 LLM 固定上下文长度时可能发生上下文截断，LLM 在处理长文档与长对话时面临挑战。本文提出一种名为 Selective Context 的方法，通过识别并剪除输入上下文中的冗余内容使输入更加紧凑，从而提升 LLM 的推理效率。我们在需要长上下文处理的常见数据源——arXiv 论文、新闻文章与长对话——上，针对摘要、问答与回复生成三类任务对所提方法进行了测试。实验结果表明，在保持与全量上下文相当性能的同时，Selective Context 显著降低了内存开销并缩短了生成延迟。具体而言，我们实现了 50% 的上下文成本削减，带来 36% 的推理内存使用量下降与 32% 的推理时间缩短，而四项下游应用中 BERTscore 仅下降 0.023、忠实度仅下降 0.038，表明该方法在效率与性能之间取得了良好平衡。

### **[62]** LLMLingua: Compressing Prompts for Accelerated Inference of Large Language Models

- **出处**：LLMLingua: Compressing Prompts for Accelerated Inference of Large Language Models ｜ EMNLP 2023 ｜ [链接](https://aclanthology.org/2023.emnlp-main.825/) ｜ 摘要来源：ACL Anthology 页面

- **系列**：A 压缩前史：Token 级任务无关

- **归类依据**：LLMLingua 系列奠基作；coarse-to-fine，摘要无 query 条件

- **摘要**：Large language models (LLMs) have been applied in various applications due to their astonishing capabilities. With advancements in technologies such as chain-of-thought (CoT) prompting and in-context learning (ICL), the prompts fed to LLMs are becoming increasingly lengthy, even exceeding tens of thousands of tokens. To accelerate model inference and reduce cost, this paper presents LLMLingua, a coarse-to-fine prompt compression method that involves a budget controller to maintain semantic integrity under high compression ratios, a token-level iterative compression algorithm to better model the interdependence between compressed contents, and an instruction tuning based method for distribution alignment between language models. We conduct experiments and analysis over four datasets from different scenarios, i.e., GSM8K, BBH, ShareGPT, and Arxiv-March23; showing that the proposed approach yields state-of-the-art performance and allows for up to 20x compression with little performance loss.

- **中文摘要**：凭借惊人的能力，大语言模型（LLM）已被应用于各类场景。随着思维链（CoT）提示与上下文学习（ICL）等技术的发展，输入给 LLM 的提示越来越长，甚至超过数万个 token。为加速模型推理并降低成本，本文提出 LLMLingua——一种由粗到细的提示压缩方法，包含三个部分：在高压缩比下维持语义完整性的预算控制器、用于更好地刻画被压缩内容之间相互依赖关系的 token 级迭代压缩算法，以及基于指令微调实现语言模型间分布对齐的方法。我们在来自不同场景的四个数据集——GSM8K、BBH、ShareGPT 与 Arxiv-March23——上进行了实验与分析，结果表明该方法取得了最先进的性能，可在几乎不损失性能的情况下实现最高 20 倍的压缩。

### **[64]** LLMLingua-2: Data Distillation for Efficient and Faithful Task-Agnostic Prompt Compression

- **出处**：arXiv:2403.12968 ｜ [链接](https://arxiv.org/abs/2403.12968) ｜ 摘要来源：arXiv API

- **系列**：A 压缩前史：Token 级任务无关

- **归类依据**：LLMLingua 系列任务无关分支终点；报告 §1.2 明确 query 与 context 分离

- **摘要**：This paper focuses on task-agnostic prompt compression for better generalizability and efficiency. Considering the redundancy in natural language, existing approaches compress prompts by removing tokens or lexical units according to their information entropy obtained from a causal language model such as LLaMa-7B. The challenge is that information entropy may be a suboptimal compression metric: (i) it only leverages unidirectional context and may fail to capture all essential information needed for prompt compression; (ii) it is not aligned with the prompt compression objective. To address these issues, we propose a data distillation procedure to derive knowledge from an LLM to compress prompts without losing crucial information, and meantime, introduce an extractive text compression dataset. We formulate prompt compression as a token classification problem to guarantee the faithfulness of the compressed prompt to the original one, and use a Transformer encoder as the base architecture to capture all essential information for prompt compression from the full bidirectional context. Our approach leads to lower latency by explicitly learning the compression objective with smaller models such as XLM-RoBERTa-large and mBERT. We evaluate our method on both in-domain and out-of-domain datasets, including MeetingBank, LongBench, ZeroScrolls, GSM8K, and BBH. Despite its small size, our model shows significant performance gains over strong baselines and demonstrates robust generalization ability across different LLMs. Additionally, our model is 3x-6x faster than existing prompt compression methods, while accelerating the end-to-end latency by 1.6x-2.9x with compression ratios of 2x-5x. Our code is available at https://aka.ms/LLMLingua-2.

- **中文摘要**：本文聚焦于任务无关的提示压缩，以获得更好的泛化性与效率。考虑到自然语言的冗余性，现有方法依据因果语言模型（如 LLaMa-7B）得到的信息熵来删除 token 或词法单元，从而压缩提示。但信息熵可能是一个次优的压缩度量：(i) 它仅利用单向上下文，可能无法捕捉提示压缩所需的全部关键信息；(ii) 它与提示压缩的目标并不对齐。针对这些问题，我们提出一种数据蒸馏流程，从 LLM 中提炼知识，以在不丢失关键信息的前提下压缩提示，同时引入一个抽取式文本压缩数据集。我们将提示压缩形式化为一个 token 分类问题，以保证压缩后的提示对原始提示的忠实性，并以 Transformer 编码器为基础架构，从完整的双向上下文中捕捉提示压缩所需的全部关键信息。通过用 XLM-RoBERTa-large、mBERT 等更小的模型显式学习压缩目标，我们的方法获得了更低的延迟。我们在域内与域外数据集（包括 MeetingBank、LongBench、ZeroScrolls、GSM8K 与 BBH）上评估了所提方法。尽管规模很小，我们的模型相较强基线仍表现出显著的性能提升，并展现出跨不同 LLM 的稳健泛化能力。此外，我们的模型比现有提示压缩方法快 3–6 倍，在 2–5 倍压缩比下可将端到端延迟加速 1.6–2.9 倍。代码已发布于 https://aka.ms/LLMLingua-2。

### **[6]** LightThinker: Thinking Step-by-Step Compression

- **出处**：arXiv:2502.15589 ｜ [链接](https://arxiv.org/abs/2502.15589) ｜ 摘要来源：arXiv API

- **系列**：A 压缩前史：Token 级任务无关

- **归类依据**：推理时压缩中间思考，摘要无 query 条件

- **摘要**：Large language models (LLMs) have shown remarkable performance in complex reasoning tasks, but their efficiency is hindered by the substantial memory and computational costs associated with generating lengthy tokens. In this paper, we propose LightThinker, a novel method that enables LLMs to dynamically compress intermediate thoughts during reasoning. Inspired by human cognitive processes, LightThinker compresses verbose thought steps into compact representations and discards the original reasoning chains, thereby significantly reducing the number of tokens stored in the context window. This is achieved by training the model on when and how to perform compression through data construction, mapping hidden states to condensed gist tokens, and creating specialized attention masks. Additionally, we introduce the Dependency (Dep) metric to quantify the degree of compression by measuring the reliance on historical tokens during generation. Extensive experiments on four datasets and two models show that LightThinker reduces peak memory usage and inference time, while maintaining competitive accuracy. Our work provides a new direction for improving the efficiency of LLMs in complex reasoning tasks without sacrificing performance. Code is released at https://github.com/zjunlp/LightThinker.

- **中文摘要**：大语言模型（LLM）在复杂推理任务中表现出色，但生成冗长 token 所带来的大量内存与计算开销制约了其效率。本文提出 LightThinker，一种使 LLM 能够在推理过程中动态压缩中间思考的新方法。受人类认知过程启发，LightThinker 将冗长的思维步骤压缩为紧凑表示，并丢弃原始推理链，从而大幅减少存储在上下文窗口中的 token 数量。其实现方式包括：通过数据构造训练模型掌握何时以及如何执行压缩、将隐状态映射为凝练的 gist token，以及设计专门的注意力掩码。此外，我们引入依赖度（Dependency, Dep）指标，通过衡量生成时对历史 token 的依赖程度来量化压缩强度。在四个数据集与两个模型上的大量实验表明，LightThinker 降低了峰值内存使用量与推理时间，同时保持了具有竞争力的准确率。我们的工作为在不牺牲性能的前提下提升 LLM 在复杂推理任务中的效率提供了新方向。代码已发布于 https://github.com/zjunlp/LightThinker。

### **[53]** Beyond Hard and Soft: Hybrid Context Compression for Balancing Local and Global Information Retention

- **出处**：arXiv:2505.15774 ｜ [链接](https://arxiv.org/abs/2505.15774) ｜ 摘要来源：arXiv API

- **系列**：A 压缩前史：Token 级任务无关

- **归类依据**：硬软混合 HyCo2，摘要无 query 条件

- **摘要**：Large Language Models (LLMs) encounter significant challenges in long-sequence inference due to computational inefficiency and redundant processing, driving interest in context compression techniques. Existing methods often rely on token importance to perform hard local compression or encode context into latent representations for soft global compression. However, the uneven distribution of textual content relevance and the diversity of demands for user instructions mean these approaches frequently lead to the loss of potentially valuable information. To address this, we propose $\textbf{Hy}$brid $\textbf{Co}$ntext $\textbf{Co}$mpression (HyCo$_2$) for LLMs, which integrates both global and local perspectives to guide context compression while retaining both the essential semantics and critical details for task completion. Specifically, we employ a hybrid adapter to refine global semantics with the global view, based on the observation that different adapters excel at different tasks. Then we incorporate a classification layer that assigns a retention probability to each context token based on the local view, determining whether it should be retained or discarded. To foster a balanced integration of global and local compression, we introduce auxiliary paraphrasing and completion pretraining before instruction tuning. This promotes a synergistic integration that emphasizes instruction-relevant information while preserving essential local details, ultimately balancing local and global information retention in context compression. Experiments show that our HyCo$_2$ method significantly enhances long-text reasoning while reducing token usage. It improves the performance of various LLM series by an average of 13.1\% across seven knowledge-intensive QA benchmarks. - **中文摘要**：任务完成率是评测上下文压缩的标准指标，但它并不完备：压缩可能迫使智能体重获被丢弃的状态，从而推高其交互成本，而完成率在统计上却毫无变化。我们提出一个在有界时程工具使用智能体中测量重获取成本的受控运行时协议。智能体在一个确定性规划环境中、以固定的 24 轮时程运行。我们改变压缩强度，比较一个丢弃算子与一个保事实算子，通过受控的 oracle 干预恢复被丢弃的状态，并将工具调用分解为检索与执行两部分。我们在两个任务体制下评测三个模型。在全部六组模型-体制比较中，检索调用均有增加，且几乎贡献了全部新增交互；其中六组中有五组在 Holm 校正后仍显著。在预先指定的 5 倍比较点上，没有任何单元格的完成率变化显著。DeepSeek 仅在 10 倍压缩下出现显著的完成率下降。GPT-5.5 是最清晰的情形：完成率从 80% 变为 85%（p = 1.0），而检索从 21.0 次增至 63.9 次（p = .002）。保留干预进一步区分了状态数量、状态类型与内容有效性：随机选择与离线事后 oracle 表现相当，而用语义无关内容替换所保留的 D 状态，则使检索增加 57%（p < .001），完成率却无显著变化。在第二个环境 ALFWorld 中，滑动压缩并未引发检索激增，表明重获取特征取决于环境，而非缩短上下文的内在属性。总体而言，当执行相关状态缺席、必须被重新获取时，压缩可能施加隐性的交互成本，而仅看完成率未必能暴露这些成本。
