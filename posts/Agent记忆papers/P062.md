# P062 Efficient Low Rank Attention for Long-Context Inference in Large Language Models

- 会议/来源：NeurIPS 2025
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/36db9d16a9f80ede9e69d5d174cfd6ea-Abstract-Conference.html

## 贡献

提出 LRQK（Low Rank Query and Key attention）：在 prefill 阶段把全精度 query 与 key 矩阵联合分解为紧凑的 rank-$r$ 因子，解码时用这些低维投影在 $O(lr)$ 时间内计算**代理注意力分数**，据此选出 top-k token 与一小批固定的最近 token；配合 GPU–CPU 混合缓存与 hit-and-miss 机制，只搬运缺失的全精度 KV 对。

## 机制要点

设计的关键在于「近似只用于选择，不用于计算」——用低秩代理分数决定取回哪些 KV，但参与注意力的仍是全精度向量，因此**注意力输出保持精确**。这把低秩方法从「有损压缩」重新定位为「廉价索引」，与 P035（SALS）的取舍相似但分工不同（SALS 用低秩存储 + 稀疏重建，LRQK 用低秩做打分 + 精确取回）。代价是需要构建低秩分解、维护 GPU/CPU 两级缓存与命中率机制，且代理分数的排序误差会直接影响选中集合的质量。

## 关键结果

在 RULER 与 LongBench 上，用 LLaMA-3-8B 与 Qwen2.5-7B 评测，LRQK 达到或超过领先稀疏注意力方法的水平，同时取得显著显存节省与极小精度损失。摘要未给出显存节省与延迟的具体倍数。

## 局限与定位

第一，代理分数的质量是系统上限：低秩分解假设 query/key 的有效秩较低，而 P035 已指出 RoPE 会抬高 key 的有效秩，因此 LRQK 的分解是否也需要类似的去 RoPE 处理，决定了它的适用性边界；摘要未涉及这一点。第二，hit-and-miss 机制的有效性取决于命中率，而命中率与「top-k 在时间上的连续性」相关——若每一步选中的 token 集合剧烈变化，只搬运缺失项的优化收益会大幅缩水，论文未给出命中率统计。第三，平均精度接近基线不排除个别任务（精确检索、计数）退化，缺 NIAH 类专项。第四，与 P051 的 CPU 侧 ANNS 检索路线相比，LRQK 的检索在 GPU 侧以矩阵乘法完成，延迟结构不同，两者在什么负载下各有优势值得对比。定位上属于「低秩打分 + 精确取回」的混合缓存方法。
