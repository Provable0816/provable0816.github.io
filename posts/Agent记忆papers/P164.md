# P164 STAC: Plug-and-Play Spatio-Temporal Aware Cache Compression for Streaming 3D Reconstruction

- 会议/来源：CVPR 2026
- 方向簇：VLM
- 链接：/content/CVPR2026/html/Wang_STAC_Plug-and-Play_Spatio-Temporal_Aware_Cache_Compression_for_Streaming_3D_Reconstruction_CVPR_2026_paper.html

## 贡献

面向**流式输入的在线 3D 重建**（需要长时程一致性与高效显存使用）提出 STAC：因果版 VGGT 类模型虽用 KV cache 应对流式输入，但 cache 随流长线性增长，成为主要显存瓶颈；在有限显存下过早驱逐会显著损害重建质量与时间一致性。论文观察到用于 3D 重建的因果 transformer 的注意力具有**内在的时空稀疏性**，据此设计三部分机制：(1) **工作态时序 token 缓存**，用衰减累积注意力分数保留长时程信息量大的 token；(2) **长期空间 token 缓存**；(3) 其余组件（摘要未完整给出）。

## 机制要点

两点值得注意。第一，「衰减累积注意力分数」是对「历史重要性」的一种时间加权形式——它与 P160（TreeKV 用分辨率渐变）、P092（级联子缓存）同属「随时间衰减的保留策略」，但此处用于流式 3D 重建，其正确性依赖**场景的时空连续性**：相邻帧高度相关，因此渐进式遗忘在几何上是合理的，这与自然语言（语义可跳变）不同。第二，把 cache 分成**时序**与**空间**两路，实际上承认了 VRAM 预算需要在「时间跨度」与「空间细节」之间分配——这是 3D 重建特有的权衡：压缩空间细节会直接损失几何精度，压缩时间跨度会破坏跨帧一致性。这一双路结构在概念上与 P162（MuKV 的三级粒度）、P083（CAKE 的多维分配）同源。

## 关键结果

论文报告在有限显存预算下改善重建质量与时间一致性；具体指标（重建误差、一致性度量）与基线需回看正文。评价这类任务时，「在同等显存下能处理多长的流」比单一质量指标更有说服力。

## 局限与定位

第一，该任务的评价标准（几何精度、一致性）与语言/视频问答的指标体系完全不同，因此该工作与其他 KV 压缩方法之间**不存在直接的性能可比性**——它更像是对同一技术（KV 缓存压缩）在新领域（3D 重建）的迁移验证，其价值在于证明这类方法不限于语言任务。第二，「衰减累积」假设时间上越近越重要，与 P160 的结论一致，但同样面临「远期关键信息」的风险：若场景中某个早期视角对后续重建至关重要（例如唯一的背面视角），衰减策略可能将其删除。第三，作为插件式方案，其与原模型（因果 VGGT）的耦合程度决定了可迁移性。第四，VRAM 预算中时序与空间两路的分配比例是核心超参，其敏感性需要分析。定位上属于 KV 压缩技术在几何重建领域的应用工作。
