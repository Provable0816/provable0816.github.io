# P188 DAVID: Dual-Stage Adaptive Vision-Text Integrated Decoupling for Multimodal KV Cache Eviction

- 会议/来源：AAAI 2026（主会）
- 方向簇：VLM
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/39285
- 本地全文：cache/txt/P188.txt

## 贡献

按**模态融合程度**分层设计多模态 KV 淘汰策略：浅层视觉与文本尚未融合，采用**解耦（decoupled）淘汰**——两模态各自打分、各自保留；深层模态已完成融合，改用**超模态（super-modal）淘汰**——统一打分。层间的切换由一个轻量的跨模态融合度量（归一化 cross attention rate $\theta$）与阈值自动决定。

## 机制要点

观察依据见 Figure 1：(a) 典型多模态输入中文本简短但信息密度高、视觉输入冗余大；(b) 在 MLLM 输入层，文本 token 得到的注意力更高；(c) 层越深，模态融合越彻底。据此，浅层若统一打分会让「高注意力的文本」挤掉视觉证据，而深层若继续解耦则会错过跨模态的联合重要性——这是本文的核心论点：**淘汰判据应与该层的信息组织状态匹配**。算法有两条分支（Figure 2）：多模态解耦淘汰与超模态淘汰，$\theta$ 低于阈值时切换。

## 关键结果

模型为 LLaVA 系列（1.5-7B、1.5-13B）与 Qwen-VL；基准为 OCRBench（Table 1，含 Text Recognition 等子项）、MMVet（Table 2）、MathVista（Table 3），并报告推理速度与消融。论文提到一个有价值的副观察：**有选择地移除与生成无关的 token 反而能提升准确率**（即淘汰具有去噪/正则效应）——这与 P003（TRIM-KV 在数学推理上超过全缓存）的观察一致，值得在综述中横向对比。

## 局限与定位

第一，解耦/融合的切换是**按层**的二值决策，而融合程度在层内不同注意力头之间可能差异巨大，按层统一化可能过粗。第二，$\theta$ 的阈值是超参，论文未给出跨模型/跨任务的稳健性扫描，而阈值错判会直接导致某一模态被系统性压制。第三，「淘汰无关 token 反而提升准确率」这一现象若普遍成立，说明该任务族上存在显著冗余，但它同时提示：以「不降分」作为压缩正确性的判据未必可靠——降噪与信息损失在指标上难以分离。定位上，它把「按层异质性分配压缩策略」这一思想（参见 P179 KVmix 的层间位宽、P180 Lethe 的层间预算）从语言模型推广到多模态，并给出「模态维」这一新的分配维度。
