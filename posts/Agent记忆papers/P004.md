# P004 DefensiveKV: Taming the Fragility of KV Cache Eviction in LLM Inference

## 一句话贡献

指出 KV 淘汰领域默认的「稳定性假设」（固定子集持续重要）本质脆弱，均值聚合在极端情形下失效；提出两步、线性时间的 **defensive aggregation**（最坏情况估计 + 自适应先验风险校正）及其实例化 DefensiveKV / Layer-DefensiveKV，在 20% 缓存预算下把生成质量损失相对最强基线降低 2.3× 与 4.3×。

## 1. 问题与第一性原理动机

主流淘汰方法遵循「打分—聚合」两步：用多个历史 token 的查询分别给每个缓存项打分，再把这些观测聚合（通常取均值）以估计其期望重要性，据此淘汰。均值是对**平均情况**最优的估计，但它对稀有而极端的负例（某些 decoding 区间里重要性骤变）没有任何保护。论文用 Fig. 1 展示：大多数步单 token 观测与全缓存重要性的相关性超过 0.8，但在约 150–230 步的区间稳定性假设失效，个别离群值跌到 0.5，均值聚合必然同样崩塌。这暴露了一个结构性缺陷：聚合器优化的是期望而非风险，而淘汰是不可逆操作，尾部事件直接决定最终输出质量。

## 2. 核心洞察

把聚合从「求期望」改写为「控制最坏情况风险」——借用金融风险管理中对极端损失的关注（论文以 CVaR 式的直觉类比），在保留均值级计算复杂度的前提下提升最坏情况下的保留重要性。Fig. 1 的量化结果是：防御式聚合把最坏情况保留重要性提升到 0.65，而均值聚合为 0.45，单 token 基线为 0.42/0.47/0.43。也就是说，同样的分数集合，仅替换聚合方式就能抬高「最差情况下仍保住的关键信息量」。

## 3. 方法机制

Defensive Aggregation（Algorithm 1）分两步，均为线性时间：(1) **最坏情况估计**——在历史观测窗口上取风险敏感的统计量（而非均值）作为保留重要性的下界估计；(2) **自适应先验风险校正**——用先验信息对估计做自适应收缩，避免在最坏情况估计过于保守时误杀有效缓存项。因为只改了聚合算子，不改变打分器，方法可与既有打分框架（如 CriticalKV 类的分数）正交叠加。Layer-DefensiveKV 进一步引入逐层预算分配，把有限的缓存预算按层的重要性重分配。代价是引入窗口大小、风险参数等超参（Table 3 给出历史窗口 16/32/64 的消融），且需要历史窗口的分数缓存，带来少量额外状态开销。

## 4. 实验证据

设置：Llama-3.1-8B-Instruct 为主，另含 MoE 模型 Qwen-3-30B-A3B；7 类任务域、18 个数据集（LongBench 的 16 个数据集 + Needle-in-a-Haystack），并给出与 int4 量化叠加的结果（Table 8）。

关键数字：20% 缓存预算下，DefensiveKV 与 Layer-DefensiveKV 的生成质量损失分别为 4.8% 与 2.6%，而最强基线 CriticalKV 为 11.1%，即相对降低 2.3× 与 4.3×（正文图 2 与摘要）。Table 1 给出逐任务域的最坏情况保留重要性提升，如 NrtvQA 0.44→0.62、HotpotQA 0.39→0.60、GovReport 0.28→0.52 等（摘要未报告的完整值见表内）；Table 7 给出「有/无防御式聚合」在 LongBench 上的直接对照。

消融：把最坏情况估计与先验校正拆开，单独去掉自适应校正会使分数从 179 掉到 103（论文正文给出该对比），说明两步缺一不可；窗口大小对结果不敏感（Table 3）；附录给出 Corollary 1 关于自适应先验校正带来鲁棒性的形式化说明。

证据缺口：主要结果建立在作者自定义的「最坏情况保留重要性」这一代理指标上，该指标与下游任务质量之间的映射只在部分数据集上被验证；评测以 Llama-3.1-8B 与少数模型为主；20% 预算之外的预算区间（如 10%）结果放在附录（Table 4）；「风险」框架来自金融类比，正文缺少对风险参数选择的理论指导（为何该风险度量与生成质量单调相关）。

## 5. 第一性原理再审视

方法的成立依赖两个假设：(1) 重要性随时间的剧烈波动是**稀有事件**而非常态——只有在尾部稀疏时，抬高最坏情况估计才不会牺牲平均性能；(2) 当前步查询观测到的分数与未来若干步的真实重要性存在足够相关性，使「取最大/风险敏感统计量」成为有效的下界估计而非纯粹悲观。若采样步之间的重要性分布持续重尾，防御式聚合会系统性高估、导致预算被低效占用；若相关性整体偏弱，问题就退化为打分器问题，聚合无法补救。该框架的真正贡献在于把淘汰的失效模式从「平均误差」重新定位为「尾部风险」，这与淘汰的不可逆性相匹配，属于结构性洞察而非工程调参；但也因此，风险参数本身成为新的隐含假设载体——论文未给出如何从任务或预算推导它的原则。

## 6. 与相邻工作的关系

与 CriticalKV、H2O、SnapKV 等注意力打分型淘汰方法的关系是「正交增强」：不改分数、只改聚合与预算分配；与 StreamingLLM 这类固定模式保留相比更依赖分数质量；与量化路线（int4）可叠加（Table 8）。它属于 KV 淘汰技术脉络中「提升决策鲁棒性」的分支，与 P003 的「学习价值函数」、P005 的「不改缓存只改检索」形成三种不同的改进着力点。

## 7. 可迁移点与开放问题

可迁移的核心是聚合算子的风险化改写：任何「多个观测 → 一个决策」的场景（缓存淘汰、记忆检索打分、多轮 agent 的历史裁剪、RAG 中多段证据的融合）都可用同样的思路替代均值，并对不可逆决策优先保护尾部。开放问题：能否给出「最坏情况保留重要性」与下游质量的可证明界；风险参数能否随层/任务自适应；该框架能否扩展到检索（可逆）与淘汰（不可逆）混合的缓存策略中。
