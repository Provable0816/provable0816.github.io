# P185 Sparse-dLLM: Accelerating Diffusion LLMs with Dynamic Cache Eviction

- 会议/来源：AAAI 2026（主会）
- 方向簇：KV
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/40586
- 本地全文：cache/txt/P185.txt

## 贡献

针对扩散大语言模型（dLLM）的迭代去掩码解码，提出首个**免训练**地把稀疏注意力与动态缓存淘汰结合起来的框架：基于「注意力稀疏性跨层持续、关键 token 在解码步间保持显著」这一观察，用延迟双向稀疏缓存（delayed bidirectional sparse caching）同时处理前缀与后缀方向的冗余，在 LLaDA、Dream 系列上取得最高约 10× 吞吐且性能相当。

## 机制要点

dLLM 与自回归模型的关键差异是解码过程：从全 [MASK] 出发，经 $T$ 步迭代去掩码，每步都对全序列计算注意力。Figure 2（LLaDA-8B-Instruct，$L=66$、$T=32$、块长 32）给出两个基础观察：一是**跨层持续稀疏**（横向看各层，pivotal token 始终显著、低相关 token 始终不重要），二是关键 token 的显著性在**步间稳定**。正是「稳定性」使得「按当前块的 query 与历史 KV 的注意力分数直接做缓存稀疏」成为可能（Figure 3 展示了整体框架，Figure 4 用 L2 范数证明当前解码块之外的 KV 状态在相邻步间变化很小）。双向体现在**前缀与后缀同时淘汰**——这与自回归模型只能处理后缀/历史的结构性差异有关。

## 关键结果

在 LLaDA 与 Dream 系列上评测，Figure 1 以「吞吐 × 精度」散点对比各方法：Sparse-dLLM 位于最优角（吞吐最高且精度不低于 vanilla）。结论部分给出三点结果：(1) 下游任务性能可比；(2) 相对 vanilla dLLM 最高约 10× 吞吐；(3) 峰值显存与 vanilla 接近（即收益主要来自计算而非内存）。

## 局限与定位

第一，「峰值内存与 vanilla 接近」意味着该方法的定位是**延迟优化而非内存压缩**——它没有减少常驻缓存规模，只是减少了参与计算的量，这与本方向多数工作（降显存）目标不同，需分清。第二，稀疏策略依赖「显著性在步间稳定」这一经验规律，而该规律在**高熵/高不确定性生成**（创意写作、开放式推理）中可能较弱，论文未按任务类型做分层验证。第三，dLLM 的缓存语义与自回归 KV 不同（每步都重新计算全序列注意力），跨范式结论不可直接迁移。定位上，它把「注意力稀疏 + 缓存淘汰」这一组合引入扩散式解码，与 P202（Fast-dLLM v2）、P203（FlashDLM）、P217（dKV-Cache）共同构成本方向在扩散 LLM 分支上的探索，是目前该分支中「训练-free + 双向淘汰」的代表。
