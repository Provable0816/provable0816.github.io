# P143 Tree of Agents: Improving Long-Context Capabilities of Large Language Models through Multi-Perspective Reasoning

- 会议/来源：EMNLP 2025（Findings）
- 方向簇：BENCH
- 链接：/2025.findings-emnlp.246/

## 贡献

针对长上下文的两难——**缩减输入有丢弃关键信息的风险，扩展窗口又导致注意力分散**——提出 Tree of Agents（TOA）：一个多 agent 推理框架，把输入切分为块、由**相互独立的 agent** 分别处理，每个 agent 生成本地认知（local cognition），随后 agent 之间沿**树结构路径**动态交换信息进行协作推理。TOA 让 agent 得以**探索不同的推理顺序**，从而应对「lost in the middle」这一信息位于中部时被低效利用的经典问题。

## 机制要点

设计上有两点值得注意。第一，用「多视角 + 不同推理顺序」直接对抗位置偏置：既然模型固有一种从两端向中间衰减的注意力倾向，那就让不同的 agent 从不同的起点/顺序阅读，从而让中部信息在至少一条路径上处于「有利位置」。这是把位置偏置问题**转化为路径多样性**的处理方式，与 P073（ParallelComp 系统分析并行注意力下的三类偏置）形成方法上的呼应——P073 用驱逐缓解偏置，TOA 用顺序多样性绕开偏置。第二，树结构而非链式通信：链式（如 P109 的 CoA）会强制固定顺序、累积误差，树结构允许多条路径并行探索并保留交互。

## 关键结果

论文报告 TOA 在长上下文任务上改善了能力并缓解了「lost in the middle」问题；具体基准与提升幅度需回看正文。判定该方法是否有效，关键要看它是否包含**针对中段信息的定向评测**（而非仅报告平均值），因为位置偏置的改善只有在按证据位置分层的指标上才可见。

## 局限与定位

第一，多 agent 树搜索的**推理成本**是主要问题：多个 agent 各自处理 + 树路径上的交换，意味着 token 消耗与延迟都显著高于单次调用；论文需要给出成本—收益对比，尤其是与「简单地用更长上下文一次读完」相比是否划算。第二，块切分与位置多样性假设「关键信息可被局部识别」，若答案需要跨块组合（多跳），单个 agent 的本地认知无法提供，依赖通信质量；这与 P109 的顺序通信瓶颈是同类问题。第三，块边界效应（P111 的「边界丢失」、P039 的 chunk 边界）在固定切分下依然存在。第四，「探索不同推理顺序」的有效性依赖顺序确实影响结果——这一前提在部分任务上成立、在另一些任务上可能无关，需要按任务类型给出证据。第五，与 P116（AgenticLU 探索澄清路径的树搜索）相比，一个探索问题分解、一个探索阅读顺序，二者都属于「用搜索换质量」，成本结构类似。

## 定位

TOA 与 P109（Chain-of-Agents）、P116（AgenticLU）、P134（RAM 的并行精读/略读）同属「多路径/多视角处理长上下文」路线；其差异在于显式利用树结构探索**阅读顺序**这一维度，针对的是位置偏置而非信息筛选。
