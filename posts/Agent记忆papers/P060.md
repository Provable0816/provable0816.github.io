# P060 Memory-Efficient Visual Autoregressive Modeling with Scale-Aware KV Cache Compression

- 会议/来源：NeurIPS 2025
- 方向簇：VLM
- 链接：/paper_files/paper/2025/hash/14550b451b65682b09f9080026d00a7e-Abstract-Conference.html

## 贡献

为视觉自回归（VAR）生成模型提出 ScaleKV：VAR 的 next-scale 预测按粗到细逐步细化，导致 KV cache 随尺度**指数增长**，成为显存与计算冗余的主要来源。ScaleKV 依据两条观察——不同 transformer 层对 cache 的需求不同、不同尺度上的注意力模式不同——把层划分为 drafter 与 refiner 两类，并按尺度做差异化的 cache 管理。

## 机制要点

Drafter 层的注意力**分散在多个尺度**上，需要更大的 cache 容量来维持跨尺度信息；Refiner 层则把注意力集中在当前 token map 上以处理局部细节，因此所需的 cache 容量可以大幅削减。基于这一功能划分，ScaleKV 在推理管线中识别每个尺度下的 drafter 与 refiner，为它们分配不同的预算，从而替代「所有层在各尺度上使用统一预算」的做法。

## 关键结果

在文本到图像 VAR 模型族 Infinity 上，KV cache 显存降至原来的 10%（Infinity-8B：85 GB → 8.5 GB，10× 缩减），同时保持像素级保真度：GenEval 分数维持 0.79，DPG 分数从 86.61 微降到 86.49。

## 局限与定位

第一，验证高度集中在单一模型族（Infinity）上；VAR 的层功能划分是否在不同规模、不同训练配方的 VAR 模型上一致，缺少证据，而「drafter/refiner」的判定本身依赖离线分析，换模型后是否需要重新分类未说明。第二，评价指标偏生成质量分数（GenEval、DPG），缺少对**细粒度可控生成**（文字渲染、精确空间关系、属性绑定）的压力测试——这类任务最依赖跨尺度信息，也最可能在削减 refiner 预算时退化。第三，10% 是「显存降至原来的十分之一」，但摘要未报告对应的生成延迟变化：显存下降不必然带来速度提升，尤其在注意力仍受访存带宽约束时。第四，与其它压缩路线（如 P046/P048 的量化、P047 的稀疏剪枝）正交，但叠加效果未知，也未讨论压缩对 VAR 迭代式生成中误差累积的影响——每次尺度细化都可能放大前一步的近似误差。

定位上，ScaleKV 是把「按功能分层分配 cache 预算」这一在 LLM 中已成熟的思路（见 P037、P058）迁移到 VAR 的分尺度生成范式，其价值在于指出 VAR 的冗余结构（粗到细 + 指数增长）与传统自回归完全不同，因此需要尺度感知而非层感知的预算分配。
