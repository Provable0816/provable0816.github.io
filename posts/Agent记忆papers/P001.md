## 一句话贡献

提出 Elastic-Cache：面向扩散大语言模型（DLM）的免训练、架构无关 KV 缓存自适应刷新策略——用「最受关注 token 的 KV 漂移」决定**何时**刷新，用「深度感知的边界层」决定刷新**到哪一层**，在 LLaDA / Dream 系列上把解码吞吐提升最高 45.1×，精度与全量重算基线持平或略高。

## 1. 问题与第一性原理动机

自回归解码之所以能缓存 KV，是因为因果掩码让已生成前缀的 $K,V$ 永久冻结：缓存只增不改。扩散 LLM（LLaDA 等）用双向注意力在 $T$ 个去噪步中反复预测全部 MASK 位置，于是每个 token 的 KV 都随其它位置被填实而改变，「前缀不变」这一前提彻底失效。既有做法（dLLM-Cache、Fast-dLLM 的置信度解码等）要么在固定间隔刷缓存，要么只改解码调度；固定周期意味着刷新频率与真实状态变化速率脱钩，浅层与深层的冗余差异也被忽略。因此问题的本质不是「要不要缓存」，而是：在状态持续可变的序列上，如何用可观测信号刻画状态变化的**速率**与**位置**。

## 2. 核心洞察

作者给出三条经验观察（Fig. 1）：(1) 远离预测窗口的 MASK token 主要充当长度偏置，可按块缓存复用；(2) KV 漂移随层深增大，故刷新只需从某个边界层 $\ell^\star$ 向深层做，浅层沿用旧缓存；(3) 当前步**最受关注**的 token 的 KV 漂移最小，可作为全体缓存 token 变化量的保守下界。第 3 条最关键：它把无法直接观测的整体误差，替换成一个极廉价的代理统计量，使「何时刷新」变成一次标量比较。若该代理关系成立，缓存刷新就从周期性问题变成自适应控制问题。

## 3. 方法机制

整体是免训练的两个决策。(a) **何时刷新**：每层取本步注意力最大的候选 token（文中 $T^{t,l}\leftarrow\arg\max_{k\in D_{<t}}P$），计算其 KV 漂移统计量，超过阈值 $\gamma$ 才触发全局刷新；漂移低于阈值说明 KV 状态稳定，重算纯属浪费。(b) **在哪刷新**：由边界层 $\ell^\star$ 起向深层重算，浅层直接复用；预测窗口外的 MASK token 按块复用而非逐 token 重算。代价是引入 $\gamma$、$\ell^\star$ 等超参，需要按模型/调度标定（Table 7 给出敏感性分析），并且漂移统计量本身有计算与同步开销（论文称其轻量，但未给出与总时延的占比分解）。

模型：LLaDA-Instruct、LLaDA-1.5、LLaDA-V、Dream-v0-Base-7B；基准：GSM8K、MATH、HumanEval、MBPP、MathVista/MathVerse；指标为精确率与 tokens/s。

## 5. 第一性原理再审视

方法成立依赖一个未被证明的单调性假设：最受关注 token 的漂移可作为全体 token 漂移的上界。Fig. 1d 只给出统计相关性，没有最坏情况界；一旦某个低注意力但内容关键的 token（答案中的常量、检索命中的实体）发生大漂移，而最受关注 token 恰好低于阈值，就会漏刷新并直接改变输出——这类失效模式在长链推理中最危险。

其次，「精度高于全量重算基线」值得警惕：78.01→78.24、43.90→46.34 这类差距落在采样噪声量级，更合理的解释是缓存近似本身起了正则/去噪作用，而非机制优越；论文未报告多种子方差或置信区间。第三，评估集中在答案短、可精确判分且以 5-shot 数学/代码为主的任务，对开放式长文本生成（缓存误差会随步数累积）与长上下文检索没有证据。第四，性能宣称（45.1×）来自单项设置，跨设置从 4.8× 到 45.1× 跨度极大，说明收益高度依赖序列长度与任务，平均收益未被汇总。

## 6. 与相邻工作的关系

与 dLLM-Cache（固定间隔刷新、训练无关）、Fast-dLLM（置信度驱动的并行解码）同属扩散 LLM 推理加速，差别在于把刷新时机从固定周期改成注意力可观测的漂移触发，并能按层选择性重算；在自回归一侧对应各类免训练自适应缓存更新，但 AR 侧前缀冻结、DLM 侧状态可变，因此本文的问题设定无法直接复用 AR 的自适应缓存结论。

## 7. 可迁移点与开放问题

可迁移的机制是「用最稳定的可观测量做保守触发器」：把难以观测的整体误差，替换成其下界的廉价的代理量。这一思路可移植到任何迭代式推理（迭代编辑、多轮 agent 状态缓存、扩散式视觉生成）。开放问题包括：能否给出漂移界的严格形式（如基于注意力熵或 KV 谱范数）而非经验下界；在需要精确长程召回的任务上是否失效；边界层 $\ell^\star$ 与阈值 $\gamma$ 能否由在线统计自动推断，避免逐模型标定。
