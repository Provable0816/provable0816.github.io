# P081 MMInference: Accelerating Pre-filling for Long-Context Visual Language Models via Modality-Aware Permutation Sparse Attention

- 会议/来源：ICML 2025
- 方向簇：VLM
- 链接：https://proceedings.mlr.press/v267/li25aq.html

## 贡献

针对长上下文多模态输入（长视频、高分辨率图像混合）的 **prefill 阶段**提出动态稀疏注意力 MMInference：分析发现视频的时空局部性导致一种独特的「Grid pattern」稀疏结构，且 VLM 在不同模态上的稀疏分布差异显著；据此用基于置换（permutation）的方法利用 Grid 结构、处理模态边界，离线为每个注意力头搜索最优稀疏模式，运行时按输入动态构造稀疏分布，并配套优化 GPU kernel。方法无需修改模型或微调即可接入现有 VLM 管线。

## 机制要点

与文本长上下文的稀疏结构不同，视频 token 的注意力具有二维（时间 × 空间）局部性，因此其可稀疏模式不是一维带状，而是网格状；同时文本段与视觉段的最优稀疏模式不同，跨越模态边界的注意力需要特殊处理——这正是「modality-aware」与「permutation」两步的目的：先重排 token 使稀疏结构规整化，再按头选择模式。任何一步做错，稀疏化都会在边界处产生系统性遗漏。

## 关键结果

在 Video QA、Captioning、Vision-NIAH、Mixed-Modality-NIAH 等基准上，用 LongVila、Llava-Video、VideoChat-Flash、Qwen2.5-VL 等长上下文 VLM 评测：1M token 输入下 prefill 阶段最高加速 **8.3×**，同时保持准确率。代码开源。

## 局限与定位

第一，论文明确只加速 **prefill**，而长视频问答的解码阶段同样有成本（尤其在多轮追问时），整体端到端收益会小于 8.3×；读者需区分阶段收益与端到端收益。第二，「保持准确率」需要按模态边界敏感的任务核验——Mixed-Modality-NIAH 的纳入是正确的方向，但跨模态检索（例如「视频里出现的文字说了什么」）最依赖边界处的注意力，是否被置换与稀疏化破坏值得细看。第三，逐头离线搜索稀疏模式引入一次成本，且换模型/换分辨率后模式是否需要重搜未说明。第四，8.3× 是在 1M token 的极端输入上取得，短输入或多图中等长度的收益曲线缺失，而后者才是多数部署场景。定位上，MMInference 与 P029（VideoChat-Flash 的层级 token 压缩）不同——前者不改 token 数只稀疏化注意力，后者压缩 token 本身，二者可叠加。
