# P192 If Attention Serves as a Cognitive Model of Human Memory Retrieval, What is the Plausible Memory Representation?

- 会议/来源：ACL 2025（主会）
- 方向簇：ARCH
- 链接：https://aclanthology.org/2025.acl-long.483/
- 本地全文：cache/txt/P192.txt

## 贡献

把「注意力 ≈ 人类记忆检索」这一计算心理语言学假设推向**表示层面**：此前的验证都基于 token 级表示（vanilla Transformer），本文改用**以句法结构为表示单位**的 Transformer Grammar（TG），并借用归一化注意力熵（NAE）作为模型与人类之间的链接假说，检验哪种记忆表示更能预测人类的自定步速阅读时间。

## 机制要点

TG 的注意力掩码由 COMPOSE/STACK 两种算子构成（Figure 1）：COMPOSE 生成已闭合成分的向量表示，STACK 维护未闭合结构，因此注意力作用在结构单元而非 token 上。把 NAE 从 TG 迁移到人类数据需要两个明确假设（论文第 3 节列出）：(1) 给定 token 序列应假设何种句法结构（论文采用**全局正确的句法分析**）；(2) 非词汇符号（`(X`、`X)`）的认知负荷如何归因到词汇 token 上。这两个假设本身即核心可争议点——它把「结构表示的优势」与「分析正确性」的依赖绑在了一起。

## 关键结果

Table 1 报告 TG 与 Transformer 的 NAE 对阅读时间预测的贡献（∆LogLik、每标准差效应量、跨随机种子的 p 值范围与显著种子数）：Transformer 的 NAE 在控制 surprisal 等基线后仍有显著预测力（效应为正，NAE 越高阅读越慢），复现了既有结论；而 TG 的 NAE 预测力**更强**。Figure 2 的似然比检验表明两者贡献**互相独立**——句法结构携带了 token 级表示未覆盖的信息，而不是同一种信号的两种测法。Figure 3 按词性给出两模型的 ∆RMSE 差异，显示 TG 的优势集中在特定词类上。

## 局限与定位

第一，实验依赖**全局正确的句法分析**，等于把黄金树结构当输入；人类处理中的「花园路径」现象恰说明结构本身是在线推断的，因此该设定高估了结构表示在真实处理中的可用性。第二，模型的 NAE 与人类阅读时间之间的关联是**相关而非因果**，且阅读时间变异有大量非记忆因素（词频、可预测性、眼动策略）。第三，这是一篇认知建模工作，其价值在于「记忆单位的选择」这一洞察——若要以结构单元（子树、话语单元）而非 token 作为记忆压缩的单位，其检索代价与压缩收益需另行评估。定位上，它为本方向「压缩粒度应匹配语义单位」的主张（见 P172、P173）提供了来自认知科学的间接支持。
