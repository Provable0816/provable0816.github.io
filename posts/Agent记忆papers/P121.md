# P121 Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for Large Language Model Agents

- 会议/来源：ACL 2026（主会）
- 方向簇：AGENT
- 链接：/2026.acl-long.981/
- 本地全文：cache/txt/P121.txt

## 一句话贡献

提出 Agentic Memory（AgeMem）：把长期记忆（LTM）与短期记忆（STM）的管理**直接并入 agent 的策略**，而不是当作两个独立模块。做法是把记忆操作暴露为**工具化动作**（存储、检索、更新、摘要、丢弃），让 LLM agent 自主决定存什么、何时存、何时取、何时弃；为训练这种统一行为，提出三阶段渐进式强化学习，并设计 **step-wise GRPO** 来应对记忆操作带来的稀疏且不连续（discontinuous）的奖励。在五个长时程基准上持续优于强记忆增强基线。

## 1. 问题与第一性原理动机

论文的诊断很准确：既有方法把 LTM 与 STM **分开处理**，并依赖启发式规则或额外的辅助控制器。这带来两个结构性限制：其一，长期与短期的取舍本质上是同一个决策的两面（把信息放进长期记忆意味着它暂时离开工作上下文，保留在短期则占用即时预算），分开管理无法表达这种权衡，只能靠外部规则拼合；其二，辅助控制器位于策略之外，无法与 agent 的最终目标端到端联合优化，因此其行为永远是次优的近似。把两者统一进策略，等于承认「记忆管理就是 agent 行为的一部分」。

## 2. 核心洞察

洞察是**记忆管理的动作空间应当与工具使用同构**。若把 store/retrieve/update/summarize/discard 定义为工具，那么 agent 就天然具备「用 RL 学习何时调用哪个工具」的机制，也就能复用工具学习的一整套方法（P023 的 MemAgent、P025 的 ReMemR1 分别用 RL 学习记忆覆写与回调，属于同一范式的两种形态）。第二层洞察针对训练难点：记忆操作的后果往往**延迟且不连续**——存下一条信息可能很久之后才有用，丢弃一条信息也可能当时无碍而后造成失败。这使标准的序列级奖励方法失效，因此需要 step-wise 的组相对优化来把信用分配到具体操作上，这与 P025 用「多层级奖励 + 逐步密集信号」解决同一问题殊途同归。

## 3. 方法机制

(1) 把 LTM/STM 操作统一为工具动作集；(2) agent 在交互中自主调用这些工具；(3) 用三阶段渐进式 RL 训练（由易到难逐步引入记忆操作）；(4) 用 step-wise GRPO 处理稀疏与不连续的奖励。代价是：动作空间变大导致探索困难（这正是需要渐进式训练的原因）；工具调用引入额外推理开销；RL 训练本身需要大量交互样本与稳定的奖励设计；记忆操作的奖励若设计不当，可能诱导「为了拿奖励而过度操作」。

## 4. 实验证据

在五个长时程（long-horizon）基准上，AgeMem 一致优于强记忆增强基线，说明统一管理带来的收益具有跨任务稳健性。具体指标与基线集合需回看正文；三阶段 RL 与 step-wise GRPO 各自的贡献应通过消融确认。

## 5. 第一性原理再审视

第一，「统一进策略」的好处明确，但代价是**训练复杂度显著上升**：把记忆管理交给 RL，意味着系统对奖励设计与训练稳定性高度敏感，而记忆的收益往往延迟显现（一条信息是否值得存，要等到很久以后才知道），这类长延迟信用分配是 RL 的经典难点；论文用 step-wise GRPO 缓解，但仍需给出训练过程的稳定性证据（如不同随机种子的方差）。第二，与启发式方法相比，RL 方案的可解释性与可调试性下降：当 agent 丢弃了关键信息时，很难判断是策略错误还是奖励设计缺陷。第三，五个基准若以检索/问答为主，则未覆盖「写入时机」最难的一类场景——查询后置（先读后问，参见 P023 的同类批评）。第四，效率上，工具化记忆操作意味着额外的模型调用；论文需要给出相对启发式方法的延迟与 token 成本，否则「统一管理」的收益可能被开销抵消。第五，与 P026（MemGAS 用熵路由）、P114（RMM 用反思 + 在线 RL）相比，AgeMem 把更多决策交给策略，属于这一谱系中最「端到端」的一端。

## 6. 与相邻工作的关系

与 P023（MemAgent 用 RL 学习覆盖率记忆的读写）在范式上最接近，差别是 AgeMem 的动作空间覆盖 LTM/STM 并显式包含 update/summarize/discard 等操作；与 P025（ReMemR1 用 RL + 密集奖励训练记忆回调）共享「用密集信号解决稀疏奖励」的技术路线；与 P114（RMM 的前瞻写入 + 回溯 RL 修正）相比，RMM 的写入由摘要机制完成、检索由 RL 优化，AgeMem 则把两者都交给策略；与 P026（多粒度 + 熵路由）代表「结构化 + 启发式」路线，与本工作构成对照。定位上属于「记忆管理即 agent 策略」这一端到端路线的最新代表之一。

## 7. 可迁移点与开放问题

可迁移：(a) 「把资源管理操作暴露为工具并交给策略学习」是可复用的范式，适用于上下文预算、工具调用预算、计算预算管理；(b) 处理延迟且不连续奖励的 step-wise 组相对优化，可用于任何「操作后果滞后」的 agent 训练。开放问题：训练稳定性与样本效率；相对启发式方法的成本/收益比；查询后置场景下的写入策略；奖励设计的鲁棒性；以及记忆操作的可审计性与用户可干预性（企业场景常见需求）。
