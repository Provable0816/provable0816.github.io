# P196 Memory Dial: A Training Framework for Controllable Memorization in Language Models

## 贡献

把「记忆」从被事后探测的现象变成**训练时可控的自变量**：用一个系数 $\alpha$ 在标准交叉熵 $L_{\text{std}}$ 与温度锐化目标 $L_{\text{mem}}$ 之间插值，得到一组架构与训练设置完全相同、仅记忆压力不同的模型族，从而把记忆效应从架构、数据与优化中解耦出来。

## 机制要点

框架见 Figure 1：$\alpha$ 增大时，对**已见**样本（训练中注入）的输出从高熵的泛化分布平滑过渡到确定性复述；对未见样本则保持泛化行为。实验流水线（Figure 2）分三相：把评测集切成 seen/unseen → 用 Memory Dial 目标训练一族模型 → 逐 $\alpha$ 测量记忆与泛化的变化。之所以需要「温度锐化」而非单纯加大训练轮数，是因为单一温度基线无法复现该效应（论文在结论中明确把这一点列为消融结论）。

## 关键结果

Table 1 报告六种架构 × 五个基准共 **30 组「已见样本准确率对 $\alpha$ 的斜率」全部为正**，即 $\alpha$ 可靠且单调地控制记忆压力；Figure 3 显示**模型越大对记忆压力的响应越强**（平均斜率随参数量上升）；Table 2 显示 seen–unseen 的 token 级困惑度差随 $\alpha$ 减小（记忆增强了已见样本的确定性）。结论部分另列多项鲁棒性检验：效应在不同 $\tau$ 下稳健、不能被单一温度基线复现、可推广到自然出现的单次出现序列、并在更长训练日程（2000 步，Figure 10）下持续存在而非衰退反转。

## 局限与定位

第一，结论建立在**评测集与训练集受控重叠**上，与真实预训练中「语料自然重复导致记忆」的机制未必同构；虽有一项单次出现序列的检验，仍属初步。第二，$\alpha$ 控制的是「记忆压力」这一整体标量，而模型在什么内容上优先记忆（论文给出高频序列在更弱压力下即被记住）才是更细的维度，当前框架只能观察而不能按内容类型定向控制。第三，与压缩方向的关系是**诊断性的**：它提供了「记忆容量/压力」这一可调旋钮及其与泛化的权衡曲线，可作为评估任何记忆压缩方法「是否伤到必要记忆」的标尺。定位上属于模型记忆机理研究，不提出记忆压缩方法。
