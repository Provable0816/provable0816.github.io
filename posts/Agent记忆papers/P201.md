# P201 Beyond Speedup — Utilizing KV Cache for Sampling and Reasoning（KV-Embedding）

- 会议/来源：ICLR 2026（主会）
- 方向簇：KV
- 链接：https://openreview.net/forum?id=d147f24cac1b6cd88753ca830e462bdc
- 本地全文：cache/txt/P201.txt

## 贡献

提出「把 KV cache 当作一种**免费的轻量表示**」：既然它在正常推理中已被计算出来，就无需再为下游任务重算或存储完整 hidden state。论文验证了两个应用——KV-CoE（Chain-of-Embedding，用它做推理路径的自我评估）与 KVClassifier（快/慢思考切换），在 Llama-3.1-8B-Instruct、Qwen2-7B-Instruct、Qwen3-8B、DeepSeek-R1-Distill-Qwen-14B 上取得有竞争力的效果，并使 token 生成量最多减少 5.7×。

## 机制要点

框架见 Figure 2：(a) KV-CoE 把各层 KV 聚合为嵌入用于自评估（判断当前推理路径是否正确）；(b) KVClassifier 依据 KV 表示动态决定「快思考（直接答）」还是「慢思考（展开推理）」。动机是成本结构：Figure 1 对比 Qwen3-32B 的「模型 + KV cache」与「模型 + 逐层 hidden state」显存占用，说明后者在长上下文下远超前者。Table 1 给出 KV 派生嵌入与专用嵌入模型在 MTEB 分类任务上的对照——结论是 KV 嵌入**明显弱于**训练好的嵌入，但仍保留可用的语义。这是一个诚实的负面基准，也界定了方法的能力上界。

## 关键结果

Table 2 在 MATH、TheoremQA 上比较 KV-CoE 与其他自评估信号（MaxProb、PPL、Entropy）的 AUROC 与 FPR95，KV-CoE 一致提升；Table 10 给出 GSM8K/MATH500 上 DeepSeek-R1-14B 与 Qwen3-8B 在 KV-Classification 与 KV-Generative 设置下的精度/token 数（如 Fast Thinking 0.845/218 vs Reasoning 0.847/432 量级的对照），并给出超参选择规律：层深与 token 覆盖的分配会影响收益，增加 token 覆盖（如 $2L\times128$）更利于 MATH500 这类难题，浅而宽（$8L\times32$）足以应付 GSM8K。附录另报告 KV-CoE-R/-C 的逐层结果。

## 局限与定位

第一，KV 嵌入弱于专用嵌入是**结构性**的：KV 是为「被后续 token attend」而训练的中间量，不是为语义相似度检索设计的，因此把它用于分类/评估属于次优复用；论文的价值在于证明「次优但免费」在成本敏感的决策场景中已经够用。第二，「减少 token 生成 5.7×」的代价是**精度损失**（论文表述为 minimal accuracy loss），但自适应切换的**误判代价不对称**（该慢却快=答错，该快却慢=浪费算力），正确性证据需要按错误类型分解。第三，超参规律（层深 vs token 覆盖）依赖任务，说明该方法的部署需要按任务调优。定位上，它属于「记忆复用」而非压缩：不缩小 KV，而是把它二次利用，与本方向中 P186（子图 KV 复用）、P204（跨模型 KV 复用）同属「KV 作为可复用资产」的一支，但复用对象是**表示语义**而非计算。
