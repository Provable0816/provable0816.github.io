# P077 RocketKV: Accelerating Long-Context LLM Inference via Two-Stage KV Cache Compression

- 会议/来源：ICML 2025（主会）
- 方向簇：KV
- 链接：https://proceedings.mlr.press/v267/behnam25a.html
- 本地全文：cache/txt/P077.txt

## 一句话贡献

提出两阶段免训练 KV 压缩：第一阶段对输入序列 token 做**粗粒度永久淘汰**，第二阶段用混合稀疏注意力做**细粒度 top-k 选择**，其中注意力分数通过同时沿头维度与序列维度降维来近似；在 A100 上相对全量 KV 基线取得最高 400× 压缩、3.7× 端到端加速、解码阶段峰值显存降低最多 32.6%，长上下文任务精度损失可忽略，并给出面向多轮场景的变体，精度接近 oracle top-k。

## 1. 问题与第一性原理动机

解码阶段受**显存带宽与容量双重约束**：cache 随输入线性增长，每步又需把它读进来。论文把压缩分为两种性质不同的操作——「永久淘汰」（减少常驻容量）与「动态 top-k」（减少每步搬运量）——并指出单用其一都有缺陷：只淘汰则容量降但每步仍需读全部剩余 cache；只做稀疏注意力则每步读得少但显存仍被完整 cache 占满。两阶段分工正好对应两类硬件瓶颈，这是方法论上清晰的一步。

## 2. 核心洞察

洞察在于**近似注意力分数的计算成本可以被压到很低**：通过对头维度与序列维度同时降维，可以在远低于精确注意力的代价下估计出哪些 token 值得被细粒度保留。这使「动态选择」不再需要付出与完整注意力相当的代价——而这个代价正是许多稀疏注意力方法在实际部署中失败的原因。第二个洞察针对多轮场景：多轮对话中历史不断变化，静态淘汰策略会系统性丢失后轮需要的信息，因此需要专门的变体，论文称其接近 oracle top-k 的水平。

## 3. 方法机制

(1) 第一阶段：在输入 token 上做粗粒度永久淘汰，确定常驻 cache 的上限；(2) 第二阶段：用头/序列双维度降维近似注意力分数，做细粒度 top-k 稀疏注意力。方法免训练，两个阶段的阈值/预算构成调参面。代价是：第一阶段不可逆，误删无法补救；双维度降维是近似，估计误差会传递到选择质量；两阶段联合调优的最佳点依赖任务与长度。

## 4. 实验证据

关键数字：最高 400× 压缩、最高 3.7× 端到端加速、解码峰值显存降低最多 32.6%（相对全量 KV 基线，NVIDIA A100），长上下文任务精度损失可忽略；多轮变体优于既有方法并接近 oracle top-k。代码开源（NVlabs/RocketKV）。

## 5. 第一性原理再审视

第一，400× 与 32.6% 这两个数字放在一起需要解释：压缩比是相对「KV cache 的逻辑大小」，而峰值显存只降三成，说明显存瓶颈并不只来自 KV（权重要占用、激活也占用）；读者若只记住 400× 会严重高估实际收益，这也是当前 KV 压缩文献普遍存在的口径问题。第二，「精度损失可忽略」应给出逐任务细节，尤其计数与多针检索；两阶段中第一阶段的永久淘汰是最危险的环节，论文需要给出淘汰预算的敏感性曲线。第三，双维度降维近似注意力的思路与 P053（非线性哈希检索）、P062（低秩代理打分）同属「廉价近似 + 精确计算」，其共同风险是近似排序误差在需要精确检索的任务上放大；论文缺少这类专项评测。第四，多轮变体接近 oracle top-k 是强结论，但「oracle top-k」本身是以全注意力排序为参照——若全注意力在该任务上并非最优，则这个参照的意义有限。

## 6. 与相邻工作的关系

与 P042（KEYDIFF，块式推理 + 纯 key 相似度淘汰）都强调在严格资源约束下的淘汰，但 KEYDIFF 完全不依赖注意力分数，RocketKV 用降维近似注意力；与 P045（KVzip，查询无关压缩）相比，RocketKV 仍是查询相关的；与 P051/P062 同属「近似检索 + 精确注意力」范式；与 P078（ShadowKV）在系统层面互为对照——后者把 value 卸载到 CPU 并用低秩存 key，前者在 GPU 内做两阶段压缩。定位上属于系统导向的两阶段压缩方案。

## 7. 可迁移点与开放问题

可迁移：(a) 「把压缩拆成减少容量与减少搬运量两类操作，分别对应两种硬件瓶颈」这一分析框架，可直接用于分析其它系统的优化空间；(b) 用多维降维来廉价近似打分，是降低选择开销的通用手法。开放问题：第一阶段淘汰的敏感性与最坏情况损失；精确检索类任务上的表现；400× 与 32.6% 之间的差距所揭示的显存构成；多轮场景下静态淘汰的长期影响；以及与量化方法的叠加。
