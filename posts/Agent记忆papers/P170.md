# P170 CMT: A Memory Compression Method for Continual Knowledge Learning of Large Language Models

## 一句话贡献

把「持续知识更新」从参数空间搬到潜在空间的**记忆库**：新文档被 compressor 压成稠密向量存入 bank，回答问题时用 cross-attention 聚合这些向量并与问题一起送入 LLM；主干参数在训练与推理中都不变，因此用「不写入参数」换取抗灾难性遗忘，并配三个技巧（memory-aware objective、self-matching、top-k aggregation）。

## 1. 问题与第一性原理动机

LLM 的知识被冻结在训练时刻，而世界在变；重训一次 GPT-3 级别模型的代价（论文引用的量级是数千 GPU·天）使「频繁重训」在经济上不成立。真正的矛盾不在算力，而在**写入位置的选择**：参数是分布式共享存储，新知识写进去必然与旧知识竞争同一位；而外部存储（检索、memory bank）容量可扩展、写入局部化，代价是每次都要把「何时检索、检索什么、如何融合」建模对。因此问题被重构为：能否把「更新」实现为**对记忆库的增删**，而不是对权重的扰动？论文明确设定在更新阶段看不到测试查询 $Q_{test}$，只能借助同分布的 $D_{train},Q_{train},Y_{train}$ 学习「什么样的查询会被问到」——这一约束才是本方法的设计起点：记忆必须按**潜在查询分布**组织，而不能按已知问题定制。

## 2. 核心洞察

受人类记忆三阶段（Figure 1：encoding → storage → 聚合/检索）启发，论文假设：文档的「可复用知识」可以被压进一个**与查询无关**的稠密向量，而检索时再按查询做加权聚合。于是 compressor 学的是「把文档压成未来可能被问到的信息」，aggregator 学的是「按当前问题从 bank 里取哪些记忆」。这个分解的价值在于把「知识保持」与「知识取用」解耦：前者只增不改（保护旧能力），后者每次重新计算（保持灵活性）。

## 3. 方法机制

(1) **Compressor**：对每篇待学习文档 $D_i$ 输出一个稠密记忆向量 $M_i$，所有向量构成 bank $\{M_1,\dots,M_{|D|}\}$；(2) **Cross-attention 聚合**：问题作为 query 对 bank 做注意力，得到加权记忆并拼入模型输入做生成；(3) **Memory-aware objective**：训练目标不是重建文档，而是**下游问答准确率**（Figure 2 的刻画是「训练目标是 downstream 的精确度」），使压缩方向由任务信号而非重构误差决定；(4) **Self-matching + top-k aggregation**：用自匹配抑制噪声记忆，只聚合与问题最相关的 top-$k$ 条。代价是：记忆库随文档流线性增长（压缩率体现在「每篇一文向量」，而非「总量有界」），且整个管线需要额外的训练阶段与配套的训练语料。

## 4. 实验证据

模型覆盖 DistilGPT2 / GPT2-Large / GPT2-XL / Llama-2-7b（Table 1 与 Table 2），数据集为持续学习三件套 StreamingQA、SQuAD、ArchivalQA。主结果（Table 2）：CMT 在 StreamingQA 取得 EM 18.36 / F1 25.98，SQuAD 19.54 / 25.50，ArchivalQA 21.73 / 25.40；摘要报告的相对增益为 Llama-2-7b 上 StreamingQA +4.07 EM / +4.19 F1。Table 1 显示在 StreamingQA 上，不使用记忆的 Uniform 基线（Llama-2）仅为 EM 12.43 / F1 13.54，说明增益主要来自「外部记忆」而非某个训练技巧。消融（Table 2）：去掉 memory-aware objective 后 StreamingQA F1 从 25.98 降到 23.71，是三组件里影响最大的一项，说明「以任务精度为目标」确实是该框架成立的关键——如果改为重构目标，记忆向量会偏向可重建但未必可用的方向。

**证据缺口**：(a) 记忆库随文档流增长，论文未给出「库规模—精度」的边际曲线，也没有给出库规模的可扩展上限，读者无法判断它在真正的长时程（百万文档）下是否仍可用；(b) 评测以 EM/F1 为主，缺少延迟/显存随 bank 增长的实测；(c) 「参数不变 → 抗遗忘」是设计推论，Figure 3 给出了知识保持分析，但缺乏与「参数更新类方法」在**同等新知识获取量**下的对照。

## 5. 第一性原理再审视

该框架成立的前提是：不存在测试查询的先验时，也能学到「值得存什么」。这是一个**归纳偏置假设**——它成立当且仅当训练阶段的查询分布 $Q_{train}$ 与在线阶段的 $Q_{test}$ 足够接近；一旦分布漂移（新领域、新任务类型），compressor 会把整篇文档压向旧任务在意的那一面，形成系统性盲区。其次，cross-attention 聚合隐含「记忆条目彼此独立可加」假设；当新旧文档互相矛盾时（知识更新场景中最常见的情形），top-$k$ 聚合可能同时取到互相冲突的记忆而没有任何冲突消解机制，论文对该场景只有「无关文档干扰」的鲁棒性实验（Figure 4 用合成无关文档），并未覆盖**矛盾文档**。第三，从信息论看，「每篇一文向量」是一种固定速率的有损编码，其成功取决于文档内部冗余；对于标识符密集的文档，压缩必然丢信息，而论文未做按冗余度分层的误差分析。

## 6. 与相邻工作的关系

与参数级编辑（knowledge editing、LoRA 增量微调）的根本区别是**写入位置**：后者改权重，CMT 只增记忆。与 MemoryLLM / Memory3 这类「模型内置记忆」相比，CMT 的记忆完全外置且可按需聚合，更接近检索增强；与 ICAE / AutoCompressor / Gisting 等压缩式方法相比，后者压缩的是「当前上下文」，CMT 压缩的是「需要长期保有的新知识」，目标从 token 缩减变成知识保持。与 RAG 的差别在于它把「压缩—存储—检索」整体纳入一个端到端训练目标。

## 7. 可迁移点与开放问题

可迁移的是**任务信号驱动的压缩目标**（memory-aware objective）：它可以直接套用到任何「先把信息压成向量再供后续使用」的系统（多轮 agent 记忆、RAG 的段落编码、跨会话个性化），训练时用下游指标而不是重构误差，是让压缩保真的通用手段。开放问题：记忆库的规模控制与淘汰策略；矛盾文档的冲突消解；查询分布漂移下的鲁棒性；以及「不写参数」是否意味着模型无法真正获得新技能（只获得新事实）。
