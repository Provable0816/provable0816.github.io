# P189 AMS-KV: Adaptive KV Caching in Multi-Scale Visual Autoregressive Transformers

- 会议/来源：AAAI 2026（主会）
- 方向簇：VLM
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/39936
- 本地全文：cache/txt/P189.txt

## 贡献

系统研究「下一尺度预测（next-scale prediction）」式视觉自回归模型（VAR）的 KV 缓存问题，并给出尺度自适应缓存策略 AMS-KV：优先保留**最粗尺度（condensed scales）**与**局部尺度**的 KV，并通过层间跨尺度相似度识别「缓存需求高」的层，从而在有限显存下稳住多尺度图像生成质量。

## 机制要点

三条经验观察（论文摘要明确列出）：(1) 关注**局部尺度**的 token 对生成质量贡献显著；(2) 为**最粗尺度**分配少量内存即可稳定多尺度生成（论文称之为 condensed scales）；(3) 「缓存高效」的层表现出更强的跨尺度 KV 相似性，而缓存需求高的层跨尺度相似性弱。第 (3) 条是关键：它把「层间预算分配」的判据从语言模型里常用的注意力稀疏度换成了**跨尺度相似度**，属于该范式特有的结构信号。整体框架见 Figure 2；Figure 3(a) 给出注意力图随尺度的增长，Figure 3(b) 给出 VAR 在 A100-80G（batch 50）上随尺度的显存增长曲线；Figure 4 可视化生成最后尺度 $r_{10}$ 时各头与各尺度的注意力密度；Table 1 通过「移除不同尺度 KV」的对照实验量化各尺度的重要性。

## 关键结果

模型为预训练的 VAR-d30、VAR-d36 与 Infinity-2B；评测对象包括 256×256（VAR-d30）与 1024×1024（Infinity-2B）图像生成质量（Figure 1 给出样例），并报告显存与效率。核心主张是：在显著压缩 KV 的前提下质量不降，优于直接把 LLM 的缓存策略（如 H2O、KIVI）套用到 VAR 的做法。

## 局限与定位

第一，观察 (2)「粗尺度少量内存即可稳定生成」解释为尺度间语义层级，但未给出理论上限——多少粗尺度 token 是必要的？缺失这一量化会导致策略在不同分辨率下失效。第二，评测以生成质量指标（FID 类或视觉质量）为主，缺少对「尺度间一致性与语义可控性」这类结构性指标的验证，而 VAR 的主要风险恰在于跨尺度不一致。第三，VAR 的 KV 语义与 LLM 的 KV 不同（尺度序列而非 token 序列），结论不可直接外推。定位上，它与 P190（HACK，按头类型分配预算）共同构成 VAR 缓存的两种互补切分（按尺度 vs 按头），是本方向在**视觉生成**分支上的新增长点。
