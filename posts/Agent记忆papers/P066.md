# P066 CateKV: On Sequential Consistency for Long-Context LLM Inference Acceleration

- 会议/来源：ICML 2025（主会）
- 方向簇：KV
- 链接：https://proceedings.mlr.press/v267/jiang25e.html
- 本地全文：cache/txt/P066.txt

## 一句话贡献

发现注意力头可以按「注意力模式的时序一致性」分成两类——部分头在解码过程中注意力分布**持续稳定**（可在预填充阶段用变异系数算法可靠识别），另一些头则随查询动态变化；据此提出混合 KV cache 方案 CateKV：对一致头只保留关键 token 信息以省显存与计算，对自适应头保留大部分 KV 对以保精度，在保持全注意力水平精度的同时把显存降低最多 2.72×、单样本解码加速 2.18×、批处理吞吐提升 3.96×。

## 1. 问题与第一性原理动机

KV 淘汰方法普遍面临一个两难：淘汰得狠则精度掉，淘汰得少则省不下多少显存。既有解法（SnapKV、H2O、Ada-KV）都在「如何更准地打分」上做文章，但都默认**所有注意力头应当用同一套压缩策略**。论文的观察指向一个被忽略的结构差异：某些头的注意力分布在整个解码过程中形状稳定，对它们保留大量 token 是浪费；另一些头的注意力随生成内容大幅漂移（P052 把这一现象命名为 saliency shift），对它们激进压缩会直接破坏输出。也就是说，压缩的最优强度本身就是**头异质**的，用统一策略必然在其中一类头上犯错。

## 2. 核心洞察

关键洞察是：头的类型可以**在预填充阶段被提前判别**，而不必等到解码结束。论文用变异系数（coefficient of variation）构造判别算法，据称能够稳健地持续识别出一致头。这一可识别性带来两点价值：(1) 判别可以离线/预填充时完成，不增加解码期的决策开销；(2) 分类结果可用于路由完全不同的压缩策略——一致头走「只留关键 token」的激进路线，自适应头走「保留大部分 KV」的保守路线。相比按重要性打分再统一裁剪，这种「先分类、再分策略」的分工在原理上把有限预算分配给了最需要的头。

## 3. 方法机制

(1) 预填充阶段计算各头的注意力变异系数，识别出一致头与自适应头；(2) 对一致头仅保留关键 KV 对（依赖一个关键性判据），对自适应头保留绝大多数 KV 对；(3) 解码时按各头的保留集合进行注意力计算。图 1 直观对比了三种做法的差异：KV 淘汰（对所有头裁剪）、KV 检索（每步取回）、以及 CateKV 的混合路由。代价是：分类阈值由变异系数界定，属新的超参；一致头内部仍需一个「关键 token」判据，该判据的误差会被激进压缩放大；混合结构使实现比统一策略复杂。

## 4. 实验证据

论文在长上下文基准上评测，报告在保持与全注意力可比精度的同时，显存最多降低 2.72×、单样本解码加速 2.18×、批处理吞吐提升 3.96×；并说明该方法与既有加速方法的扩展组合特性。具体基准集合、模型与预算档位需回看正文表格。

## 5. 第一性原理再审视

第一，**分类是否稳定跨任务**是整套方法的地基：变异系数是在某个上下文（或某批样本）上测得的统计量，而头的一致性可能依赖输入类型（代码 vs 叙事文 vs 数字推理）。若分类在换域后漂移，就会把本应保守处理的自适应头误判为一致头并激进压缩，产生难以诊断的失败。论文应给出跨任务的分类一致性证据与误分类的代价曲线。第二，「一致头只留关键 KV」这一句式把问题从「留多少」转移到了「留哪些」，而关键性判据若仍基于注意力统计，就回到了它想绕开的问题；若基于其它信号，需要说明其依据。第三，2.72×/2.18×/3.96× 三个数字对应三种不同场景（显存、单样本解码、批处理吞吐），不宜合并理解；其中批处理吞吐的 3.96× 与实际 serving 的调度策略强相关，可迁移性需核实。第四，与 P037（Ada-KV 的头间预算分配）存在理念重叠——两者都主张按头差异化处理，区别是一个分配「预算」、一个分配「策略类别」；论文需要说明在 Ada-KV 基础上再做头分类能否带来额外增益，否则可能只是同一思想的另一种表述。

## 6. 与相邻工作的关系

与 SnapKV/H2O（统一策略淘汰）形成直接对照，主张按头分类路由策略；与 P037（头间预算分配）最接近但粒度不同：Ada-KV 连续地分配预算，CateKV 离散地把头分成两类并采用性质不同的策略；与 P052（SmallKV，指出 saliency shift 并用小模型补偿）关注同一现象的两端——P052 用外部信号补救漂移，本文用分类规避漂移大的头；与 P045（查询无关压缩）相比，CateKV 仍依赖查询相关统计，属于面向单次推理的加速而非可复用压缩。

## 7. 可迁移点与开放问题

可迁移：(a) 「先按结构性质给组件分类，再给不同类别配置不同强度的压缩」这一范式可直接用于 MoE 专家、不同层、不同模态分支的资源分配；(b) 用变异系数这类**免训练的稳定性统计量**做在线判别的做法，成本极低，适合需要快速路由的场景。开放问题：头分类跨任务/跨模型的稳定性；一致头内关键 token 判据的设计；分类阈值的敏感性；与头间预算分配方法叠加是否仍有增益；以及在长思维链场景下注意力漂移加剧时分类是否失效。
