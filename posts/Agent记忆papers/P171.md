# P171 CSR: Achieving 1 Bit Key-Value Cache via Sparse Representation

- 会议/来源：AAAI 2025（主会）
- 方向簇：KV
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/34779
- 本地全文：cache/txt/P171.txt

## 一句话贡献

把 KV cache 从「稠密张量」改写成「稀疏索引 + 稀疏系数」：用一组可学习的字典（NeuralDict）对 key/value 向量做稀疏表示，使每通道可低至 1 bit 仍保持可用精度，从而绕开量化方法在 2 bit 以下的失稳区。

## 1. 问题与第一性原理动机

KV cache 随序列长度 $O(L)$ 线性增长，是长上下文 serving 的显存瓶颈。压缩有两条正交路径：**减少元素个数**（eviction）与**降低每元素位宽**（量化）。量化在 2 bit 附近出现结构性墙：位宽越低，per-block 的 scale/zero-point 常数所占的相对开销越大，且低比特均匀量化对离群通道的分辨率骤降。论文的出发点是：如果向量本身**近似位于一个低维字典张成的稀疏组合**上，那么存储的就不必是坐标值，而可以是「用哪些字典原子、系数多大」——这在数学上等价于把「量化」换成「稀疏编码」，后者的码率可以突破均匀量化的下界。

## 2. 核心洞察

作者给出两条经验观察作为依据（Figure 2、Figure 3）：(1) 不同 prompt 之间 key 的分布几乎一致（$X_K$ 的分布在 prompt 间近似相同），而 value 在浅层的空间重叠明显、深层出现分化；(2) 用 JS 散度度量不同层 $X_{K,V}$ 分布差异，发现层间分布相似性有规律。含义是：**存在跨 prompt、跨层可复用的结构**，因此一份离线学得的字典可以服务整个推理过程——这是「共享字典 + 稀疏系数」能成立的前提，也是它与 per-token 自适应量化最本质的区别。

## 3. 方法机制

框架（Figure 1）：离线用 NeuralDict（一个神经网络）自动生成字典 $\Phi$；在线把每层的 $K/V$ 向量分解为稀疏索引与对应权重，即 $x \approx \Phi s$，只存 $s$ 的非零项及其位置。由于字典是稠密常数（离线训练、所有 token 共享），存储成本只落在稀疏系数上，等效位宽因此可压到极低——论文给出换算式：**CSR-8 等价于 2 bit 量化，CSR-16 等价于 4 bit**。代价有三：字典需要离线校准与训练（论文 Limitations 明确承认这一步「time-consuming」）；稀疏编码需要额外的解码计算；字典质量决定上限，分布外输入会退化。

## 4. 实验证据

模型覆盖 Llama2-7B-chat（MHA）、Llama3-8B-Instruct（GQA）、Baichuan2-7B-chat（MHA），基准为 LongBench。结果（Table 1、Table 2）：在**相同比特数**下与量化方法对比，CSR 在多数任务上占优；摘要与结论声称在 <2 bit 区间仍稳健，且「per-channel bit count 低至 1」时仍能保持可用性能，这是量化方法无法到达的区域（论文明确说明「不存在低于 2 bit 的对应量化方法，因此只展示 CSR-4 / CSR-6」）。Table 3 报告 NeuralDict 在不同 $s, s_n$ 参数下的 MSE，用来论证字典收敛质量。Figure 4 给出不同方法在长上下文推理下的显存占用对比。

**证据缺口**：(a) 「1 bit 可用」的判据是 LongBench 上的平均分，论文未给出 **1 bit 下的逐任务退化分布**，也没有给出与全精度基线的绝对差距——读者无法判断「可用」是指几乎无损还是仅比随机略好；(b) 校准数据集的选择与字典泛化性没有被系统评测（换模型/换领域时是否需要重训字典）；(c) 解码开销（稀疏索引寻址）与理论显存收益未做端到端吞吐对照，只给了显存图。

## 5. 第一性原理再审视

稀疏表示优于均匀量化是一个条件性结论，条件正是「向量确实近似落在字典张成的低维子空间上」。这把风险从「位宽」转移到「字典覆盖」：只要某类 token（罕见实体、数字、代码符号）的表示不被字典覆盖，其系数会变得又大又不稳定，误差就会集中出现在最需要保真的位置——这与 eviction 方法里「精确检索任务崩溃」是同一类失效模式，只是从「整条被丢」变成「整条被压缩失真」。其次，论文用 JS 散度论证层间分布相似，但分散度小只说明**低阶统计**相似，不保证高阶结构可被同一组原子共享；一个更严格的检验是测试「跨模型复用同一字典」的精度掉落，而论文未做。第三，从信息论角度，1 bit/channel 能成立意味着有效自由度远小于通道数；那么一个自然的追问是——为什么不用更少的通道数（降维）而用稀疏编码？论文没有给出与「低秩 + 量化」这类混合基线的直接对照，因此「稀疏表示比降维更好」这一隐含主张缺乏证据。

## 6. 与相邻工作的关系

与 KIVI / WKVQuant / KV cache 耦合量化等**量化**路线是直接竞争关系，区别在码本是否 token 自适应：量化用 per-block 常数重建数值，CSR 用共享字典重建结构。与 H2O、StreamingLLM 等 **eviction** 路线正交（一个减元素、一个减位宽），论文将其列为相关工作但未做组合实验。与基于 SVD 的低秩压缩（如利用奇异值降低量化误差的工作）同属「用结构先验换位宽」，区别是 CSR 的基由神经网络学得而非数据 SVD。

## 7. 可迁移点与开放问题

最有迁移价值的不是「1 bit」这个数字，而是**把压缩器设计成一个可学习字典 + 稀疏编码的联合优化问题**：同样的形式可以用于 agent 的向量记忆库、跨会话历史表示、以及需要长期驻留显存的任何中间状态。开放问题：字典的跨模型/跨领域泛化边界；稀疏索引的硬件友好编码（当前索引本身也要占位）；与 eviction、低秩降维的组合；以及最关键的——在需要**精确逐字召回**（数字、ID、代码）的任务上，稀疏表示还能否保持可用。
