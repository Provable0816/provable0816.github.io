# P112 Dynamic Steering With Episodic Memory For Large Language Models

## 一句话贡献

提出 DSEM：一个**免训练**的框架，用情景记忆把「激活引导（activation steering）」从全局静态操作改造为**逐 token、且以输入查询为条件**的动态操作。它用键值记忆存储「已生成 token 与引导向量」的关联，推理时通过最近邻为每个 token 片段动态计算引导向量，从而比整体施加同一个句级引导向量更精确；在安全、风格迁移、角色扮演等对齐任务上超过强基线。

## 1. 问题与第一性原理动机

论文比较了两种把示例（演示）注入模型的方式：传统 ICL 把示例放进 prompt，缺点是**难以定量控制**且消耗宝贵的上下文空间；激活引导用一个由示例导出的向量直接作用于隐状态，省了空间但现有方法**对所有 token 施加同一个句级向量**。后者的缺陷是结构性的：LLM 是自回归的，不同生成位置对「应当表现为哪种风格/角色」的需求不同（例如角色扮演中，叙述句与对话句的期望风格不同），统一向量在部分位置上纠正过度、在另一些位置上纠正不足，导致输出不一致。因此引导信号应当与**当前位置**和**当前问题**共同相关。

## 2. 核心洞察

洞察是：把「哪些 token 应该被哪种方式引导」当作一个**可检索的记忆问题**。既然引导向量可以被看作是某种「经验」的表示，那么就可以建立一个键值记忆，键是生成 token 的表示、值是相应的引导向量；推理时按最近邻检索出适合当前 token 片段的引导向量，动态合成。这样既保留了激活引导「不占上下文」的优点，又获得了 ICL 那样的条件化能力，而且整个过程免训练（只需构建记忆）。这与 P025/P093 把记忆用于「取回信息」不同——这里的记忆检索的是**行为控制信号**，属于记忆机制的新用途。

## 3. 方法机制

(1) 构建键值记忆：键为生成 token 的表示，值为对应的引导向量；(2) 推理时用最近邻机制为每个 token 片段（chunk）动态计算引导向量；(3) 以查询为条件调整引导强度/方向。方法免训练。代价是：记忆构建需要参考示例（示例分布决定引导质量）；最近邻检索带来额外开销；片段粒度与检索的 k 值是超参；引导强度若不当会损害生成多样性。

## 4. 实验证据

在安全、风格迁移、角色扮演等多类对齐任务上超过强基线，并通过实验说明对齐效果优于基线；论文强调「无需训练」与「不占上下文空间」两点优势。具体指标数值需回看正文。

## 5. 第一性原理再审视

第一，评测集中在**对齐类任务**（安全、风格、角色），这些任务的评价本身依赖 LLM 或人工判断，且「风格一致性」这类指标容易与「输出更保守」混淆；缺少对**任务能力**（推理、知识）同时不下降的验证，是主要证据缺口——激活引导最典型的失败就是对齐变好而能力受损。第二，最近邻检索的键是「生成 token 的表示」，而生成过程是自回归的，键会随生成推进而分布漂移；记忆库若在固定示例上构建，检索在长生成后段可能失准，论文未给出稳定性分析。第三，免训练虽降低门槛，但记忆构建的质量直接决定效果，其可迁移性（换领域、换模型是否需要重建）比训练成本更关键。第四，与 ICL 的比较应控制「提示长度」这一变量，否则「不占上下文」的收益会被混入性能对比。第五，引导向量的动态合成如何避免不同记忆条目之间的冲突（多个近邻给出方向相反的引导），是机制层面的开放问题。

## 6. 与相邻工作的关系

与激活引导（activation steering / representation engineering）一类工作最直接，改进点是把静态句级向量变为动态 token 级；与 ICL 路线是替代关系（节省上下文但需维护记忆）；与 P025（ReMemR1 的记忆回调，用于取回内容）、P093（EM-LLM 的情景事件检索）相比，本方法的记忆存的是**控制信号**而非内容信息，因此在系统里可与内容记忆并存；与 P114（RMM 用反思机制管理记忆）在「用记忆提升对话行为」这一目标上接近，但 RMM 管理的是对话内容记忆、DSEM 管理的是行为引导。定位上属于记忆机制在可控生成方向上的新用法。

## 7. 可迁移点与开放问题

可迁移：(a) 「把控制信号也当作可检索的记忆条目」是记忆系统设计的一个新维度，可推广到风格控制、安全护栏、多角色 agent 的行为切换；(b) 用免训练的记忆替代训练微调来实现行为对齐，是降低适配成本的可复用路线。开放问题：对齐提升是否以能力下降为代价；长生成下检索的稳定性；记忆的跨域/跨模型迁移；多近邻引导冲突的消解；以及引导强度与多样性的权衡。
