# P025 Look Back to Reason Forward: Revisitable Memory for Long-Context LLM Agents

## 一句话贡献

在「边读边记」（memorize while reading）的记忆 agent 中嵌入**回调（callback）机制**，让记忆更新过程本身可以按需取回历史记忆，从而把单次线性扫描的表达能力扩展为非线性推理；并设计多层级奖励（最终答案奖励 + 逐步密集信号）来缓解长链路下的信用分配稀疏问题，在 HotpotQA 与 2WikiMultiHopQA 上跨模型规模全面领先。

## 1. 问题与第一性原理动机

「边读边记」把长文问答降到线性复杂度：agent 逐个消费 chunk $c_t$，把 $c_t$ 与旧记忆 $m_t$ 压缩成新记忆 $m_{t+1}$，读完后仅凭 $m_T$ 作答。论文指出这一范式有三条**结构性**缺陷：(1) **潜在证据被剪枝**——压缩是单向的，某条在读取时看不出用处的信息会被不可逆地丢掉；(2) **覆写造成的信息损失**——记忆是覆盖式更新，早期细节会被后续内容稀释；(3) **强化学习信号稀疏**——只有最终答案给出奖励，模型无法知道是哪一步的记忆操作出了问题。前两条合起来意味着「读到即判定」，而判断证据是否有用恰恰需要后文甚至问题本身；第三条则使长链路上的策略优化极不稳定。三者不是调参能解决的，而是把「单次扫描 + 定长状态」当作固定架构所付出的代价。

## 2. 核心洞察

关键洞察是：**记忆的读与写不应该是单向流水线**。既然剪枝与覆写是信息损失的根源，那就给 agent 一个「回头取」的动作——在更新记忆时允许它按需回调历史记忆片段，把过去的细节重新带入当前推理。这样，即使某条信息在写入时被压缩掉了，只要历史记忆仍可被寻址，它就还有被恢复的机会；换句话说，该方法把「信息是否保留」从写入时的单点决策，变成写入与回调的联合决策，从而把线性链变成可非线性访问的记忆图。第二个洞察针对训练：既然「用没用对记忆」可以逐步判断，就应该在每一步给出密集信号，而不只依赖最终答案的对错。

## 3. 方法机制

框架名为 ReMemR1。记忆侧：在每个时间步更新记忆时允许选择性 callback 历史记忆，因此最终用于作答的记忆 $m_T$ 不再只是最后一次覆写的结果，而是「当前状态 + 被回调的历史状态」的组合；信息增益可被显式刻画（论文讨论「若 $m_t$ 相对 $m_{t-1}$ 带来正信息增益」这类判断）。训练侧：多层级奖励 = 最终答案奖励 + 逐步的稠密信号，用于指导有效记忆使用；策略优化沿用无标准差归一化的组相对形式。整体目标是在几乎不增加计算开销的前提下获得非线性文档利用能力（论文强调引入检索模块后的额外开销可忽略）。代价是引入了一个新的离散动作空间（何时回调、回调什么），这让策略学习的方差增大，也正是密集奖励必须存在的理由。

## 4. 实验证据

评测集为 HotpotQA 与 2WikiMultiHopQA（Table 1），覆盖多个模型规模。基线包含三类：通用 LLM（Qwen2.5 系列、DeepSeek-R1 蒸馏的 Qwen）、长上下文 LLM（Qwen2.5-1M）以及专用记忆 agent（MemAgent，即 P023）。结论是 ReMemR1 在所有模型规模、数据集与上下文长度上都取得最佳准确率；相对 MemAgent 最多高出 7.3%（3B）与 7.6%（7B）。论文另报告一项重要趋势：随着上下文文档数量增加，记忆机制的作用越来越关键——纯推理模型与长上下文模型在极长上下文下性能急剧下降，而记忆 agent 能缓解这一退化。RQ2 专门验证回调机制确实带来非线性文档利用；效率上，加入检索后的额外开销被描述为几乎可忽略。

## 5. 第一性原理再审视

三点需要追问。第一，「可回调」并不等于「无损」：若回调依赖对历史记忆的索引与寻址，而索引本身也是压缩产物，那么回调仍可能找不回被剪掉的证据——论文没有给出「被剪枝信息可恢复率」这一直接度量，只给了端到端准确率，因此回调究竟是在恢复信息，还是仅仅在减轻覆写稀释，无法区分。第二，评测任务偏窄：HotpotQA 与 2WikiMultiHopQA 都是维基百科多跳问答，证据分散但结构规整，这类任务天然适合「回头找」；论文未在需要全局综合（长文档摘要、跨文档时间线推理）或需要精确字符串的任务上验证，而后者恰是记忆压缩路线最易失效的场景。第三，与 MemAgent 的对比中，两个方法在训练数据、RL 算法与奖励设计上都不相同（本文额外有密集奖励），所以 +7.3/+7.6 混合了架构改动与训练改动。第四，「计算开销可忽略」需要具体口径：回调意味着对历史记忆的额外读取与注意力计算，在记忆面板较大的设定下这一项会随步数增长，论文未给出开销随序列长度变化的曲线。第五，多层级奖励的权重与逐步信号的构造方式未在摘要体现，其敏感性直接决定结论的可复现性。

## 6. 与相邻工作的关系

与 MemAgent（P023）最直接：两者都基于覆盖式记忆 + RL 训练，本文的区别是在更新环节引入回调，把「只写不读」变成「可回读」；与 Full-Text Retrieval 范式相比，本文保留线性复杂度的同时避免了向量索引的重存储负担；与 REMem（P024）相比，后者的记忆是显式的图结构 + 工具化检索（时间算子），本文的记忆仍是隐状态面板，靠 RL 策略而非显式接口决定何时回看。整体属于「记忆 agent 的读写协议」这一分支，其核心贡献是给单向流水线补上反向通路。

## 7. 可迁移点与开放问题

可迁移：(a) 「把单向压缩流改成双向可寻址」这一思路对所有流式记忆系统都适用——缓存、日志、持续对话都可引入显式的回调接口；(b) 用逐步密集奖励解决长链路的信用分配稀疏，是训练记忆/工具使用 agent 的通用手段。开放问题：如何度量并提升「被剪枝信息的可恢复率」；回调的搜索空间随步数增长时如何控制开销；密集奖励的构造是否引入对特定任务分布的过拟合；以及在问题后置（先读后问）的场景下回调策略如何运作。
