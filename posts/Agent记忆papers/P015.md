# P015 ReST-KV: Robust KV Cache Eviction with Layer-wise Output Reconstruction and Spatial-Temporal Smoothing

## 一句话贡献

把 KV 淘汰从"保留注意力大的 pair"改写为"最小化删除所导致的层内输出重构误差"，得到能显式反映注意力重分配的指标 $I_t[n]=\frac{A_t[n]}{1-A_t[n]}\lVert \mathrm{MHA}(\cdot)-v_nW_O\rVert_2$，再叠加 EMA 时间平滑与自适应窗口空间平滑，在 LongBench 上平均超 SOTA 2.58%、RULER 平均提升 15.2%，128K 上下文下解码延迟降低 10.61×。

## 1. 问题与第一性原理动机

现有淘汰方法用静态重要性（累积注意力、query-key 相似度）排序，隐含假设"删掉低分项不影响其余项"。但注意力是归一化的：删掉一项后权重会重分配到剩余项，而被重分配顶上来的项未必能补上被删项的输出贡献。因此重要性本质上是"删掉它后输出会变多少"——一个依赖全局、非局部的量，而静态打分在结构上无法表达它。这一缺陷不是工程细节，而是"用局部分数近似全局扰动"的范式问题。

## 2. 核心洞察

把淘汰写成一阶可解的问题。定义删除第 n 个 KV 后的重构误差 $I_t[n]$，在局部线性假设（Molchanov 等）下化简为式 (7)：$\frac{A_t[n]}{1-A_t[n]}$ 是 $(0,1)$ 上的单调非线性放大器，既保留"权重越高越该留"的序，又拉开高竞争项之间的差距；$\lVert \mathrm{MHA}(x_t,\cdot)-v_nW_O\rVert_2$ 刻画"剩余项能否补偿被删 value"。两者相乘即把注意力重分配敏感性量化进指标。此外作者观察到重要性沿时间波动、沿位置漂移（$I_{t-k}[n-kN]$ 与 $I_t[n]$ 形状相似），于是引入两种平滑。

## 3. 方法机制

四个部件：① 层内重构指标，即式 (7)；② 时间平滑：在最近 $S_w$ 个 query 的窗口上对 I 做 EMA（系数 α），最近 $S_w$ 个 token 直接赋极大值 Ω 强制保留；③ 空间平滑：把观察窗对半切，分别求 top-B 重要项的平均下标 $D_{front}$、$D_{rear}$，用 $\Delta D$ 自适应决定窗口大小 $W_s$ 与偏移 $\gamma_{shift}$，最后对窗口内指标取均值作为最终分数；④ 每个 head、每个 layer 独立保留 top-B。代价是需要按层计算 $v_nW_O$ 的额外投影，以及 α、β、$S_w$ 三组超参。

## 4. 实验证据

骨架 5 个：Llama2-Chat、Gemma-Instruct（MHA）与 Llama3-Instruct、Mistral-v0.3、Qwen2.5-Instruct（GQA）。基线 StreamingLLM / H2O / TOVA / SnapKV / LaCache，并把 PyramidKV、AdaKV 的自适应预算接入以验证兼容性。LongBench 16 数据集：低预算下最高 +2.58%（Mistral）。Table 1（Llama-3.1-8B，$B_{total}=64L$）ReST-KV 平均 33.54，SnapKV 31.48；Llama2-7B 在 64L 下 25.54，LaCache 仅 13.51。RULER（Llama3.1-8B，$B=1024L$，4K–128K）：平均 82.27，SnapKV 67.11、PyramidKV 66.97、Full 93.46；128K、保留率不足 1% 仍可检索。NIAH（Mistral-v0.3，$B=1024L$）保持约 98% 的性能。消融（Table 3）：纯注意力 top-k 32.98，ReST-KV 35.86；去掉 LOR 33.95（−1.91）、去掉 EMA 34.02（−1.84）、去掉 AWS 33.50（−2.36），三个部件均有独立贡献，空间平滑贡献最大。

## 5. 第一性原理再审视

式 (7) 依赖"删除后 softmax 重归一化 + 局部线性展开"，它是单步、单层的近似；真实目标是未来 T 个 query 上的累积输出误差，而指标只用当前观测窗口，靠 EMA 与窗口滑动去逼近这个未来量——平滑不是装饰，而是填补"局部代理 ≠ 全局目标"的缺口。因此上限受两点制约：一阶近似在注意力分布剧烈变化时误差大；窗口与 EMA 超参把"多久之前的查询还算数"编码成硬性先验，论文没有给出由预算或任务推导它们的准则。其真正贡献是把淘汰的失效模式从"打分不准"重新定位为"忽略重分配"，与淘汰的不可逆性相匹配。

## 6. 与相邻工作的关系

与 H2O/TOVA/SnapKV 是"指标替换"关系，可直接套进它们的框架；与 Keyformer 都关注淘汰对注意力分布的扰动，但 Keyformer 靠归一化补偿，ReST-KV 把扰动直接写进排序依据；与 P004（防御式聚合，强调尾部风险）互补——一个改聚合方式，一个改指标定义。

## 7. 可迁移点与开放问题

可迁移的是"用删除后的输出差异而非删前的重要性做决策"这一原则，适用于记忆检索打分、多段证据融合、agent 历史裁剪等一切不可逆的保留/丢弃决策；以及"时间 EMA + 空间自适应窗"这套针对漂移重要性的平滑模板。开放问题：能否给出累积输出误差的可证明上界；α、β、$S_w$ 能否自适应；与量化叠加时误差如何分解。
