# P096 D2O: Dynamic Discriminative Operations for Efficient Long-Context Inference of Large Language Models

- 会议/来源：ICLR 2025
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/d862f7f5445255090de13b825b880d59-Abstract-Conference.html

## 贡献

提出 D2O：一个免微调的 KV 压缩方法，在**层与 token 两个层面**做动态且具判别性的操作。层层面，利用浅层与深层注意力权重的密度差异，用动态分配策略决定哪些层应当避免过度淘汰，以减少信息损失；token 层面，引入**补偿机制**：维持一个相似度阈值，对被淘汰的 token 重新判别其重要性，决定是否应当召回并与相似 token 合并。实验显示显著省显存、推理吞吐提升超过 3×，同时保持高质量长文本生成。

## 机制要点

两个设计对应两类被既有方法忽视的结构。第一，浅层与深层的注意力密度不同（浅层更分散、深层更集中），因此对它们施加同等强度的淘汰会在一部分层上造成不必要的损失——这与 P037（头间预算）、P091（层间预算）的判断一致，但 D2O 用注意力权重的密度而非表示差异来刻画。第二，**被淘汰不等于应该永久消失**：用一个相似度阈值定期重审被删除的 token，并把它们合并进相似的代表，等于把「淘汰」变成「暂存 + 合并」，从而在不增加 cache 规模的前提下回收部分信息——这与 P040（合并）、P090（补偿 token）属于同一类「有损但可补救」的设计思路。

## 关键结果

在多种基准与 LLM 架构上，D2O 取得显著的显存节省、推理吞吐提升超过 3×，并保持高质量长文本生成；方法无需微调。

## 局限与定位

第一，「质量保持」需要用对压缩最敏感的任务（多针检索、计数、精确字符串）核验，而摘要未列出具体评测集；考虑到 D2O 的淘汰是不可逆的（召回只发生在相似合并这一受限形式下），这类任务的风险最高。第二，>3× 吞吐是相对何种基线（全量 cache 还是其它压缩方法）需要明确；若是对全量 cache，则需与同预算的竞品比较才能判断方法优劣。第三，两个层面各有超参（层分配策略、相似度阈值），联合调参的敏感性未见；补偿机制的重审频率也带来额外计算。第四，与 P040（AsymKV，key 合并 + 无损 value）、P090（RazorAttention，补偿 token）相比，D2O 的补偿发生在**token 级相似合并**上，其效果与「多保留几个 token」的性价比需要量化对比。定位上属于多层 + 多机制组合的免训练压缩方案。
