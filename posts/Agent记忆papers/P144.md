# P144 Perception Compressor: A Training-Free Prompt Compression Framework in Long Context Scenarios

- 会议/来源：NAACL 2025（Findings）
- 方向簇：CTX
- 链接：/2025.findings-naacl.229/
- 本地全文：cache/txt/P144.txt

## 一句话贡献

提出 Perception Compressor：一个**免训练**的 prompt 压缩框架，针对长上下文场景中的冗余信息与**位置敏感性**两个问题，包含三个部件——用引导问题与指令检索最相关示范的 perception retriever、动态分配压缩比与「开卷比（open-book ratio）」的 dual-slope ratio allocator、以及在 token 级保留关键信息同时移除干扰 token 的半引导迭代压缩。

## 1. 问题与第一性原理动机

论文点出的第二个问题常被低估：LLM 对**关键信息所在位置**敏感（即「lost in the middle」一类位置偏置），因此压缩不仅要减少冗余，还要考虑压缩后关键信息的**位置**是否落在模型擅长利用的区间。这解释了为什么需要「开卷比」这一概念——决定哪些内容以原文形式保留（开卷）与哪些被压缩，本质上是在重新安排信息在上下文中的分布。把「压缩多少」与「保留多少原文」作为两个独立旋钮（dual-slope），比单一压缩率更能应对位置敏感性。

## 2. 核心洞察

洞察是**压缩比的分配应当是非均匀且与查询相关的**：不同片段的信息价值不同（P019 的 MIG、P083 的层间分配都基于同一判断），而「半引导迭代压缩」则承认一次性压缩难以找准边界，需要通过多轮迭代在 token 级逐步收紧——这与 P085（Activation Beacon 的渐进压缩）在哲学上一致，但发生在 prompt 层面且免训练。第二个洞察是感知（perception）视角：先用引导问题让系统「知道该找什么」，再据此检索与压缩，避免无目的的通用压缩。

## 3. 方法机制

(1) perception retriever：用引导问题与指令检索最相关的示范；(2) dual-slope ratio allocator：动态分配压缩比与开卷比；(3) semi-guided iterative compression：在 token 级保留关键信息、移除干扰。方法免训练，因此可直接用于黑盒或托管模型。代价是：引导问题需要构造（其质量影响检索与压缩）；迭代压缩带来多轮处理开销；开卷比这一新旋钮需要调参；token 级删除仍是不可逆的，且会破坏原始文本的连续性与可引用性。

## 4. 实验证据

在 NaturalQuestions、LongBench、MuSiQue 上做了大量实验，论文称相对既有方法有较大幅度提升。基准组合覆盖单跳（NQ）、综合长文（LongBench）与多跳（MuSiQue），其中多跳任务的纳入尤其重要——它是 token 级删除最容易失效的场景。

## 5. 第一性原理再审视

第一，「较大幅度提升」需要确认对照方法是否为同等免训练设定；若与需要训练的方法比较，则优势可能来自任务适配而非压缩机制。第二，token 级删除在多跳任务上天然危险：单看与查询无关的片段可能与其他片段组合后才关键（P111 的「边界丢失」与 P019 的相关性主导选择都指向这一点），而论文把 MuSiQue 纳入评测是正面信号，但需要按跳数与证据分布分层报告。第三，开卷比与压缩比的联合调参使方法有较多自由参数，实际部署时需要在目标域上调优，与「免训练」的简洁性形成张力。第四，位置敏感性被列为动机，但评测是否包含**按信息位置分层的指标**决定了该动机是否被真正验证；只报平均值无法体现位置改善。第五，与 P113（面向检索的压缩，用偏好优化训练）相比，本方法免训练但缺少目标对齐的训练信号，属于「低门槛 vs 高上限」的经典取舍。

## 6. 与相邻工作的关系

与 P019（COMI 的 MIG 压缩）在「按相关性非均匀分配」上同源，但 COMI 需要训练 encoder 且改写为软表示，本方法免训练且保留部分原文；与 P054（EHPC 用评估者头速读压缩）同属免训练硬 token 压缩，差别是打分信号来源（引导问题检索 vs 内部注意力头）；与 P085（Activation Beacon 的渐进压缩）在「迭代压缩」上呼应但层面不同；与 P118（按句间相似度动态切块）在预处理粒度上可互补。定位上属于免训练 prompt 压缩中结构较完整的一种。

## 7. 可迁移点与开放问题

可迁移：(a) 「把压缩比与原文保留比例作为两个独立旋钮」是有实用价值的接口设计，便于按任务调节；(b) 用引导问题驱动检索与压缩，是让免训练方法获得任务相关性的低成本手段。开放问题：与训练式方法的公平对比；多跳任务上的证据保真；参数调优的负担；位置敏感性的分层验证；以及不可逆删除的风险控制（例如与 P022 的 EntropyRank、P025 的可回调机制结合）。
