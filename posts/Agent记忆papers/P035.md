# P035 SALS: Sparse Attention in Latent Space for KV Cache Compression

- 会议/来源：NeurIPS 2025
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/00a0ebcad584c59dbc439c2af8793638-Abstract-Conference.html

## 贡献

把「低秩压缩」与「token 稀疏选择」组合成 SALS：先在隐空间用低秩投影压缩 KV cache，再在这个空间里用**不含 RoPE** 的 query–key 交互做稀疏 token 选择，最后只把被选中的少量 token 重建回高维做精确注意力，从而避免为施加 RoPE 而重建整个 cache。

## 机制要点

两个观察支撑设计：(1) 对 key 施加 RoPE 会放大其方差、进而抬高有效秩，所以低秩压缩与位置编码天然冲突——这正是既有低秩方法要么掉点、要么引入新瓶颈的原因；(2) key 被投影到隐空间后，其表示在大多数层之间保持稳定，因此可跨层复用低秩结构。关键开销被削减在重建量上：只重建 top-k 重要 token，而非全量 KV。

## 关键结果

在 LLaMA2-7b-chat 与 Mistral-7b 上，SALS 在给定稀疏度与低秩压缩比下达到论文所称的 SOTA 精度；4K 序列上取得 6.4× KV cache 压缩与相对 FlashAttention2 的 5.7× 注意力算子加速，端到端吞吐相对 GPT-fast 在 4K 与 32K 上分别提升 1.4× 与 4.5×。可扩展性在 LLaMA3.1-8B-Instruct 上用 RULER-128k 验证。论文 Table 1 从访存量、内存与复杂度三维度与 Palu、Loki、StreamingLLM、Quest、DS、Hshare 做了对比。

## 局限与定位

低秩投影矩阵需训练或校准获得，其成本与是否需按模型重训在摘要中未说明；「competitive accuracy」的措辞表明精度目标是持平而非超过全量 cache。效率数字集中在 4K 与 32K，128K 只报告了可行性而非吞吐收益，超长上下文下重建稀疏 token 的相对开销是否仍可忽略缺乏证据。另需注意正文 Table 1 中本方法一行的复杂度标注存在排版错误（写作 "Midian"）。定位上，SALS 属「低秩 + 稀疏」混合路线，与 token 淘汰（信息不可恢复）和量化（不减少 token 数）互补，其独特价值在于显式处理了 RoPE 与低秩压缩的结构性冲突。
