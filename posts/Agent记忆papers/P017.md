# P017 Bottlenecked Transformers: Periodic KV Cache Consolidation for Generalised Reasoning

## 一句话贡献

用信息瓶颈（IB）理论论证自回归训练会让 KV 缓存成为"过度保真"的终端瓶颈，进而提出 Bottlenecked Transformer：在推理步边界（换行触发）用一个小型 Cache Processor 对最近步窗口与 top-k 召回的 KV 做原地、非因果重写（类比记忆的巩固与再巩固），在 4 个骨架、7 个数学/逻辑推理基准上稳定优于 SFT 与 pause-token 基线，最高 +6.6pp。

## 1. 问题与第一性原理动机

Transformer 缓存无界增长，因此在检索任务上极强，却在需要系统性规则应用与分布外泛化时不如 RNN/状态空间模型——后者用固定大小隐状态强制每步重新加工信息。论文把这类推理期增量计算统称为 Auxiliary Latent-Space Computation（ALSC），并指出其中"缓存算子"一支几乎只关注压缩显存，忽略了"重写以提升泛化"。根本问题是：自回归训练只奖励预测下一 token，是否必然鼓励缓存保留大量对未来预测无用、却对泛化有害的历史细节？

## 2. 核心洞察

IB 视角。Thm 4.1：decoder-only Transformer 的 $(K_{0:n},V_{0:n},O_n)$ 就是序列到序列的终端瓶颈 $\hat Z$。Thm 4.2：$L(\theta)\le\sum_n I(S_{0:n};C_{0:n})-\sum_n H(S_{n+1}\mid S_{0:n})$，同时 $L(\theta)\le\sum_n I(C_{0:n};S_{n+1})-H(S_{n+1})$，即最大化似然会同时抬高两个互信息项。由于 $C_{0:t}$ 包含所有更早的子状态，最大化 $I(S_{0:n};C_{0:n})$ 的后果是：缓存里编码的是"逐步预测轨迹的高保真副本"，而非任何压缩摘要。也就是说，泛化所需的压缩（降低 $I(X;Z)$）在自回归训练中从未被激励，这与 RNN 用小状态被迫压缩形成鲜明对照。

## 3. 方法机制

在主干 LLM 外挂与每层对齐的小 Transformer 块集合 $T_{proc}^{(\ell)}$，触发时机是推理步完成（发出换行 token）。每次调用改写两类条目：最近步窗口（RSW）内的新缓存（巩固）与由注意力质量从历史步选出的 top-k 条目（再巩固）。流程：把选定层的 KV 按所有 head 拼成 "KV-token" → 投影到 processor 隐空间（$d_p=512$、16 头、中间维 2240）→ 无因果掩码的 Transformer 块 → 投影回 KV 维度 → 带可学习标量门 $g^{(\ell)}$ 的 sigmoid 门控残差写回。关键取舍是不做任何降维，以避免"无差别削减预测信息"。训练两阶段：先 SFT 主干，再冻结主干、仅用"预测下一推理步"的交叉熵训练 processor，并在步边界截断 BPTT。

## 4. 实验证据

骨架 Llama-3.2-1B、Llama-3.1-8B、Qwen-3-0.6B、Llama-3.2-3B；训练数据 OpenMathInstruct-2 的 128k 样本；基线 SFT、SFT+pause tokens（16）、SFT+latent rollout（16，仿 Coconut）。Table 1（pass@1，贪心）：Llama-3.2-1B 上 SVAMP 38.0→44.6（+6.6）、GSM8K 29.80→32.97、TheoremQA 8.84→10.84；Llama-3.2-3B GSM8K 46.78→51.33（+4.6）；Qwen-3-0.6B MATH 26.68→29.08；Llama-3.1-8B LogiQA 20.74→23.81（+3.1）。反例同样明确：Llama-3.1-8B 的 Gaokao-MathQA 仅 3.99（低于 SFT 的 4.84，论文归因于中文分布外）；Llama-3.2-3B 的 LogiQA 20.12 低于 SFT 22.12。消融：top-k 在 16/32/64/128/256 中 k=32 最好；RSW 长度在 16–48 内结果稳健。重写幅度分析显示 value 向量被实质改写而 key 几乎不变（改内容不改寻址），改动集中在最浅层，前约 10 次调用幅度最大后进入稳定平台，说明 processor 未退化为恒等映射。

## 5. 第一性原理再审视

理论回答的是"为什么有可能"，不是"为什么一定有效"：论文明确没有实现 IB 损失，压缩只能靠数据处理不等式与 SGD 噪声隐式产生；$I(X;Z)$ 在高维变长缓存上不可估，重写幅度只是定性代理。监督信号也偏弱——只用下一步交叉熵回传，作者自承信用分配方差大、难逃局部最优。因此"提升泛化"的因果链是：周期性重写 → 缓存瓶颈信息量下降（未测） → 泛化提升（观测到），中间环节缺证据。此外"巩固"与"再巩固"在神经科学中触发条件与时间尺度均不同，本文把二者合并为单一在线 processor，并用固定的换行触发而非预测误差触发，作者在讨论中承认这是简化。

## 6. 与相邻工作的关系

在 ALSC 谱系中属"缓存算子"，但与淘汰/合并/摘要类压缩的本质区别是不降低显存、只改变内容；与 pause token、Coconut 式 latent rollout（token 介导）和 activation steering（残差算子）并列，本文实验只与前者对照；与 P013/P015 这类 KV 压缩方法目标不同（提升推理 vs 降显存），不构成直接竞争。相对深层循环/RMT 类架构，它保留无界缓存但周期性"重加工"，接近 RNN 的压缩收益而不承担固定状态的容量损失。

## 7. 可迁移点与开放问题

可迁移的是"在推理步边界周期性重写工作记忆"这一通用机制，可套用到 agent 长轨迹、多轮对话与工具调用历史；以及"门控残差 + 小门初值"这种防止早期漂移的稳定化技巧。开放问题：能否显式加入压缩项（如对选中 KV 注入受控噪声再迭代去噪）真正优化 IB；触发信号换成预测误差/惊奇度是否更好；把离线"睡眠式"重放型 consolidator 与在线 reconsolidator 分离是否更贴近生物机制并带来增益。
