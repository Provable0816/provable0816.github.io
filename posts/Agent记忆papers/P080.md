# P080 On-the-Fly Adaptive Distillation of Transformer to Dual-State Linear Attention for Long-Context LLM Serving

- 会议/来源：ICML 2025
- 方向簇：ARCH
- 链接：https://proceedings.mlr.press/v267/ro25a.html

## 贡献

提出两个部件：DSLA（dual-state linear attention），维持**两个专用隐状态**——一个保存历史上下文、一个追踪近因——以缓解线性注意力常见的短程偏置；以及 DSLA-Serve，一个在线自适应蒸馏框架，在推理时**逐步把 Transformer 层替换为 DSLA 层**，替换顺序由基于敏感度的排序决定，并用链式微调保证每层替换后与已替换的层保持一致。

## 机制要点

线性注意力的经典失效模式是把定长状态过度偏向近期 token（overemphasizing recent tokens），导致历史信息被覆盖。把「历史」与「近因」拆成两个状态，等于在架构层面显式分离两种时间尺度，避免单一状态被迫在两者间折中。第二部分的工程意义更大：把「训练时替换」变成「推理时按需替换」，使同一个已训练模型可以根据负载动态决定保留多少全注意力层，从而在质量与效率之间连续调节，而不必为每种配置单独训练一个模型。

## 关键结果

在常识推理、长上下文 QA 与文本摘要上，DSLA-Serve 相对 Llama2-7B 推理快 2.3×、相对混合架构 Zamba-7B 快 3.0×，同时下游任务表现相当。消融显示 DSLA 的双状态确实同时捕捉全局与局部依赖，缓解了既有线性注意力对历史 token 表示不足的问题。代码开源。

## 局限与定位

第一，「性能相当」的对照基线是 Llama2-7B 与 Zamba-7B，而非同代的更强长上下文模型；相对旧基线的优势可能被新一代模型削弱。第二，链式微调意味着**每条替换路径都需要训练**，若要在部署时灵活选择层数，就需要预先训练或在线训练多组配置，这与「on-the-fly」所暗示的即插即用存在张力；论文需说明在线微调的时间与算力门槛。第三，DSLA 的双状态缓解了短程偏置，但线性注意力在**精确召回**上的固有劣势（P056 已指出）是否被解决未给出专项证据（如 NIAH 多针）。第四，敏感度排序是离线测得还是在线估计、是否随输入分布变化，决定了替换决策的可靠性。定位上，DSLA-Serve 属于「架构替换 + 自适应部署」的组合，与 P056（二次—线性对等混合）相比更偏向工程化的渐进替换。
