# P040 Homogeneous Keys, Heterogeneous Values: Exploiting Local KV Cache Asymmetry for Long-Context LLMs

- 会议/来源：NeurIPS 2025（主会）
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/750b0f9fccafad88e0da366315e03d1a-Abstract-Conference.html
- 本地全文：cache/txt/P040.txt

## 一句话贡献

揭示 KV cache 的一个被忽视的不对称性：**相邻 key 的注意力权重高度相似（局部同质），相邻 value 的表示却明显异质**；据此提出免训练的 AsymKV——对 key 做同质性合并、对 value 做有数学证明的无损压缩，在 LLaMA3.1-8B 的 LongBench 上取得 43.95 平均分，大幅超过 H2O 的 38.89。

## 1. 问题与第一性原理动机

既有压缩方法几乎都把 key 与 value 当作一个整体处理：要么按注意力分数成对淘汰 KV，要么成对合并。这个「对称假设」在结构上并不成立，因为 key 与 value 在注意力公式里扮演的角色完全不同——key 只通过 $q^\top k$ 参与**权重**计算，value 则直接决定输出的**方向与幅度**。因此「相邻 key 相似」只意味着权重近似，「相邻 value 相似」才意味着输出可近似。论文用 Spearman 相关度量这个差异：相邻注意力权重的平均秩相关约 0.727，而相邻 value 相似度的秩相关仅约 0.392，且该模式在几乎所有层与头上一致。现存方法的另一个痛点是：按历史重要性硬淘汰会丢掉「历史上不重要、但下一步突然关键」的 token；而合并类方法虽然保留了更多信息，却**默认**可合并的表示一定相近——本文正是要挑战这个默认。

## 2. 核心洞察

关键洞察是把不对称性转成两种不同的处理策略：对 key 侧，既然相邻 key 引起的注意力权重近似相同，就可以把它们**合并成一个 key** $k^*$，用更少的 key 表达几乎相同的权重分布；对 value 侧，若多个 token 共享或对齐到同一个 key，那么它们的 value 可以按某种**基数归一化**方式合并，而注意力输出在这一构造下保持**无损**——论文称之为 cardinality normalization，并给出数学证明。这条结论的深层含义在于：注意力机制允许「无损合并」的条件并不要求 value 本身相似，只要求合并方式与权重归一化保持一致。这解释了为什么此前把 key/value 同等对待的合并方法必然有损。

## 3. 方法机制

AsymKV 是 training-free 框架：(1) 依据局部同质性把相邻 key 合并为 $k^*$，减少 key 数量并提升计算效率；(2) 对与同一 key 对应的 value 做无损值表示（cardinality normalization），保证注意力输出等价于原结果；(3) 整体目标是在给定 cache 预算下最小化总损失，而不是逐 token 做硬淘汰。由于没有训练环节，方法可直接加在任何现成模型上，无需校准数据或微调。代价是：合并集合如何构造（合并多少、按什么准则确定分组）成为决定近似程度的关键，而「无损」只对 value 侧成立，整体误差集中在 key 合并这一步。

## 4. 实验证据

主结果：LLaMA3.1-8B 上 LongBench 平均 43.95，对比 H2O 的 38.89，论文称之为大幅领先；论文称在多种任务与多个基座模型上一致优于既有长上下文方法。支撑性分析包括：跨全部层与头的相邻注意力权重 Spearman 相关（平均 0.727）与相邻 value 相似度的 Spearman 相关（平均 0.392）的对比图，以及无损注意力输出保持的图示。方法与 H2O、RoCo、L2 范数类压缩等做了对照讨论。

## 5. 第一性原理再审视

「无损」这个词需要严格限定：从论文的自述看，被证明无损的是「在给定合并构造下，value 的合并不改变注意力输出」——也就是说，误差被完整地推到了**key 合并**环节。若合并后的 $k^*$ 不能精确代表被合并 key 的权重分布（它显然不能，因为权重是 $q$ 的函数而 $k^*$ 固定），那么整体输出必然有偏，只是这份偏差不上界。因此这更接近「把误差集中到一个可度量的位置」，而非真正无损压缩，读者不应把标题里的 lossless 理解为端到端无损。第二个隐含假设是局部同质性在所有层/头上稳定成立：论文给的是平均值（0.727）与分布可视化，但压测高风险任务（精确计数、长链数值推理）时，若关键信息恰落在异质性最强的头，合并会直接抹掉区分度。第三，AsymKV 的压缩能力是否随预算收紧而平滑退化（还是存在断崖）未在摘要体现，而这恰是 KV 压缩最关心的性质。第四，评测集中在 LongBench 与 LLaMA3.1-8B，跨模型族（Qwen、Mistral）与超长上下文（>128K）的证据不足。

## 6. 与相邻工作的关系

与 H2O（历史注意力淘汰）、SnapKV（观测窗口淘汰）相比，本文不淘汰而是合并，因此信息保留度更高；与 CaM、D2O 这类「key 相似则合并」的合并方法相比，本文指出它们错在把 key 与 value 同等处理，并给出显式的无损 value 合并构造；与 P039（ChunkKV，以 chunk 为选择单位）在「成组处理」上同源但机制不同：ChunkKV 保留原始 token，AsymKV 主动改写表示。整体属于「利用 KV 结构不对称性」这一新切口。

## 7. 可迁移点与开放问题

可迁移：(a) 「先检验被当作整体的两个对象是否真的同构，再分别设计压缩策略」这一分析范式，适用于任何成对存储的结构（如 MoE 的 gate 与 expert、检索中的 doc 与 embedding）；(b) 「把误差集中到可度量的单一环节」比「各处都有小误差」更利于工程控制。开放问题：key 合并的最优分组能否由查询分布自适应决定；合并后 cache 是否仍兼容 FlashAttention 等高效 kernel；在需要精确区分的任务上能否给出有损界；以及该方法与头间/层间预算分配（如 P037）叠加时的交互效应。
