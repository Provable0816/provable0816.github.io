# P207 Randomization Boosts KV Caching, Learning Balances Query Load: A Joint Perspective

## 贡献

给出首个把 **KV cache 淘汰**与**查询路由**统一起来的数学模型：在限内存、动态到达、多 LLM 服务的场景下，「单机缓存命中率最大化」与「全局负载均衡」是本质冲突的目标。作者据此推导出「**可证竞争比的随机化缓存淘汰** + **基于学习的自适应路由**」的组合算法（LBGR + RLT），在大规模实验上大幅超越 SOTA。

## 机制要点

冲突的刻画见 Figure 1：把同一前缀的查询粘在同一台机器上能提高命中率，但会造成负载倾斜；为均衡而打散查询则会破坏局部性、扰乱 LRU。论文的第一个结论是随机化在这一权衡中有结构性优势——随机淘汰/随机化策略可以获得**竞争比保证**（相对离线最优的界），而确定性 LRU 在对抗性到达序下会被击穿（Figure 4 用 worst-case round-robin 到达序专门检验这一点，LBGR+RLT 仍然胜出）。第二个结论是路由需要学习：查询到达模式演化时，固定规则无法同时兼顾负载与亲和性，因此用学习式组件自适应路由。Table 1 给出记号体系，说明模型把淘汰、路由、到达过程纳入同一形式化。

## 关键结果

实验覆盖 4 个基准（GSP、ShareGPT、UltraChat、Loogle）与 3 种前缀共享设置，模型含 Llama-3.1-8B-Instruct（Figure 2）、Llama-3.1-70B-Instruct 与 Mixtral-8×7B-Instruct-v0.1（Figure 3）。摘要报告相对 SOTA 的最优改进幅度：缓存命中率最高 **6.92×**、延迟降低 **11.96×**、TTFT 降低 **14.06×**、吞吐提升 **77.4%**；Table 给出 P50/P95 延迟、TTFT、命中率、吞吐以及淘汰/路由的平均耗时的分项数据。

## 局限与定位

第一，命中率估计依赖共享的全局基数树（radix tree）与前缀最长匹配，论文自陈字符级与 token 级粒度的不匹配、以及并发更新导致的陈旧性会使估计偏离真实命中率——这直接影响路由决策质量，作者把它留作未来工作。第二，理论保证针对**淘汰策略**，而路由的学习部分是经验性的，因此端到端的「可证性」只覆盖系统的一半。第三，实验模拟的是给定到达过程与共享前缀分布，真实生产流量的分布漂移与时变特性会更复杂。定位上，它把 KV 压缩的问题从「单个缓存内如何取舍」提升到「多个缓存之间如何分配」，与 P204（跨模型共享 KV）、P186（子图级 KV 复用）同为**系统级复用**路线；其最大贡献是把这一系统问题第一次写成了带竞争比保证的数学对象，这在以工程启发式为主的 KV 优化领域是罕见的。
