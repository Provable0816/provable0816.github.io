# P140 You Only Use Reactive Attention Slice When Retrieving From Long Context

- 会议/来源：EMNLP 2025（Findings）
- 方向簇：KV
- 链接：/2025.findings-emnlp.1125/
- 本地全文：cache/txt/P140.txt

## 一句话贡献

提出 YOURA：一种**免训练、免微调**的基于注意力的检索技术。它用一个新的「反应分数（reaction score）」启发式来量化语言模型的**自注意力对用户查询产生何种「反应」**，并配以句子抽取算法高效预处理上下文。在三个开源模型、LongBench 与 BABILong 上，相对基于嵌入的检索把问答准确率提升最多 15%、推理吞吐提升最多 31%。

## 1. 问题与第一性原理动机

论文指出既有检索的两难：**基于嵌入的方法因依赖词汇/语义相似度而常常不准**，而**神经检索器训练成本高**。前者的问题与 P128（语境不匹配的检索）、P136（错误归因接地）同源——相似不等于相关；后者的问题是部署门槛。因此需要一种既准确又零成本的检索信号。论文的答案是：既然模型已经**对查询做出了反应**（自注意力分布随查询改变），那么直接观测这一反应就可以作为相关性证据，无需训练任何检索器。

## 2. 核心洞察

洞察的关键在于**把检索信号从「输入侧」搬到「模型内部」**。嵌入检索比较的是「文档与查询的表示是否接近」，而反应分数衡量的是「把文档放进模型后，模型的注意力是否被查询引导到它身上」。后者更接近真正决定输出的机制——这与 P088（OmniKV 利用层间关注一致性）、P135（DASH 利用表示稳定性）属于同一思路：**用模型自身的动态而非外部相似度来判断价值**。第二层洞察是「反应」这一概念天然包含了**查询条件化**，因此避免了 query-agnostic 方法在多样查询下的固有限制（P045 为了可复用性不得不放弃查询信息）。

## 3. 方法机制

(1) 用句子抽取算法对上下文做预处理（降低后续检索的粒度与开销）；(2) 计算反应分数，量化自注意力对查询的响应；(3) 据此检索。全程免训练、免微调，可直接套用在开源模型上。代价是：需要运行模型前向来观测注意力，因此检索本身有计算成本（论文通过句子级预处理与吞吐提升来抵消）；反应分数的定义与阈值需要设计；对不暴露注意力或使用融合 kernel 的实现（如 FlashAttention）不友好——这与 P042/P090 面临同一约束，而它们选择回避注意力、本文选择使用注意力。

## 4. 实验证据

三个开源 LM 上、LongBench 与 BABILong 两个基准：问答准确率相对嵌入检索提升最多 15%，推理吞吐提升最多 31%。吞吐提升来自于句子级抽取减少了需要处理的内容量。

## 5. 第一性原理再审视

第一，「准确率 +15%」的对照是**基于嵌入的检索**，而这是相对较弱的基线；与强神经检索器（如经微调的检索模型）对比才能定位 YOURA 的真实水平，尤其在需要语义泛化的任务上。第二，反应分数要求读取注意力分布，这与高效 attention 的实现路径相冲突；论文用「免训练」换取了模型内部信息的可用性，但在生产级 serving 中这一取舍的代价可能很高（P042 明确选择避免注意力矩阵正是为此）。第三，句子级抽取作为预处理会改变上下文结构，可能出现 P111 指出的「边界丢失」——关键信息跨越句边界时被削半；论文未讨论该风险。第四，吞吐提升 31% 主要来自输入变短，而非检索机制本身更高效，因此它不能与其他压缩方法的吞吐数字直接比较。第五，与传统检索相比，该方法把检索成本从「离线建索引 + 在线查表」变成了「在线跑模型前向」，在**多查询复用同一上下文**的场景下可能反而更贵（P045 的查询无关路线正为此设计）。

## 6. 与相邻工作的关系

与 P051（RetrievalAttention 用向量索引与 CPU 驻留）相比，一个用外部索引、一个用模型内部注意力，前者可扩展、后者更「原生」；与 P042（KEYDIFF 完全不依赖注意力以兼容 FlashAttention）在工程约束上正相反，构成一对有代表性的取舍；与 P045（KVzip 的查询无关压缩）相比，YOURA 是查询相关的检索；与 P128（STITCH 用意图线索提升检索精确度）都在解决「相似≠相关」，但一个用外部结构线索、一个用模型内部反应。定位上属于免训练的内部信号检索路线。

## 7. 可迁移点与开放问题

可迁移：(a) 「用模型对查询的反应而非文档与查询的相似度来判断相关性」是一条可复用的判断，尤其适用于领域外或需要推理的场景；(b) 句子级预处理作为降本手段可复用到任何长文本检索流程。开放问题：与强神经检索器的横向对比；与融合 kernel 的兼容路径；句子边界效应；多查询复用场景下的成本；以及反应分数在不同模型族之间的可迁移性。
