# P091 SqueezeAttention: 2D Management of KV-Cache in LLM Inference via Layer-wise Optimal Budget

- 会议/来源：ICLR 2025（主会）
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/3b0a8df568ec496a717566a7f8158aaa-Abstract-Conference.html

## 一句话贡献

把 KV 压缩从单一序列维度扩展为**序列 × 层**的二维管理：用「自注意力层前后输入 prompt 差异的余弦相似度」衡量各层的敏感度，据此把层分成两组并在线调整各自的 KV 预算，再在每层内部套用三种代表性序列压缩算法；在多种 LLM 与基准上取得约 30%–70% 的显存下降与最高 2.2× 吞吐提升。

## 1. 问题与第一性原理动机

论文指出的结构性缺陷与前一批工作一致却更清晰：多数压缩方法**在所有层上平均分配 KV 预算**，但层的敏感度并不相同——某些层对输入 token 的依赖很弱，给它同等预算既无必要也浪费。这一点的关键在于「敏感度」的定义方式：如果只看注意力分数，无法区分「这层看了很多 token」与「这层真的改变了表示」。SqueezeAttention 选择的度量是**经过自注意力层前后，prompt 表示的差异**——若变化很小，说明该层对输入上下文的依赖弱，可以削减预算。这个度量把「层是否重要」锚定在功能后果上，而非行为表象，因此在原理上比注意力统计更贴近信息流。

## 2. 核心洞察

洞察是：分配与选择是两个可分离的问题，且分配应当先做。既有的序列级算法（打分、淘汰、合并）解决「层内留哪些 token」，但前提是「该层有多少预算」已经确定；把预算做对，层内算法的效果会同步放大——论文正是通过在预算维度上先优化，再叠加三种现成的序列级算法来验证这一点。第二层洞察是分配可以**在线进行**：敏感度由当前输入决定，故不需要离线校准或额外训练，这也避免了 P048 所批评的校准漂移问题。

## 3. 方法机制

(1) 计算每层自注意力前后 prompt 表示的余弦相似度，作为敏感度；(2) 据此把层分为两组并分配不同的 KV 预算；(3) 在每层内用序列级方法（论文纳入三种代表性算法）按其预算压缩。代价是：把层划成两组是离散化近似，边界附近的层可能被误分；相似度指标需要额外一次前向比较；「两组」这一粒度相对 P037（头级连续分配）、P083（层间级联分配）更粗。此外该指标衡量的是 prompt 侧敏感度，对解码期动态注意力的变化不敏感。

## 4. 实验证据

在广泛的 LLM 与基准上，显存下降约 30%–70%，吞吐最高提升 2.2×。论文的核心验证方式是「预算分配 + 三种现成序列算法」的组合实验，说明增益来自分配维度而非某个特定打分函数。代码开源。

## 5. 第一性原理再审视

第一，用「注意力前后表示差异」衡量层敏感度有一个隐含前提：差异小等价于该层的信息可由更少的 KV 支撑。但差异小也可能意味着该层做了高度非线性但**不可省略**的映射（例如把关键事实压进某个方向），此时削减预算会破坏能力而指标并不预警。论文应给出该指标与下游任务损失的相关性曲线，而不只是分组后的端到端结果。第二，层敏感度是**输入相关**的：同一模型在代码、长文、对话上可能给出不同的层排序；在线计算虽避免校准漂移，但也意味着分配随输入波动，需要验证这种波动不会引起输出不稳定。第三，30%–70% 的区间跨度大，说明收益依赖模型与基准；应报告在固定预算下相对统一分配的增益（这才是「分配」这一贡献的净效应）。第四，与 P037（头间分配）、P083（层间 + 时序级联）相比，二维中只做了「层」这一维，未涉及头与时间维度，组合空间仍大。

## 6. 与相邻工作的关系

与 P037（Ada-KV 头间预算分配）构成互补的维度：一个在层内按头分配、一个按层分配，二者可叠加；与 P083（CAKE 层间 + 时序级联分配）在目标上最接近，差别是敏感度度量与级联 vs 两分组的做法；与 P058（PrefixKV 在 LVLM 中搜索层间前缀配置）共享「层间预算不均」的判断；与 P070（层间量化精度搜索）在维度上平行但分配的是比特而非 token 预算。定位上属于「预算分配」这一子问题的早期系统化工作之一。

## 7. 可迁移点与开放问题

可迁移：(a) 用「组件对表示的实际影响」而非「组件的内部行为统计」来评估组件重要性，是更稳健的重要性度量范式；(b) 先做资源分配再做层内选择的解耦思路，可用于任意多层次资源优化问题。开放问题：敏感度指标与任务损失的相关性；在线分配的稳定性；两层分组与更细粒度分配之间的收益差距；与头间分配、时序分配的联合优化；以及在长思维链等注意力剧烈漂移场景下的适用性。
