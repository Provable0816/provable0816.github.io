# P075 M+: Extending MemoryLLM with Scalable Long-Term Memory

- 会议/来源：ICML 2025（主会）
- 方向簇：ARCH
- 链接：https://proceedings.mlr.press/v267/wang25au.html
- 本地全文：cache/txt/P075.txt

## 一句话贡献

针对隐空间记忆路线的代表工作 MemoryLLM 的**容量饱和**问题给出扩展：MemoryLLM 把所有层的隐状态压缩成一个约 1B 参数的记忆池，在 16k 序列内有效，但超过 20k token 便难以保留知识；M+ 在其上加入长期记忆机制与一个**协同训练的检索器**，在生成过程中动态取回相关信息，把知识保持跨度从不足 20k 扩展到 160k 以上，而 GPU 显存开销相当。

## 1. 问题与第一性原理动机

隐空间记忆（把历史压进高维向量）相比 token 级记忆的优势是不占上下文窗口、不需要外部检索基础设施；代价是**容量是硬上限**——定长状态能编码的信息量有限，超限后新信息必然覆盖旧信息。这就是 MemoryLLM 在 20k 之后失效的根本原因：不是训练不足，而是信息瓶颈。要突破它，必须引入某种**可扩展的存储**，而这又意味着重新引入检索。M+ 的问题设定因此是：如何在保留隐空间记忆优点的同时，给它接上一个可扩展的长期存储。

## 2. 核心洞察

洞察是：**记忆池与检索器应当协同训练，而不是各自独立**。常规做法把检索器单独训练好后外挂；但检索的「查询」来自模型内部状态，而模型内部状态本身又是被记忆池塑造的——两者的表示空间必须对齐，否则检索到的内容与模型当前的计算需求错配。M+ 通过 co-trained retriever 让检索目标与生成任务共同优化，从而在隐空间记忆已达瓶颈时，仍能把「该记住什么」的决策交给长期存储与检索环节。这一思路与 Cartridges（P020）的 context distillation 有共同逻辑：记忆的写入/检索必须由任务目标驱动。

## 3. 方法机制

(1) 保留 MemoryLLM 的隐空间记忆池作为短期/中期的压缩状态；(2) 增加长期记忆模块用于存放超出一阶容量的信息；(3) 训练一个与模型协同的检索器，在生成过程中动态取回相关内容并注入。代价是：协同训练需要额外数据与算力；检索器带来在线延迟；长期记忆的存储仍需管理（写入策略、去重、更新）。摘要未给出延迟与存储规模的细节。

## 4. 实验证据

在长上下文理解与知识保持类基准上，M+ 显著优于 MemoryLLM 与近期强基线；最核心的数字是知识保持跨度从**不足 20k 扩展到 160k 以上**，且 GPU 显存开销与之相当。代码开源。

## 5. 第一性原理再审视

第一，「160k 以上」这一提升改变了方法的性质而非仅仅改善指标：一旦超出一阶记忆容量，系统实际上变成了「隐空间压缩 + 外部检索」的混合体，其成败更多取决于检索质量而非记忆压缩本身。论文应给出检索命中率与端到端性能的关系，否则无法判断瓶颈是否已转移到检索侧。第二，「显存开销相当」需要在语义上澄清：若长期记忆存放在 CPU/磁盘，则显存确实不变但引入了新的延迟与带宽成本；这类隐藏成本在长上下文服务中是决定性的（参见 P064、P068 对存储路径的讨论）。第三，知识保持的评测通常以「能否回答早期事实」为标准，但真实长期记忆还包括矛盾消解与信息演化（P027）以及时序推理（P024）；这些维度缺少证据。第四，与 MemoryLLM 的对比中，M+ 额外引入了训练组件与检索，因此提升既可能来自容量扩展、也可能来自更强的训练信号，需要消融来分离。第五，隐空间记忆的一个隐含问题是不可解释性——存储的是稠密向量，出错时无法审计，这在需要可追溯性的应用中构成障碍。

## 6. 与相邻工作的关系

与 MemoryLLM（被扩展的对象）同属隐空间记忆路线；与 P074（Peripheral Memory，把记忆外设化并加相关位）在设计上最接近——都在隐空间记忆之上叠加外置结构与读写控制；与 P044/P045 的 KV 复用与压缩不同，后者管理的是单次推理的缓存而非跨会话的知识；与 P024/P026 的显式图式记忆相比，M+ 的记忆仍是稠密表示，可审计性差但检索成本更低。整体属于「隐空间记忆 + 可扩展检索」的混合路线。

## 7. 可迁移点与开放问题

可迁移：(a) 「压缩状态到达容量上限后，用协同训练的检索接口扩展，而非简单加大状态」是处理定长记忆瓶颈的通用策略；(b) 记忆与检索器协同训练这一原则，适用于任何「内部状态驱动检索」的系统（agent 长期记忆、个性化助手）。开放问题：瓶颈是否已转移到检索侧；长期存储的延迟/带宽成本；矛盾消解与时序更新的评测；消融分离容量扩展与训练增益；以及隐空间记忆的可解释与可编辑性。
