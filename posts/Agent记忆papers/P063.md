# P063 Improving Model Representation and Reducing KV Cache via Skip Connections with First Value Heads

- 会议/来源：NeurIPS 2025
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/cf326db238429dac58625977f6fb8265-Abstract-Conference.html

## 贡献

提出 SkipV1Former：从第二层起，每层**复用第一层 Value 头的一半**、仅计算另一半，从而把 Value 投影与 V cache 削减近 50%；同时主张这种做法不仅省显存，还**提升表示质量**——论文在理论上说明把未经压缩的第一层 Value 直接路由到深层可以恢复压缩过程中丢失的信息，并加速模型的隐式元优化（implicit mesa-optimization）。

## 机制要点

与「加更多层/更宽层」这一常规扩容路线相反，SkipV1Former 通过跨层复用第一层的值表示来同时降低资源占用与增强表示。这一设计与 GQA、MLA 等注意力结构改造正交，且论文给出把已有 MHA 检查点 uptrain 成 SkipV1Former 的配方（仅需 10–15% 额外计算），显著降低了落地门槛——这是相对多数「从零训练」的架构创新更实用的地方。

## 关键结果

跨模型规模，KV cache 一致减少约 25%，同时困惑度优于标准 MHA Transformer 及部分先进变体；与 YOCO 组合时 KV cache 近乎减半且性能仍提升；可与 GQA、MLA 叠加获得进一步节省。

## 局限与定位

需要注意数字口径：V cache 近乎减半只对应**整体 KV cache 约 25%** 的下降（因为 K 侧未变），二者不能混用；论文在摘要中区分了两者，读者应沿用该口径。第二，「困惑度更优」是在同等或更少资源下取得，但困惑度与下游任务能力（尤其长上下文检索、多步推理）并不总是一致，缺少 LongBench/RULER 类评测会削弱结论强度。第三，复用第一层 Value 的合理性依赖「第一层的值承载了通用且未被压缩的信息」这一假设，其成立条件（模型深度、任务类型）未见系统分析；若某些任务需要深层特化的值表示，共享会构成瓶颈。第四，uptrain 配方虽省算力，但仍需在目标域上继续训练，尚非免训练方案。定位上属于架构层面的 KV 削减，与量化/淘汰（P034、P045 等）正交且可叠加。
