# P197 MM-MEM: From Verbatim to Gist — Distilling Pyramidal Multimodal Memory via Semantic Information Bottleneck for Long-Horizon Video Agents

- 会议/来源：ACL 2026（主会）
- 方向簇：VLM
- 链接：https://aclanthology.org/2026.acl-long.533/
- 本地全文：cache/txt/P197.txt

## 贡献

提出基于模糊痕迹理论（Fuzzy-Trace Theory）的**金字塔式多模态记忆** MM-MEM：自下而上构建 Sensory Buffer（细粒度视觉证据）→ Episodic Stream（情节流）→ Symbolic Schema（高层文本抽象）三层记忆，配合 SIB-GRPO 做动态记忆管理（删除冗余、保留任务相关语义）与自上而下的层级检索，从而在长时程视频理解中同时避开「视觉稠密堆积导致高延迟冗余」与「激进字幕化导致细节丢失与幻觉」两个极端。

## 机制要点

架构见 Figure 2：左侧自下而上把原始帧逐级抽象为符号 schema（对应语义信息瓶颈的压缩路径），右侧自上而下按查询做层级检索（先定语义层，再回落到情节/感知层取证）。SIB-GRPO 作用于记忆管理，把「冗余」与「任务相关语义」区分开——这是压缩的关键判据：不是按时间远近，而是按任务相关性。Figure 1 用四格对比刻画既有范式（视觉中心、文本中心）与本文的灵感来源。

## 关键结果

评测覆盖四类基准：Video-MME（短/中/长三档，含与不含字幕）、MLVU（九任务，3 分钟至 2 小时）、VSTREAM-QA（在线流式，EGO/MOVIE）以及自建的 HD-EPIC++（Table 3）。Table 1 报告 Video-MME 与 MLVU，论文称在 Video-MME 上取得 **5.1% 相对提升**（含/不含字幕两种设置均成立）；Table 2 报告 VSTREAM-QA-EGO，MM-MEM 取得 **30.28%**，超过最强对手 Qwen3-VL-8B。Table 4 给出效率对比（记忆构建时间 Con. ## 局限与定位

第一，金字塔三层是**固定的层级设计**（对应 gist/verbatim 二分），层数与每层容量不可学习，面对任务需求变化时缺少自适应伸缩。第二，SIB-GRPO 的奖励来自任务相关性，训练信号与下游任务耦合，跨任务迁移成本未知。第三，符号层以文本承载高层语义，仍可能继承文本中心路线的信息损失，论文用「自上而下回到感知层取证」缓解——这一手段的有效性依赖检索准确率，属于关键但未充分展示的环节。定位上，它把「压缩粒度层级化」这一先验（见 P172/P173 关于语义单元与句级压缩的讨论）从文本扩展到多模态，并用 RL 决定删什么，与本方向「压缩即丢弃 + 丢弃依据可学习」的主线一致。
