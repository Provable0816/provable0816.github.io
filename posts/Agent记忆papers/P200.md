# P200 RobustKV: Defending Large Language Models Against Jailbreak Attacks via KV Eviction

- 会议/来源：ICLR 2025（主会）
- 方向簇：KV
- 链接：https://openreview.net/forum?id=38bbae17d60940f3ee14dfd1035d7542
- 本地全文：cache/txt/P200.txt

## 贡献

把 KV 淘汰从「效率优化」变成「安全机制」：RobustKV 依据重要性排序**主动淘汰最低分 token 的 KV**，而由于 jailbreak 提示为了生效必须让自身 token 获得高注意力，这会反过来压低被隐藏的有害查询 token 的重要性，从而把有害内容从缓存中挤出去，使模型无法生成恶意回答。

## 机制要点

论证链条见 Figure 1、Figure 2（有害查询与 jailbreak 提示中 token 重要性（按升序）的排名对比）：jailbreak 的有效性依赖「注意力倾斜」，而注意力是一份竞争性的权重预算，倾斜即意味着对有害查询 token 的忽视；RobustKV 只需在缓存层执行既有的淘汰逻辑即可利用这一结构性事实。它的优势在于**不依赖识别 jailbreak 模板**，因此对自适应攻击有天然抵抗力；更巧妙的是它制造了一个 **evasiveness dilemma**：攻击者若想让有害 token 保住注意力，就必须削弱 jailbreak 提示本身的效力，从而又会被模型内置护栏拦住。

## 关键结果

Table 1 报告代表性 jailbreak 攻击（AutoDAN、GCG、AdvPrompter 等）在各类防御下的攻击成功率（ASR）；Table 2、Table 3 分别报告防御对**短文本任务**（AlpacaEval / VicunaEval 的 WinRate）与**长文本任务**（与其他 KV 淘汰方法同预算对比）的一般能力影响；Table 11 给出 Llama2-13B 上对 AutoDAN 的防御效果与效用保持（ASR 与 WinRate 并列）。论文的结论是：在有效降低 ASR 的同时保持良性查询上的通用表现，并对自适应攻击保持鲁棒。

## 局限与定位

第一，「淘汰低分 token」是一个**全局**操作，良性长上下文中的低注意力 token（如引言中的背景设定、长文档中的关键细节）也会被同等淘汰——论文用短/长文本任务证明一般能力「保持」，但需要核对长文本任务上的预算与基线是否公平。第二，安全有效性依赖「jailbreak 必然抬高自身 token 注意力」这一前提；对于**低注意力即可生效**的攻击（例如把有害意图分散到大量普通 token，或利用多轮累积），该假设失效，这类攻击未被覆盖。第三，ASR 评测本身对解码采样、判官模型敏感，跨论文比较需谨慎；论文的代码与告警说明表明其生成了有害内容样本。定位上，它是本方向中罕见的「压缩即安全」案例，说明 KV 淘汰的副作用可以转化为机制优势——这一视角对设计任何记忆压缩策略都有启示：**压缩的选择准则决定了被丢弃信息的性质，而这一性质可以被主动利用**。
