## 一句话贡献

把超长文本处理改写成一个「分段读入—覆写记忆」的 agent 工作流，并用多对话 DAPO（Multi-Conv DAPO）以最终答案奖励端到端地优化记忆读写策略；仅用 8K 训练窗口的 Qwen2.5-7B/14B，在 RULER-HQA 上外推到 3.5M token 仍保持大部分性能（摘要称损失 <10%），512K NIAH 超过 95%。

## 1. 问题与第一性原理动机

自回归因子分解 $p(x_{1:N})=\prod_n p(x_n\mid x_{1:n-1})$ 要求所有历史（或至少其隐状态）留在活动上下文中，这正是长文本瓶颈的根源：状态无界增长，注意力成本随之二次增长。要打破它就必然引入**有损的定长状态**。MemAgent 的改写是把无界历史换成定长记忆 $m\in\mathbb{V}^M$：

$$p(x_{1:N})=\sum_{m_{1:K-1}}\prod_{k=1}^{K}\underbrace{p(c_k\mid m_{k-1})}_{\text{read}}\underbrace{p(m_k\mid c_k,m_{k-1})}_{\text{write}}$$

每步只需 $O(C+M)$，整体线性。但由此产生一个不可回避的第一性问题：**记忆该保留什么，取决于未来会被问到什么**，而重建式（reconstruction）目标无法回答这个问题。因此作者把读写动作建模为 MDP，用任务结果奖励去优化「记忆状态的条件分布」，让记忆从「重建语料的充分统计量」变成「完成任务的充分统计量」。

## 2. 核心洞察

第二条洞察是信用分配的结构。同一 query 会生成多条**上下文相互独立**的对话（每条 = 一次完整的分段读入与覆写），其中只有包含最终答案的那条承载了完整证据链。作者据此把 GRPO 的 (group, token) 结构扩展为 (group, conversation, token)：优势由含答案的那条对话算出、然后**均匀广播**给同一 sample 的其余对话（并沿用 Dr. GRPO 不除以标准差的处理）。这样即使无答案的对话也能学到「如何读」，覆盖了「读法不同、答案相同」这一天然的数据增广。

## 3. 方法机制

工作流上，文档被切成 $K$ 个连续块，模型迭代读块并用固定模板覆写记忆面板，流走完后调用 Answer-Generation 模块输出答案；记忆是覆盖式（overwrite）而非追加式，因此容量恒定、无索引结构。训练上，8K 窗口被显式分配为 1024 query + 5000 chunk + 1024 memory + 1024 output，其余留给 chat 模板；采用两阶段课程强化学习，第一阶段练基础记忆能力，第二阶段迁移到更杂的上下文与更难任务；奖励是规则校验器给出的答案等价性 0/1。实现基于 verl，骨干为 Qwen2.5-7B/14B-Instruct。

## 4. 实验证据

Table 1（RULER-HQA 准确率）：RL-MemAgent-14B 从 7K 的 80.47 到 56K 的 83.59，224K 77.34，896K 75.78，1.75M 78.91，3.5M 71.09；7B 在 3.5M 仍有 71.88。对照中 Qwen2.5-Instruct-14B-1M 在 896K 掉到 0.00，QwenLong-L1-32B 从 112K 的 31.25 降到 896K 的 11.72，1.75M 起标为 N/A。Table 3（LongBench-QA 平均）：MemAgent-14B 51.0、7B 48.2，高于 QwenLong-L1-32B 的 50.7 与 DS-Distill-Qwen-32B 的 49.0，但优势很小。Table 2（LongBench-SUM）：RL-MemAgent-14B 在 GovReport 平均 21.80、QMSum 31.39，为全场最高。NIAH（Figure 5）：RL-MemAgent 在 512K 三档难度下几乎无退化，原文称损失小于 5%，并强调 512K 评测涉及 100 轮以上对话。消融（Figure 5/6/7）：去掉 RL 后 MemAgent 仍优于骨干但随长度显著下滑，说明 RL 是外推能力的必要条件而非锦上添花。

## 5. 第一性原理再审视

有三个被掩盖的前提。第一，**query 在一开始就已知**——8K 窗口里明确划出 1024 token 给 query，且片段在 query 之后才读入，所以记忆写入天然可以 query-conditioned；真实长上下文 agent 场景中问题往往在读完大量材料之后才出现，此时「该记什么」的难度完全不同，本文没有测这种设定。第二，外推证据的分布匹配：RULER-HQA 的合成方法与第一阶段训练数据相同，所以 3.5M 上的稳定表现更像分布内插值而非异域外推；真正异域的 LongBench-QA 上，14B 模型只领先 32B 的 QwenLong-L1 0.3 分。第三，NIAH 是极低信息密度的单针任务，而覆写式记忆天然适合「只留一条关键信息」；它无法检验多事实竞争下的保留策略。此外还有两个工程性缺口：3.5M 上下文按 5K 块切分需要约 700 次串行前向，「线性复杂度」只描述了单步开销，论文没有报告延迟、吞吐或总成本；记忆容量固定为 1024 token，但正文未给出记忆大小的消融，因此「容量—精度」曲线未知。最后，优势广播把所有对话同等加权，当多条对话的读法质量差异很大时，这种均匀归因会把好路径和坏路径混在一起，缺乏对「读法质量」的直接监督信号。

## 6. 与相邻工作的关系

与 Cartridges（P020）共享同一根本信念——记忆应针对 query 分布而非数据分布来优化——但 Cartridges 在离线把语料固化成 KV，本方法在推理时用策略在线覆写记忆；与 RMT/Recurrent Memory Transformer 一类分段记忆架构相比，本方法把更新规则交给 RL 策略而非固定注意力；与 MemGPT 式「分页 + 虚拟上下文」相比，本文不维护外部存储、直接覆写，代价是不可回溯；与 LongBench 上评测的流式/压缩基线相比，其定位是「训练一个会管理自己记忆的模型」而非「压缩一段上下文」。

## 7. 可迁移点与开放问题

可迁移：把长上下文处理形式化为带定长状态的 MDP，并用最终结果奖励优化状态更新，这一范式可直接用于多轮工具调用、持续对话记忆、代码库级 agent 的上下文管理；「同一样本多条独立路径、优势广播」是稀疏奖励下廉价而有效的信用分配技巧。开放问题：query 后置（先读后问）时记忆策略如何定义；覆写造成的不可逆信息损失能否用量化或外部索引补偿；记忆容量的最优值与任务信息密度的关系；以及把延迟/成本纳入奖励后策略会怎样变化。
