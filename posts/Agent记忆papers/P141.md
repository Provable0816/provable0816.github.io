# P141 Recall with Reasoning: Chain-of-Thought Distillation for Mamba's Long-Context Memory and Extrapolation

- 会议/来源：EMNLP 2025
- 方向簇：CTX
- 链接：/2025.emnlp-main.235/

## 贡献

针对 Mamba 的困境——**理论上的无限上下文潜力在序列远超训练长度时无法兑现**——提出 Recall with Reasoning（RwR）：从一个教师模型蒸馏**思维链式摘要（CoT summarization）**，把这些摘要作为 CoT prompt 前置到微调数据中，教 Mamba 主动在长上下文上**回忆并推理**。在 LONG-MEMEVAL 与 HELMET 上，RwR 优于 Mamba 上的既有长期记忆方法，并在相近预训练条件下相对可比的 Transformer / 混合基线提升了 Mamba 的长上下文表现，同时**保持短上下文能力，且不改变架构**。

## 机制要点

方法的思路是用**行为训练**弥补**状态容量**的限制：Mamba 的状态是定长且有损的，靠扩大状态并不现实；因此改为教模型一种「主动回忆与推理」的行为模式——通过 CoT 摘要示范「该如何从长上下文中提取并利用信息」，把能力从架构层面转移到行为层面。这与 P079（GCA 让检索器端到端学习「对生成有用」的检索）、P020（Cartridges 让训练目标匹配查询分布）共享同一逻辑：**当表示能力受限时，用学习到的行为来补偿**。第二点是蒸馏的作用：教师模型提供的是「如何回忆」的过程示范，而非答案，因此训练信号更接近可迁移的策略而非具体知识。

## 关键结果

在 LONG-MEMEVAL 与 HELMET 上优于 Mamba 上的既有长期记忆方法；在相近预训练条件下改善 Mamba 的长上下文表现并优于可比的 Transformer/混合基线；短上下文能力不受损；不改变架构——最后两条尤为重要，说明收益不是通过牺牲通用能力或以架构改造换来的。

## 局限与定位

第一，评测仅限 Mamba 这一类状态空间模型，方法是否对其它次二次架构（线性注意力、RWKV 等）同样有效需要验证；「不改变架构」的优点是相对的——它仍需微调与教师模型蒸馏。第二，CoT 摘要会**增加推理时的长度与成本**：让模型显式回忆与推理意味着更多生成 token，这与长上下文场景下的效率目标存在张力，论文需要给出端到端的成本对比（不仅是质量提升）。第三，蒸馏依赖教师模型的记忆能力，学生上限可能被教师的示范质量约束（P028 的 MARC 也面临同一问题）。第四，LONG-MEMEVAL 与 HELMET 主要评测长期记忆与长上下文能力，对需要精确逐字检索的合成任务覆盖有限，而 Mamba 类架构的弱项恰在此处（P056 对线性记忆牺牲精确召回的论述）。第五，与 P057（RAMba 给 RNN 加层级稀疏注意力实现随机访问）相比，RwR 走的是纯行为路线、不改机制，其能力上限受线性状态本身的限制；二者构成「改架构 vs 改行为」的对照。

## 定位

RwR 与 P080（DSLA-Serve 把 Transformer 层逐步替换为线性注意力层）、P056（二次—线性记忆混合）同处「次二次架构如何获得长上下文能力」这一问题域；其独特之处在于完全不动架构，仅通过 CoT 蒸馏改变行为，因此落地成本最低，但天花板也最受架构约束。
