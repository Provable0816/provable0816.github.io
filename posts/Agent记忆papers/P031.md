# P031 Seeing, Listening, Remembering, and Reasoning: A Multimodal Agent with Long-Term Memory

- 会议/来源：ICLR 2026
- 方向簇：AGENT
- 链接：/paper_files/paper/2026/hash/ec370e882e8a02be955679ddbd2731b8-Abstract-Conference.html

## 贡献

提出 M3-Agent：一个具备长期记忆的多模态 agent，用「记忆化」与「控制」两条并行进程分别处理实时视听输入与外部指令，记忆按实体为中心（entity-centric）组织，并区分 episodic（具体事件，含说话人、动作、时间与跨模态线索）与 semantic（从事件中逐步抽象的世界知识）两类。同时发布 M3-Bench：100 段机器人视角新录制视频（M3-Bench-robot）与 920 段网络视频（M3-Bench-web），覆盖人物理解、常识抽取与跨模态推理等题型。

## 机制要点

记忆构建阶段把视频流切成片段，抽取实体与事件，形成以实体为枢纽的图结构，并把视听证据挂到同一实体节点上，使同一人物的语音、外观与行为在检索时聚合；语义记忆由 episodic 记忆逐步归纳而来，而不是另行抽取。控制阶段给定指令后自主进行多轮推理，用不同粒度的检索在记忆图上取证。训练采用强化学习而非纯提示工程。

## 关键结果

相对最强基线（使用 Gemini-1.5-pro 与 GPT-4o 的提示式 agent），M3-Agent 在 M3-Bench-robot、M3-Bench-web、VideoMME-long 上分别高 6.7%、7.7%、5.3% 准确率（摘要）。数据集构造上要求每段视频至少 12 个 QA、单个事件至少对应 15 个问题，以保证题目必须依赖长期记忆才能回答。

## 局限与定位

作者自陈的后续方向是改进语义记忆形成的注意力机制、以及发展更丰富但更高效的视觉记忆，说明视觉侧记忆仍是瓶颈。证据缺口：基线与自研方法在模型规模、训练数据和是否经 RL 微调上并未对齐（基线是提示式通用模型），因此 6.7/7.7/5.3 个点同时混合了架构、训练与记忆三方面因素；benchmark 由团队自建自评，缺少第三方复现；机器人视角数据仅 100 段，规模偏小，且实体与说话人识别依赖上游感知模块，论文未给出感知误差的敏感性分析。定位上属于「记忆组织 + agent 控制」的联合设计，与纯视频长上下文建模（P029）互补。
