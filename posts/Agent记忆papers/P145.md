# P145 Prompt Compression for Large Language Models: A Survey

- 会议/来源：NAACL 2025（主会）
- 方向簇：BENCH
- 链接：/2025.naacl-long.368/
- 本地全文：cache/txt/P145.txt

## 一句话贡献

对 prompt 压缩做系统综述：把方法分为**硬 prompt 方法**与**软 prompt 方法**两大类，先比较其技术路线，再从**注意力优化、参数高效微调（PEFT）、模态集成、新合成语言**四个视角解释这些方法的机制，随后梳理各类方法在下游任务上的适配方式，最后分析当前局限并给出若干未来方向。

## 1. 问题与第一性原理动机

综述存在的理由是：prompt 压缩是长上下文成本问题中**最直接作用于输入端**的一类优化——相比架构改造与实现层优化，它直接减少一次推理调用的资源占用，且可与前两类叠加。但方法数量增长很快，各方法的目标函数、评估方式与适用场景差异极大，导致横向比较困难。把「硬 vs 软」作为第一分类维度是合适的，因为它直接决定一项关键工程约束：方法能否用于黑盒 API（硬 prompt 保持离散 token，软 prompt 需要访问内部表示）。

## 2. 核心洞察

综述提出的四个解释视角有实质价值。「注意力优化」把压缩理解为对注意力分布的引导；「PEFT」把软 prompt 压缩与参数高效适配联系起来（两者都在学习「如何用少量参数承载信息」，与 P106 的模态桥接、P115 的解耦压缩器同源）；「模态集成」提示压缩表示可以跨模态（与 P106 xRAG、P127 Glyph 的思路相通）；「新合成语言」则把压缩推向「让模型使用非自然语言的紧凑表示」。这四个视角的共同价值是：把看似分散的方法归入少数几条机制性原则，从而便于判断新方法的归属与局限。

## 3. 方法机制

综述的组织方式本身即其「方法」：以硬/软 prompt 为主线分类，用四个视角解释机制，再按下游适配（问答、摘要、检索增强、多任务）组织现有证据，最后列出局限与未来方向。这种「分类—机制—适配—挑战」的四段结构，使读者可以按自己的约束（是否可访问模型内部、是否有训练预算）快速缩小候选方法范围。

## 4. 实验证据

作为综述，其证据形式是**覆盖范围与分类的一致性**，而非单一指标：论文给出各方法的技术比较、机制解释与下游适配梳理。论文也明确指出当前方法的局限（如软 prompt 的黑盒不可用性、硬 prompt 的不可恢复删除）并展望若干方向。

## 5. 第一性原理再审视

第一，综述的时间点决定其覆盖边界：本批中更晚的工作（P098 的率失真极限、P113 的面向检索的压缩、P122 的「记忆—利用鸿沟」、P134 的分级保真）出现在其收尾之后或未被覆盖，因此使用该综述时应补充这些进展。第二，综述类工作的固有局限是无法对方法做统一实证对比，因此「各方法效果」只能转述原文数字，而原文的实验设定（模型、任务、压缩率口径）差异极大；读者不应把不同来源的数字直接比较——这正是 P158（PCToolkit）试图解决的碎片化问题，两者互补。第三，四个解释视角中「模态集成」与「新合成语言」在当前证据下偏前瞻，其可行性依赖具体实现。第四，综述未涉及 KV/缓存级压缩这一并行发展的领域；对长上下文成本问题而言，prompt 压缩与 KV 压缩是互补的两层（前者跨 API 可用、后者需本地模型），选型时应同时考虑。

## 6. 与相邻工作的关系

与 P158（PCToolkit）构成「地图与可执行环境」的互补：综述给分类与机制，工具包给统一实现与评测；与 P098（prompt 压缩的率失真极限）互补：本综述梳理方法，P098 给出该类方法的能力上界；与 P054（EHPC）、P144（Perception Compressor）、P113（CoLoR）等具体方法构成「综述与实例」的关系；与 P094（SCBench）、P117/P125（长期记忆评测）同属该领域的基础设施类工作。定位上，这是 prompt 压缩子领域的重要参考与入门地图。

## 7. 可迁移点与开放问题

可迁移：(a)「以工程约束（黑盒可访问性、训练预算）作为第一分类维度」的组织方式，对任何方法繁多且约束差异大的领域都适用；(b) 用少数机制性原则（注意力、PEFT、模态、合成语言）归纳方法，是降低领域认知负担的有效手段。开放问题：硬/软 prompt 的适用边界能否被量化；压缩目标与下游用途的对齐（P113 与 P098 已给出部分答案）；覆盖后续进展与 KV 级压缩的更新；以及统一评测口径的建立（P158 的方向）。
