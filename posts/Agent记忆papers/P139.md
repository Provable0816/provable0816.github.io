# P139 Think Clearly: Improving Reasoning via Redundant Token Pruning

- 会议/来源：EMNLP 2025（Findings）
- 方向簇：CTX
- 链接：/2025.findings-emnlp.1169/
- 本地全文：cache/txt/P139.txt

## 一句话贡献

观察长思维链推理路径存在**大量冗余**，且答案正确与错误时的注意力分布形态不同（错误答案伴随更强的注意力稀疏/分散）；论文主张**主动移除推理过程中的冗余可以提升性能**——相当于通过裁剪干扰实现「清晰思考」。具体做法是：在每个中间推理步骤末尾插入显式指令及其对应的特殊 end-of-thinking token，用 token 级注意力到该 token 的分数来系统识别冗余；并进一步提出**结构感知剪枝**，优先删除贡献低的整个推理片段，而非零散地删 token。

## 1. 问题与第一性原理动机

长链推理（long CoT）被广泛用于提升准确率，但论文指出其成本与收益不成比例——推理路径中包含大量重复、犹疑与自证。更值得注意的是第二个观察：**错误答案表现为更强的注意力稀疏**，即答错时注意力被分散到更多 token 上。这一现象指向一个因果假设：冗余内容既是计算浪费，也是**注意力的干扰源**；若如此，删除冗余就不仅是提速，而是直接改善推理质量。这一假设把「压缩」从效率手段提升为质量手段，是本文与绝大多数压缩工作的根本差别（P050 也观察到推理模型的长输出中冗余与失败相关，但把冗余当作压缩目标而非质量改进手段）。

## 2. 核心洞察

洞察是**用「到终点的注意力」作为冗余的度量**。借助在每步末尾插入的显式指令与 end-of-thinking token，可以让模型对「这句话是否推进了结论」给出可观测的注意力信号；注意力低的 token 即为可删的冗余。这种方法比通用的重要性打分更贴近推理任务的结构——因为它把「对最终结论的贡献」显式地引入打分。第二个洞察是**结构感知**：冗余在推理中通常以「整段无效思辨」而非「随机散落的无关词」形式出现，因此按片段删除比按 token 删除更符合冗余的真实形态（这与 P039 用 chunk 作为压缩单位的动机一致：选择单位应与语义结构匹配）。

## 3. 方法机制

(1) 在每个中间推理步骤末尾插入结束指令与特殊 token；(2) 测量各 token 对该特殊 token 的注意力；(3) 低注意力 token/片段视为冗余；(4) 用结构感知剪枝优先移除贡献低的推理片段。代价是：插入显式指令会改变被评测模型的输出格式（对既有模型可能需要提示工程或微调配合）；剪枝发生在推理过程中，属于动态干预，实现复杂度高于后处理式压缩；注意力到特殊 token 的分数是否忠实反映「逻辑贡献」需要验证。

## 4. 实验证据

论文报告两个层面的结果：其一，冗余确实存在且错误答案伴随更强注意力稀疏（诊断性证据）；其二，主动剪枝带来性能提升（干预性证据）。这种「诊断 + 干预」的组合比单纯报告改进更有说服力；但需要核实改进是否在不同模型与任务上一致，以及剪枝带来的计算节省与质量提升哪个是主效果。

## 5. 第一性原理再审视

第一，核心因果链「冗余导致注意力稀疏 → 稀疏导致错误」需要更严格的验证：另一种解释是「模型不确定时生成了更多冗余」，即冗余是结果而非原因；区分二者需要干预实验（对同一推理路径人为注入冗余，观察是否更容易出错），论文若只做「删除冗余后变好」则只能证明相关性。第二，插入特殊 token 并测注意力这一手段依赖模型的指令遵循与格式一致性，对未在此格式上训练过的模型可能失效；摘要未说明所需的适配程度。第三，如果删除冗余真能提升准确率，那么一个自然推论是「应当训练模型直接生成更简洁的推理」，即把这一后处理收益内化到训练中；论文未讨论这一方向。第四，注意力到 end-of-thinking token 的分数是「贡献度」的代理，但推理中存在必要但低注意力的环节（例如设定前提条件），误删这类内容会造成系统性错误；这与 P111 的「惊奇即丢失」是同类风险。第五，与 P050（R-KV 针对推理冗余做 KV 压缩）相比，一个改推理内容、一个改缓存，二者可叠加：先剪掉冗余推理，再压缩其 KV。

## 6. 与相邻工作的关系

与 P050（R-KV 将推理模型中的冗余视为主要浪费并据此压缩 KV）在同一声明上最接近，但作用层面不同（内容 vs 缓存）；与 P135（DASH 利用表示稳定性跳过冗余计算）都在「识别并跳过冗余」上，但 DASH 针对预填充的计算、本文针对推理内容的语义冗余，二者互补；与 P039（ChunkKV 以 chunk 为单位压缩、提高索引复用）在「结构感知」这一点上同源；与 P038（注意力时间模式预测）在「注意力形态蕴含信息」这一判断上呼应。定位上属于把压缩从效率工具扩展为推理质量工具的代表工作。

## 7. 可迁移点与开放问题

可迁移：(a) 「冗余既是浪费也是干扰」这一判断提示压缩方法可能同时改善效率与质量，值得在其他任务（长文档生成、多轮对话）中检验；(b) 用「对最终结论的注意力」作为重要性度量，把打分与任务目标直接挂钩，是比通用启发式更贴近任务的做法。开放问题：冗余与错误之间的因果关系；特殊 token 机制对模型的适配要求；误删必要低注意力环节的风险；把收益内化到训练中；以及与 KV 级压缩的组合。
