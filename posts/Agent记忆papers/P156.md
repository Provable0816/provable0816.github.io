# P156 Efficient Multimodal Large Language Model via Dynamic KV Cache Quantization

- 会议/来源：AAAI 26
- 方向簇：VLM
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/39241

## 贡献

提出面向多模态 LMM 的**动态 KV cache 量化**策略：对 K 施加逐通道量化、对 V 施加逐 token 量化（利用二者各自的统计分布来分配精度），并引入**自适应的 token 与通道记录机制**，依据实时分布追踪动态调整量化参数，以缓解离群值的影响；为提升压缩效率，进一步实现**细粒度分组**，把 KV 张量划分为局部子组。

## 机制要点

技术路线是多模态场景下的量化工程改进：量化轴的选择沿用「key 按通道、value 按 token」这一已被广泛验证的经验（P101、P102、P107 都采用或讨论了这一分工），贡献点在于 (1) 用**实时分布追踪**替代静态校准参数，从而应对多模态输入分布波动大的特点——这与 P048（NSNQuant 通过规范化实现免校准）目标一致但手段不同（一个在线追踪、一个离线规范化）；(2) 细粒度分组以提升低比特下的表示能力，代价是量化元数据开销上升（P107 正是为降低该开销而设计通道可分离的方案）。因此该方法与 P107 在「精度 vs 元数据开销」这一权衡上立场相反，可以作为对照阅读。

## 关键结果

论文报告在多模态任务上改善了显存与精度的权衡；具体位宽、压缩比与基准数值需回看正文。

## 局限与定位

第一，「实时分布追踪」引入在线统计开销，且需要判断何时更新量化参数——更新过频会带来抖动、过疏则失去自适应性；摘要未给出更新策略与开销，这是评估实用性的关键。第二，逐 token/逐通道的动态参数意味着存储的参数数量随 token 数增长，细粒度分组会进一步放大这一开销；在极低比特区间，元数据可能占据可观比例（P107 的实证正说明这一点）。第三，评测以多模态任务为主，而量化最易失效的仍是需要精确视觉细节或文字识别的场景（P095 的视觉密集任务、P028 的细粒度视频）；缺少这类压力测试，结论强度受限。第四，与 P048（免校准 VQ）、P101（耦合量化）、P151（重要性与敏感性解耦）相比，本方法的差异点在于「动态」与「分组」，但未见与这些方法在同等比特下的系统对比。定位上属于多模态 KV 量化的工程改进型工作。
