# P098 Fundamental Limits of Prompt Compression: A Rate-Distortion Framework for Black-Box Language Models

## 一句话贡献

为黑盒语言模型下的 prompt 压缩建立了形式化框架：把「生成硬 prompt（离散 token）」的这一类方法统一起来，把**失真—速率函数（distortion-rate function）**写成线性规划并给出基于对偶的高效求解算法，从而得到该问题的**基本极限**；以该极限为基准测量现有压缩方法，发现它们与最优策略存在巨大差距，并指出**查询感知（query-aware）压缩的关键性**，据此提出 Adaptive QuerySelect 来缩小差距。

## 1. 问题与第一性原理动机

prompt 压缩长期缺乏「能压到多小」的参照系：论文不断提出新方法并在若干数据集上比拼，但没有任何结果能说明当前方法距离理论上限还有多远。这在方法论上是结构性的缺失——没有极限，就无法判断改进空间是否已经耗尽，也无法判断某个「新方法」的收益是否只是把别人没调好参数的部分补上。因此把问题形式化为率失真问题（在给定失真约束下最小化压缩后的 token 数）并提供可计算的极限，是这类研究走向成熟的必要一步。

## 2. 核心洞察

框架的关键假设与结论有三点：(1) 压缩器对 LLM 是**黑盒**的，只能给出离散 token 序列（而不是软提示或激活），这一限制与真实 API 使用场景一致；(2) 在该设定下，最优压缩可表述为线性规划，其失真—速率函数可通过对偶问题高效计算，因此极限是**可算的**而非仅理论存在；(3) 由于目标是让黑盒模型回复正确的答案，压缩必然依赖下游任务/查询——这正是为什么 query-aware 压缩具有本质优势，而 query-agnostic 的压缩在信息上有可证明的劣势。第 (3) 点与 P045（KVzip 的查询无关压缩在复用场景的优势）构成一个重要的张力：**复用性与信息效率在同一预算下不可兼得**，选择取决于服务模式。

## 3. 方法机制

(1) 形式化：给定原始 prompt、黑盒 LLM 与查询，定义压缩后的离散 prompt 集合与失真度量；(2) 把失真—速率函数写成线性规划，并用对偶算法高效求解得到极限值；(3) 以该极限为基准评估现有方法（如 query-agnostic 的 LLMLingua 系列、query-aware 的选择式方法）；(4) 提出 Adaptive QuerySelect：在已有工作基础上做 query-aware、可变速率（variable-rate）的自适应版本以逼近极限。评测在两类数据上进行：一个由马尔可夫链合成 prompt + 自然语言查询/答案的合成数据集，以及一个小规模自然语言数据集。

## 4. 实验证据

主要发现有三：其一，现有 prompt 压缩方法与最优策略之间存在**较大差距**，说明改进空间显著；其二，query-aware 压缩相对 query-agnostic 有实质优势，验证了「知道下游问题再压缩」的必要性；其三，提出的 Adaptive QuerySelect 能缩小该差距。合成数据集与自然语言数据集上的结论方向一致。

## 5. 第一性原理再审视

第一，合成数据集的构造（马尔可夫链生成 prompt）是证明力的关键约束：在马尔可夫源上，信息结构简单、最优压缩的形态也较规整，因此「现有方法离极限很远」这一结论在真实自然语言分布上未必同样成立——作者用一个小的真实数据集做了补强，但规模有限。第二，失真度量是压缩系统的核心设计决策：若失真定义为「答案是否正确」这类 0/1 量，则率失真函数的形状会非常不连续，最优解可能退化为「在信息刚好足够时的相变」；若定义为连续近似，则与真实任务的相关性下降。论文的选择决定了极限在多大程度上代表真实需求，这一点需要读者核对。第三，黑盒 + 硬 prompt 的限定虽然贴合 API 场景，但也排除了软提示、KV 压缩等更大空间；因此这里的「基本极限」是**该类方法的上限**，而非 prompt 压缩的全局上限——标题的强度需在此限定下理解。第四，Adaptive QuerySelect 是在已有方法上的自适应变体，其逼近极限的程度说明「现有方法的主要短板在于未做速率自适应」，这是有价值的诊断结论，但方法与极限之间的剩余差距仍待研究。

## 6. 与相邻工作的关系

与 P019（COMI）、P054（EHPC）等实践型 prompt 压缩方法形成「理论极限 vs 工程实现」的对照：本工作提供了衡量它们的标尺；与 P033（Learning is Forgetting，把 LLM 训练视为有损压缩并用信息瓶颈刻画）在方法上有共同的理论根基（信息论视角下的压缩），但前者刻画的是**训练**、后者刻画的是**推理期的输入压缩**；与 P045（KVzip）以及 P042（KEYDIFF）等查询无关方法之间构成直接的取舍张力（信息效率 vs 可复用性）。定位上，这是该子领域少见的、给出可计算基本极限的理论工作。

## 7. 可迁移点与开放问题

可迁移：(a) 「先给出可计算的基本极限，再评估现有方法」这一研究范式可应用于检索预算、上下文预算、agent 记忆容量等所有「有损 + 有目标」的压缩问题，避免在无标尺情况下刷指标；(b) 把 query-aware 与 query-agnostic 的差异提升为可证明的结构性结论（而非经验观察），有助于指导系统在服务模式上做取舍。开放问题：在真实长文分布上极限与现状的差距有多大；失真度量如何设计才能既数学可处理又与下游任务对齐；把软提示与 KV 压缩纳入同一框架后的极限形态；以及 query-aware 压缩在 cache 复用场景下的可行折中。
