# P191 DigimonGPT: An Evolvable Agent with Hierarchical Human-like Memory for Video Question Answering

- 会议/来源：AAAI 2026（主会）
- 方向簇：AGENT
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/37523
- 本地全文：cache/txt/P191.txt

## 贡献

提出可演化的视频问答 agent DigimonGPT：用**层级类人记忆**（视频内**陈述性记忆** + 跨任务**程序性记忆**）替代「每次重新看视频」的范式，并设计**层级记忆回放**机制按相关性与问题复杂度选择记忆的类型与数量，使系统在多次问答中逐步累积经验。

## 机制要点

架构见 Figure 2，含记忆构造与层级记忆回放两大部分。陈述性记忆（intra-video）包含视频基础特征与从历史 QA 对中抽取的语义上下文；程序性记忆（inter-task）编码「解题经验」，即跨视频可迁移的问答套路。记忆构造流程见 Figure 3（用文本编码器把摘要转成语义向量存入向量库 $D_s$）；检索机制见 Figure 4，其核心是**按任务复杂度决定调取哪一层、调多少**——这是本文在「记忆压缩」意义上最有价值的机制：它把「取多少记忆」变成查询条件化的决策，而不是固定 top-$k$。

## 关键结果

实现基于 PyTorch + LangChain，语言侧用 GPT-4o-mini，视觉侧用 LaViLa 做帧级字幕、ViCLIP 与 text-embedding-3-large 做视觉—文本特征、RT-DETR + ByteTrack 做时空分析；在单张 RTX 3090 上以 in-context learning 与冻结主干评测。摘要称其准确率优于对照方法，并强调计算开销被记忆复用显著降低。

## 局限与定位

第一，系统由多个现成模型拼装（字幕、嵌入、检测、跟踪、LLM），误差会沿流水线累积，而各模块的贡献度分解（消融）是判断「层级记忆到底带来多少增益」的关键，摘要层面未给出。第二，程序性记忆以文本经验形式存储，其**抽取质量与泛化性**没有独立的评测协议——跨视频迁移是否真的发生，需要「同任务不同视频」的受控对比。第三，视频帧字幕是一种激进的有损压缩，对需要细粒度视觉证据的问题（计数、空间关系）风险最高，论文的问答类型分布需要核对。定位上，它与 P197（MM-MEM 的金字塔多模态记忆）构成多模态记忆的两条对照路线：P197 用固定三层金字塔 + RL 管理，P191 用陈述/程序二分 + 复杂度感知回放；两者都把「记住什么、取多少」作为一等公民。
