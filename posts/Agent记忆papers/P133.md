# P133 Octopus: Gated Selective Attention for Memory-Bounded Long-Context Inference in Large Language Models

- 会议/来源：ACL 2026（主会）
- 方向簇：KV
- 链接：/2026.acl-long.1631/
- 本地全文：cache/txt/P133.txt

## 一句话贡献

提出 OCTOPUS：为**已预训练的 Transformer** 赋予固定显存推理能力，而不承受线性化（linearization）带来的信息损失。方法用 **Gated Selective Attention** 改造注意力层——一个可学习模块，在上下文历史上施加自适应稀疏策略：动态打分并只保留高实用价值的 KV 状态，从而把无界 cache 变成紧凑且演化的记忆预算，并过滤无信息噪声。在 GSM8K 上，相同显存约束下比最先进的线性化基线高出 36 分以上。

## 1. 问题与第一性原理动机

论文把长上下文推理的两条路线摆在一起比较：Transformer 的 KV cache 随序列线性增长、推理受显存限制；次二次架构（线性注意力等）提供常数显存，但代价是**激进的状态压缩**，从而在复杂推理任务上性能显著下降（P056 对「线性记忆牺牲精确召回」已有系统论述）。OCTOPUS 的问题设定是：能否在不做线性化、不丢失精确召回能力的前提下，把显存固定下来？答案是把「固定显存」交给选择机制而非状态压缩——保留的仍是完整的 KV 状态，只是**保留哪些**由门控学习决定。

## 2. 核心洞察

洞察是**「固定预算」与「固定状态」是两件事**：线性模型通过把历史压成定长状态实现固定显存，本质上是有损压缩；而选择式方法通过保留一部分原始 KV 实现固定预算，保留下来的信息是**无损的**。因此选择式路线在需要精确召回的任务上更具优势，这正是它在 GSM8K 这类推理任务上大幅领先的原因。第二点是把选择做成**可学习门控**而非启发式打分：门控可以在训练中自动发现与任务相关的保留策略，避免手工设计的重要性度量（P045、P052、P042 都在不同程度上受制于启发式度量的局限）。

## 3. 方法机制

(1) 在预训练 Transformer 的注意力层上外挂 Gated Selective Attention 模块；(2) 该模块对上下文历史动态打分并保留高实用价值 KV，形成自适应稀疏策略；(3) 结果是把无界 cache 变成紧凑、持续演化的记忆预算。代价是：需要训练门控模块（虽非从头训练，但仍需适配阶段）；硬性选择可能不可微，需要训练技巧（如松弛或直通估计）；门控容量与上下文复杂度之间的匹配影响稳健性；固定预算意味着在信息密度极高的输入上必然有损失。

## 4. 实验证据

论文的核心数字是：在 GSM8K 上、相同显存约束下，OCTOPUS 比最先进的线性化基线高出 36 分以上。这一对比的价值在于它把问题定位在「固定显存是否必须以牺牲精确召回为代价」——36 分的差距说明线性化在该任务上的代价极大。摘要未给出长上下文检索类基准的结果，而这恰是另一类需要验证的场景。

## 5. 第一性原理再审视

第一，GSM8K 是数学推理任务，擅长暴露「状态压缩破坏精确计算」的问题，但不擅长暴露「选择机制漏掉关键 token」的问题（题目上下文短）。OCTOPUS 相对线性化的巨大优势不能直接外推到长文检索——在超长输入上，选择机制的召回率才是瓶颈，这需要 NIAH/多针类评测。第二，「记忆预算」是固定还是随输入自适应，决定了方法在信息密度变化时的鲁棒性；固定预算在长而稀的文本上浪费、在短而密的任务上不足的现象需要分析。第三，门控的引入使 KV 结构与预训练时不同，模型行为可能出现分布外效应（P071 的 LaCache 也面临同类问题：模型未见过「某些层看不到近期 token」的输入）。第四，与线性化基线的对比是「选择式 vs 压缩式」的路线之争，但缺乏与**同等预算下其它选择式方法**（P083、P084、P090、P107）的横向对比，因此无法说明 OCTOPUS 在选择式路线内部的位置。第五，改造已有 Transformer 的代价（适配训练的数据量、是否需要重训位置编码）影响落地可行性。

## 6. 与相邻工作的关系

与线性注意力 / 状态空间模型（常数显存路线）构成直接的路线对照；与 P084（DuoAttention 的检索头/流式头划分）、P090（RazorAttention 的检索头 + 补偿 token）、P083（CAKE 的层间 + 时序预算）、P107（ZipCache 的显著度比特分配）同属选择式压缩阵营，差别是 OCTOPUS 用可学习门控替代启发式打分；与 P045（KVzip 的重建式重要性）相比，一个用重建能力、一个用任务相关的门控；与 P121/P124 的「把记忆管理交给学习」在理念上同源，但发生在注意力层内部而非 agent 动作空间。定位上属于「用学习式选择实现固定预算」的架构改造工作。

## 7. 可迁移点与开放问题

可迁移：(a) 「固定预算 ≠ 固定状态」这一区分是理解选择式与压缩式路线的关键，也提示在预算受限时应优先考虑无损选择而非有损压缩；(b) 用可学习门控替代手工重要性度量，是提升选择质量的通用手段。开放问题：长文检索任务上的召回率；固定预算与输入信息密度的匹配；门控导致的行为分布外效应；与其它选择式方法的横向比较；以及改造预训练模型的适配成本。
