# P048 NSNQuant: A Double Normalization Approach for Calibration-Free Low-Bit Vector Quantization of KV Cache

- 会议/来源：NeurIPS 2025（主会）
- 方向簇：KV
- 链接：/paper_files/paper/2025/hash/3d8ee933c215fbb7b4d1948ff4906299-Abstract-Conference.html
- 本地全文：cache/txt/P048.txt

## 一句话贡献

指出既有 KV cache 向量量化（VQ）方法因依赖校准数据集而对**分布漂移**脆弱，提出免校准的 NSNQuant：用「token 级归一化 → 通道级中心化 → 再次 token 级归一化」的三步变换配合 Hadamard 变换，把 token 分布对齐到标准正态分布，从而只需一个可复用的码本即可稳健量化；在 1-bit 与 2-bit 设定下一致优于先前方法，吞吐最高提升 3×。

## 1. 问题与第一性原理动机

向量量化（用一个码本把向量映射到最近的码字）比标量量化更省比特，因为它能利用维度之间的相关性。但码本必须由数据确定——若用校准集学码本，则码本隐含了**校准数据的分布假设**。当实际推理时的输入分布与校准集不同（领域漂移、语言切换、任务变化、长上下文带来的分布外 token），码字就落在错误的区域，量化误差急剧上升。这不是「校准集不够大」的问题，而是「任何离线固定的码本都会与在线分布存在错配」这一结构性矛盾。既然分布不可预知，那就应当**把分布本身规范化成固定的形态**，使码本与数据无关。

## 2. 核心洞察

论文的洞察是：与其让码本去适配分布，不如让分布去适配码本。三步变换各自解决一个问题——token 级归一化消除单个 token 的尺度差异；通道级中心化（Shift）消除通道之间的系统性偏移（对应 KV cache 中普遍存在的通道偏置）；第二次 token 级归一化进一步收紧分布；再叠加 Hadamard 变换把能量分散、削弱离群值。经过这套处理，不同 token 的表示被对齐到接近标准正态的形态，于是**一个固定的、可复用的码本**就能在任意数据上工作。这一思路与 P049（极坐标变换）和 P047（非结构化剪枝利用离群）在动机上同源——都在问「用哪种表示能让压缩器的假设成立」。

## 3. 方法机制

离线准备一个不依赖校准数据的可复用码本；在线对 KV 向量依次施加 token 级归一化、通道级中心化、再次 token 级归一化与 Hadamard 变换，再用码本编码，计算前按逆变换恢复。三处代价需注意：Hadamard 变换与两次归一化带来额外计算（论文称其被量化带来的带宽节省覆盖，故仍有最高 3× 吞吐）；码本大小固定，无法随比特预算任意伸缩；逆变换的数值稳定性在 1-bit 这种极端低比特下更敏感。

## 4. 实验证据

在 1-bit 与 2-bit 两种极端低比特设定下，NSNQuant 一致优于先前方法，体现较强的泛化性，并报告相对全精度基线最高 3× 吞吐提升。论文的核心对照维度是「免校准 vs 依赖校准」，其立论建立在对现有 VQ 方法在分布漂移下退化的分析之上。

## 5. 第一性原理再审视

核心待检验问题是「对齐到标准正态是否真的与模型精度无关」。归一化是**可逆的仿射变换**，但量化发生在变换后的空间，误差经逆变换会被重新缩放：若某通道尺度很小，归一化后该通道的相对量化步长被放大，反变换回去可能放大相对误差。也就是说，分布对齐让码本通用，代价是牺牲了「按通道重要度分配误差预算」的能力——而 P034（ChanMix）恰恰利用了这种能力。论文的「一致占优」属于经验证据，缺少误差界分析与同比特下对校准型方法的逐任务对比（尤其长文检索）。此外「1-bit 下仍优于先前方法」是在极端低比特区间做相对比较，绝对精度水平需回看正文，不能仅凭相对优势判断可用性。

## 6. 与相邻工作的关系

与 P049（PolarQuant，用极坐标变换解决 key 离群）和 P034（ChanMix，通道级混合精度）同属「更换表示或分配方式以适配量化」的路线：P049 换坐标系、P034 按敏感度分配比特、NSNQuant 统一分布以复用码本。与 P047（非结构化剪枝）正交，稀疏与低比特理论上可叠加。与标量量化相比，VQ 利用维度相关性，但需要码本这一额外结构——NSNQuant 的贡献正是让该结构不再依赖数据。定位上属于低比特 KV 量化的鲁棒性改进。

## 7. 可迁移点与开放问题

可迁移：(a) 「先做可逆规范化使分布收敛到固定形态，再用与数据无关的压缩器」是提升压缩鲁棒性的通用范式，可搬到激活量化、权重压缩、跨领域嵌入存储；(b) 「校准依赖」应被当作量化方法的常规风险项显式评估，而非默认校准集具有代表性。开放问题：规范化后的量化误差能否给出界；免校准与校准型方法在同比特下的逐任务对比（尤其精确检索）；码本大小与比特预算的可伸缩性；Hadamard 变换的在线开销在长上下文与大批量下是否仍可忽略；以及与稀疏化的叠加收益。
