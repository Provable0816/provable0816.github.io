# P058 PrefixKV: Adaptive Prefix KV Cache is What Vision Instruction-Following Models Need for Efficient Generation

- 会议/来源：NeurIPS 2025
- 方向簇：VLM
- 链接：/paper_files/paper/2025/hash/87b8bc2289d95bda4a8b620fc2232a9b-Abstract-Conference.html

## 贡献

指出视觉指令跟随模型（LVLM）的 KV 压缩存在一个被忽视的偏差：既有方法为**每一层分配相同的 cache 大小**，而各层 KV 向量的重要性分布差异很大，于是某些层被迫承担与其信息量不匹配的裁剪，导致明显的上下文信息丢失。PrefixKV 把「为所有层确定各自的 cache 尺寸」重新表述为一个**全局前缀配置的搜索问题**——这里的 prefix 指按重要性排序后的 top-ranked KV，而非原序列中的位置前缀。

## 机制要点

方法用一个基于二分搜索的自适应逐层保留方案：在给定总预算下搜索各层保留比例的组合，使每层能保全的上下文信息最大化。因为总预算是固定约束，逐层分配本质上是一个约束优化，二分搜索提供了一种低成本求近似解的途径。设计上与具体打分函数解耦，可叠加在既有 KV 压缩方法之上。

## 关键结果

论文称与其它方法相比取得 SOTA 表现，在推理效率与生成质量之间给出更好的权衡。摘要未给出具体数值（如保留率、显存下降幅度、基准得分），需要回看正文表格。

## 局限与定位

三点缺口。第一，「每层最优预算不同」这一现象在文本 KV 压缩中已被系统研究（如 PyramidKV/DynamicKV 的层间分配、P037 的层内头间分配），本工作把该思想迁移到 LVLM 场景，因此**新颖性主要体现在应用域而非机制**；论文需要给出 LVLM 的层间分布与文本模型有何本质差异（例如视觉 token 是否集中在特定层），否则难以说明为何必须专门设计。第二，二分搜索的代价与收敛性未在摘要中说明——若搜索需要多次前向试探，在线推理的延迟优势可能被抵消。第三，评测需覆盖视觉密集任务（高分辨率图像、长视频），因为视觉 token 的冗余模式与文本不同，若只在通用 VQA 上验证，无法支撑「vision instruction-following 需要自适应前缀」这一论断。定位上属于把成熟的层间预算分配思想移植到多模态 KV 压缩。
