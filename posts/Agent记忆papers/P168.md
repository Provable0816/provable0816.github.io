# P168 FrameFusion: Combining Similarity and Importance for Video Token Reduction on Large Vision Language Models

- 会议/来源：ICCV 2025
- 方向簇：VLM
- 链接：/content/ICCV2025/html/Fu_FrameFusion_Combining_Similarity_and_Importance_for_Video_Token_Reduction_on_ICCV_2025_paper.html

## 贡献

指出视频 token 削减中一个被忽视的事实：**即使是被判为「重要」的 token 也可能高度冗余**——由于相邻视频帧相似以及画面中重复出现的视觉元素，高重要性 token 之间存在大量重复；因此仅按重要性剪枝会保留冗余副本。FrameFusion 提出把**基于相似度的合并**与**基于重要性的剪枝**结合起来，并给出三项关于 token 相似性的实证发现，其中第一项是：**相邻帧中空间对应的视觉 token 之间的余弦相似度显著高于其它 token 对**。

## 机制要点

论文击中了一个真正的结构性问题：**重要性与冗余是两个正交维度**，只优化其中一个必然次优——这与 P030（MixKV 明确把重要性 + 多样性联合优化）、P040（AsymKV 区分 key 同质与 value 异质）、P151（DesireKV 解耦重要性与敏感性）构成同一方法论家族：**在压缩决策中引入第二个正交维度**。第三者的具体形式各有不同（多样性、同质性、敏感性、相似度），但共识是单维度排序无法刻画压缩的真实需求。第二项发现「相邻帧空间对应 token 相似度高」也给出了合并的操作依据：可以按空间位置对齐后合并，而不是盲目聚类。

## 关键结果

论文报告在视频 LVLM 上以更少的 token 保持性能，并给出三组关于相似性特征的实证发现作为动机。判断价值的关键是与**同等 token 预算**下纯剪枝方法（如累计注意力剪枝）的对照，以及合并操作对需要区分相似物体的任务（例如「左边那个杯子还是右边那个」）的影响。

## 局限与定位

第一，相似度合并会**主动模糊差异**：当两个空间对应 token 相似但不完全相同时（例如同一位置先后的两个不同物体），合并会丢失区分信息；对细粒度时序推理任务（「哪个先出现」）风险较高，需要专门评测。第二，「相邻帧空间对应」的假设依赖帧采样率与相机运动：镜头切换或快速运动时，空间对应关系断裂，按位置合并会产生错误配对；论文需要说明对镜头切换的处理（P081 用置换处理模态边界，思路可借鉴）。第三，作为 to-be-confirmed 的第三项发现（摘要被截断）未在此评估，读者应回看正文。第四，与 P169（VFlowOpt 的渐进剪枝 + 回收）相比，一个做「合并 + 剪枝」、一个做「渐进剪枝 + 回收」，二者与 P030 共同构成视频 token 削减的三条近期路线。定位上属于相似性与重要性联合的视频 token 削减。
