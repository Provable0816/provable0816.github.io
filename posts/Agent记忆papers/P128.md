# P128 Grounding Agent Memory in Contextual Intent

- 会议/来源：ACL 2026（Findings）
- 方向簇：AGENT
- 链接：/2026.findings-acl.584/
- 本地全文：cache/txt/P128.txt

## 一句话贡献

指出长时程目标导向交互中记忆系统的典型失败：**相似的实体与事实会在不同的潜在目标与约束下反复出现**，导致记忆系统检索到语境不匹配的证据。据此提出 STITCH（Structured Intent Tracking in Contextual History）：为轨迹中的每一步建立**结构化检索线索「上下文意图（contextual intent）」**——包含 (1) 当前定义主题段的潜在目标、(2) 动作类型、(3) 锚定哪些属性重要的显著实体类型——检索时按当前步骤的意图匹配历史，并**抑制语义相似但语境不兼容**的记忆片段。同时提出 CAME-Bench 用于评测语境感知检索，在 CAME-Bench 与 LongMemEval 上取得 SOTA。

## 1. 问题与第一性原理动机

论文诊断的失败模式非常具体且常见：假设用户多次讨论同一家公司，但每次的目标不同（一次是投资评估、一次是招聘、一次是采购），此时所有相关的记忆片段在**语义上高度相似**（都包含该公司的名称与基本事实），单纯的向量相似度无法区分应取回哪一段。这不是检索精度不足，而是**表示维度缺失**——记忆条目只携带内容，不携带「当时为什么讨论它」。因此需要给记忆补上一个与内容正交的维度：意图。这与 P024（情景记忆需要显式的时间与情境维度）、P125（记忆需要随时间失效）属于同一认识的三个侧面：语义相似不足以确定相关性。

## 2. 核心洞察

洞察在于**把意图拆成三个可操作的结构化字段**：主题目标（划分段落）、动作类型（我此刻在做什么）、显著实体类型（此刻哪些属性重要）。这三个字段之所以有用，是因为它们分别对应三种歧义来源——话题歧义、行为歧义、属性歧义。把它们显式化后，检索就变成「先按意图过滤、再按语义排序」的两阶段过程，从而抑制语境不匹配的历史。第二层洞察是**索引与检索必须使用同一套线索**：如果写入时不记录意图，检索时就无从匹配，因此这一设计要求在轨迹的每一步都进行意图抽取（等于把成本前移到写入侧）。

## 3. 方法机制

(1) 对轨迹每一步抽取结构化意图（潜在目标、动作类型、显著实体类型）；(2) 用它作为该步记忆的检索线索；(3) 推理时按当前步骤的意图匹配并优先取回相容的历史，抑制语义相似但语境不符的片段。代价是：每步意图抽取需要 LLM 调用（写入侧成本上升）；意图模式的粒度与字段设计是新的工程决策；意图误判会把正确证据过滤掉（过滤型机制的双刃剑效应）；CAME-Bench 由作者构造，存在与被测方法同源的风险。

## 4. 实验证据

在自建的 CAME-Bench 与既有 LongMemEval 上取得 SOTA，说明该思路在作者设计的语境感知任务与更传统的长期记忆基准上都有效。关键需要看的是消融：三个意图字段各自消除了哪类错误、以及过滤机制是否在某些任务上反而降低了召回。

## 5. 第一性原理再审视

第一，过滤（suppressing）比排序更危险：若意图抽取有误，原本正确的证据会被**硬性排除**，而排序型方法至少还能依赖语义兜底。论文需要给出「意图误判率 → 最终任务指标」的敏感性分析，并说明是否存在回退机制。第二，CAME-Bench 由作者构造，其难度是否真实反映语境歧义的分布需要外部验证；在 LongMemEval 上的 SOTA 是重要的外部证据，但两个基准的任务形态不同，需分别解读。第三，每步意图抽取的写入成本在长时程交互中会持续累积，而记忆系统的经济性恰是长期部署的关键（P114 的多粒度摘要也面对同一问题）。第四，三个字段的取值空间是开放的（潜在目标如何枚举？动作类型如何定义？），不同实现之间的可比性存疑；这类方法的可复现性依赖抽取提示的公开。第五，与 P024（REMem 的时间限定符 + 工具化检索）相比，STITCH 的线索是**语义—意图**维度而非时间维度，两者可互补成更完整的检索线索集。

## 6. 与相邻工作的关系

与 P024（REMem）在「记忆需要显式结构化线索」这一原则上一致，但线索维度不同（时间 vs 意图）；与 P125（Memora 指出的过时记忆误用）相关——语境不匹配与时间失效都可归为「语义相似但不应取用」；与 P026（MemGAS 的熵路由粒度选择）都在解决「该用哪种视角检索」，一个是粒度、一个是意图；与 P114（RMM 用引用反馈改进检索）相比，STITCH 是写入侧加线索、RMM 是读取侧调策略，两条路线可组合。定位上属于记忆检索的语境化改进。

## 7. 可迁移点与开放问题

可迁移：(a) 「记忆条目应携带『当时为什么重要』的元信息」是可推广的设计原则，适用于 agent 轨迹、日志、会话记忆；(b) 把检索拆为「按结构化线索过滤 + 按语义排序」的两阶段过程，是处理语义歧义的标准手段。开放问题：意图抽取错误的回退机制；写入侧成本的增长；意图字段体系的可复现性；自建基准的外部效度；以及与时间维线索的联合设计。
