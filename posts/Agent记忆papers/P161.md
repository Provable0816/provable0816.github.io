# P161 AirCache: Activating Inter-modal Relevancy KV Cache Compression for Efficient Large Vision-Language Model Inference

- 会议/来源：ICCV 2025（主会）
- 方向簇：VLM
- 链接：/content/ICCV2025/html/Huang_AirCache_Activating_Inter-modal_Relevancy_KV_Cache_Compression_for_Efficient_Large_ICCV_2025_paper.html
- 本地全文：cache/txt/P161.txt

## 一句话贡献

提出 AirCache：面向 LVLM 推理加速的 KV cache 压缩方法。论文系统考察了 LVLM 注意力机制中**视觉 token 与文本 token 之间的相关性**，实证发现**被缓存的视觉 token 存在可观冗余**——策略性地剔除它们能在保持模型性能的同时显著加速上下文生成；并引入「精英观测窗口（elite observation window）」来评估视觉组件在 KV cache 中的重要性。

## 1. 问题与第一性原理动机

LVLM 的成本结构与纯文本 LLM 不同：视觉 token 的数量可达文本的数十倍（高分辨率图像与长视频尤甚），因此 KV cache 的构成**以视觉 token 为主**。这决定了压缩的重心应当放在视觉侧——而多数从 LLM 迁移来的压缩方法按统一的注意力统计处理所有 token，实际上把大部分预算花在了视觉 token 的排序上，却忽略了模态间的相关性结构：一个视觉 token 的价值往往取决于**文本查询是否引用了它所对应的区域**，这是一个跨模态关系，而非视觉 token 自身的属性。

## 2. 核心洞察

洞察是**视觉 token 的重要性由模态间的相关性决定**。「精英观测窗口」的作用正是在文本上下文中寻找可以作为重要性判据的窗口（例如包含指令与关键提问的部分），据此评估视觉组件是否被引用。这一思路与 P095（VL-Cache 的模态感知打分）、P030（MixKV 的模态特异冗余）一致，也与文本侧 P045（查询无关 vs 查询相关）、P042（避免读取注意力矩阵）讨论的取舍同源：判断视觉 token 相关性必然涉及跨模态交互，因此难以完全做到查询无关。

## 3. 方法机制

(1) 用精英观测窗口评估视觉 KV 的重要性；(2) 剔除冗余的视觉 token 以压缩 cache；(3) 在保持性能的前提下加速上下文生成。代价是：重要性判据依赖文本侧窗口的选取（窗口选得不好会系统性误判）；视觉 token 的剔除是不可逆的，对需要细粒度视觉细节的任务（小字、精确计数）风险高；多轮交互中不同提问会引用不同区域，缓存的视觉 token 集合需要随之调整。

## 4. 实验证据

论文报告大量视觉 token 冗余的实证分析与压缩带来的加速，同时保持性能。需要核实两方面：加速的绝对值（相对何种基线）与在**视觉密集任务**（高分辨率文档、图表、细粒度视频）上的精度保持——这两类任务最可能暴露视觉 token 剔除的风险。

## 5. 第一性原理再审视

第一，「视觉 token 冗余」这一结论强依赖任务与被测模型：在通用 VQA（对象级关系）上冗余度可能很高（P110 报告池化掉 70% 视觉 token 仅掉 3%），但在 OCR、图表理解与视频细粒度问答上冗余度低得多；把前者得到的压缩率外推到后者是常见错误，论文需要按任务类型分层报告。第二，「精英观测窗口」的构造需要一个关于「哪部分文本重要」的先验，若窗口固定（如系统提示 + 首轮提问），在多轮对话中会失效——这与 P111 的「边界丢失」属同类风险。第三，视觉 token 间的空间关系（相邻 patch 的语义连续性）在逐 token 剔除时容易被破坏，P039（chunk 化）与 P152（语义片段）提示按区域/片段剔除可能优于按 token 剔除，论文未讨论单位选择。第四，多模态 KV 压缩的方法数量激增（本批中 P030、P058、P081、P095、P152、P155、P162、P163、P168、P169 均属此列），横向可比性差；论文应尽量与同类方法在统一预算下对照。定位上属于跨模态相关性驱动的视觉 KV 压缩。

## 6. 与相邻工作的关系


与 P095（VL-Cache 的模态感知打分 + 层自适应预算）最接近，差别在于重要性判据的构造（精英观测窗口 vs 模态感知策略）；与 P030（MixKV 的重要性 + 多样性）在「只按重要性不足」这一判断上一致，但 MixKV 从多样性维度补足、AirCache 从跨模态相关性维度补足；与 P081（MMInference 的模态感知稀疏注意力）相比，一个改注意力模式、一个改 cache 内容；与 P152（StreamKV 的语义片段）在「选择单位」上不同。定位上属于 LVLM 视觉侧 KV 压缩。

## 7. 可迁移点与开放问题

可迁移：(a) 「用模态间相关性而非单模态显著性来评估价值」可推广到任何多源输入的压缩（文档 + 表格、指令 + 图像、文本 + 传感器流）；(b) 用有限的观测窗口替代全注意力统计，是一种廉价的注意力代理，适合无法读取完整注意力矩阵的部署环境。开放问题：视觉 token 剔除在视觉密集任务（OCR、图表、细粒度视频）上的代价；观测窗口在多轮提问下的适应性；剔除单位（token vs 区域/片段）的取舍；与多粒度（P162）和频域判据（P163）方法的统一对比；以及重要性判据跨模型的迁移性。
