# P072 Lexico: Extreme KV Cache Compression via Sparse Coding over Universal Dictionaries

- 会议/来源：ICML 2025（主会）
- 方向簇：KV
- 链接：https://proceedings.mlr.press/v267/kim25ae.html
- 本地全文：cache/txt/P072.txt

## 一句话贡献

发现现代 LLM 的 KV cache 可以用一个**极小、与输入无关的通用字典**（约 4k 个原子）的稀疏线性组合高精度逼近：Lexico 用正交匹配追踪（OMP）做稀疏近似，通过直接控制稀疏度获得灵活的压缩比，从而在 Mistral、Llama 3、Qwen2.5 上以 15–25% 的 KV 显存保持原始性能的 90–95%，并在 2-bit 量化失效的极低内存区间胜过量化与 token 淘汰方法（最高 1.7× 更好的压缩）。

## 1. 问题与第一性原理动机

KV 压缩的两大主流各有硬边界：量化在低比特（2-bit 及以下）时误差急剧上升；token 淘汰则面临不可逆的信息删除。二者共同的问题是把 KV 表示当作**固定的数值对象**来近似——量化是在原坐标上用粗网格表示，淘汰是直接删掉维度（token）。论文提出的替代视角是：KV 向量在语义上可能并不需要被逐元素精确表示，而只需要落在某个**共享的低维子空间的稀疏组合**中。若这一假设成立，压缩比就可以由稀疏度直接控制，且在极低内存下仍保持结构信息——这解释了为什么它能在 2-bit 量化失效的区间仍然有效。

## 2. 核心洞察

关键发现是字典**与输入无关**：论文称字典约 4k 个原子，可在不同 prompt、任务与模型之间复用。这一性质有两层意义：(1) 字典只存一次，KV 存储的边际成本降到「每个向量用哪几个原子 + 系数」，压缩效率高；(2) 输入无关意味着它捕捉的是模型表示空间的**内在几何结构**，而非特定语料的统计，从而具备跨任务的通用性。第二个洞察是稀疏度是连续可调的压缩旋钮，比量化位宽更细——这使系统能在给定的内存约束下精确地使用预算，而不是被 2/4/8 bit 这类离散档位限制。

## 3. 方法机制

(1) 离线构建（或学习）一个约 4k 原子的通用字典；(2) 在线用正交匹配追踪对每个 KV 向量求稀疏近似，保留选中原子索引与系数；(3) 通过限制非零系数个数（稀疏度）直接控制压缩率。代价是：OMP 有迭代计算成本，需要在解码路径上考虑是否可与注意力融合（对比 P067 用可交换码本把解码并入注意力）；重建是近似的，误差随稀疏度增加而上升；字典虽小，但仍需为不同模型准备（是否为每个模型单独学习未在摘要说明）。

## 4. 实验证据

GSM8K 上，跨 Mistral、Llama 3、Qwen2.5 多个模型族，Lexico 用 15–25% 的全量 KV 显存保持 90–95% 的原始性能，优于量化与 token 淘汰方法；在 2-bit 量化失效的低内存区间仍然有效，在 LongBench 与 GSM8K 上取得最高 1.7× 的更好压缩同时保持高准确率。论文强调其灵活性来自直接控制稀疏度。

## 5. 第一性原理再审视

第一，「保持 90–95% 的原始性能」意味着**损失并非可忽略**：在需要精确召回的任务上（多针检索、长文中的数字），5–10% 的相对下降可能集中在少数关键样本上，平均口径会掩盖这一点；论文以 GSM8K 为主战场，缺少长上下文精确检索的逐任务分析。第二，通用性与压缩率之间存在未明说的张力：字典与输入无关这一优点意味着它必须覆盖所有输入的子空间，若某些任务使用训练字典时未见的表示方向，稀疏近似的残差会显著增大；4k 原子这一规模是否对更大模型（70B+、MoE）仍足够，需要验证。第三，OMP 的在线开销是关键工程问题：论文的有效性建立在极低显存上，若解码期每步为每个 KV 向量做 OMP，其计算可能抵消收益；摘要未给延迟数字。第四，与量化的关系值得澄清——稀疏编码与低比特量化理论上可以叠加（先量化系数再稀疏化），论文未涉及这一组合空间，而它可能比单独使用更优。

## 6. 与相邻工作的关系

与 P035（SALS，低秩投影 + 稀疏选择）同属「低维结构 + 稀疏」思路，但 SALS 用固定低秩子空间、Lexico 用稀疏字典原子，压缩机制不同；与 P048（NSNQuant）、P067（CommVQ）同处向量量化阵营，区别是 Lexico 用**超完备字典的稀疏编码**而非固定码本聚类，因此可用原子组合表达更丰富的方向；与 token 淘汰方法（P045、P050）互补——淘汰减少向量个数，Lexico 减少每个向量的存储。定位上属于「表示空间稀疏化」这一分支，其核心卖点是极端低内存区间仍可用。

## 7. 可迁移点与开放问题

可迁移：(a) 「用输入无关的通用字典 + 稀疏编码表示中间状态」这一思路可搬到激活量化、embedding 存储、多模态特征缓存；(b) 把压缩比做成**连续旋钮**（稀疏度）而非离散档位（位宽），使系统能在任意内存约束下精确用满预算——这是工程上极有价值的性质。开放问题：字典规模与模型规模的缩放关系；OMP 在线开销与注意力融合的可能性；长文精确检索任务上的保持率；字典是否需要按模型/领域重训；以及与量化叠加的最优组合。
