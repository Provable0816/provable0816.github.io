# P138 Pre-Storage Reasoning for Episodic Memory: Shifting Inference Burden to Memory for Personalized Dialogue

## 一句话贡献

把复杂推理从**推理时**前移到**记忆构建时**：PREMem 抽取细粒度记忆片段并归类为事实性（factual）、体验性（experiential）与主观性（subjective）三类，随后在跨会话的记忆条目之间建立**显式关系**，刻画演化模式（扩展、转变、蕴含）；由于推理发生在「预存储」阶段而非响应生成阶段，系统既得到更丰富的记忆表示，又降低了交互时的计算负担，因此在**所有模型规模**上都取得显著提升，降低了对模型尺寸的依赖。

## 1. 问题与第一性原理动机

论文指出的问题具有很强的结构性：现有系统把「跨会话信息综合」这一重负担放在响应生成阶段，导致性能**高度依赖模型规模**——大模型还能勉强综合多条记忆，小模型则力不从心。这是一个糟糕的架构选择，因为跨会话综合所需的信息（同一用户在不同时间说了什么、是否发生变化）在写入时就已经全部可得，完全没必要推迟到回答时再做。把推理前移到记忆构建，等价于在信息最完整、时间最宽裕的时刻承担计算，从而让推理阶段只做「取用」。

## 2. 核心洞察

洞察是**时间维度的资源重分配**：同一份推理工作，放在写入侧还是读取侧，其成本与质量都不同。写入侧是「一次做、多次用」（成本可摊薄），读取侧是「每次都做」（成本随查询数线性增长）；而且写入侧拥有跨会话的全局视野，更容易发现演化关系。第二点是记忆条目的**三分法**（事实/体验/主观）与**关系类型**（扩展/转变/蕴含）：前者回应了 P129（HINDSIGHT）主张的「事实与信念分离」，后者则显式建模了 P125（Memora）所指出的「记忆演化与调和」问题——两者都指向同一个缺口：记忆系统缺少对「信息如何变化」的表示。

## 3. 方法机制

(1) 抽取细粒度记忆片段并归为三类；(2) 在跨会话的记忆条目间建立显式关系，刻画扩展、转变、蕴含等演化模式；(3) 在预存储阶段完成上述推理，交互时直接使用富化的表示。代价是：写入阶段的 LLM 调用成本上升（且随会话累积），这在长期使用中会持续增长；关系类型的体系需要设计（当前三类是否覆盖所有演化形态？）；关系误判会固化为错误结构并影响后续所有交互。

## 4. 实验证据

论文报告在**所有模型规模**上都取得显著性能提升——这一「跨规模一致」的结论恰是「前移推理负担」这一设计目标的直接证据：若收益只出现在大模型上，说明负担并未真正转移。具体指标与基准需回看正文。

## 5. 第一性原理再审视

第一，「跨所有模型规模都有提升」需要看提升幅度是否随规模递减：若小模型提升更大，说明前移确实补偿了推理能力；若各规模提升相近，则可能更多来自记忆表示本身的质量，而非负担转移。论文应给出提升幅度与模型规模的关系曲线。第二，写入侧成本的增长是长期系统的核心风险：随着会话累积，关系的数量可能呈超线性增长（每条新记忆要与历史条目比对），需要明确的增量更新策略；摘要未涉及复杂度分析。第三，关系体系（扩展/转变/蕴含）是人为枚举的，真实对话中的演化可能更复杂（如条件化的偏好、冲突并存的信念）；枚举不足会导致关系分类被迫粗糙，枚举过多则标注与判定成本上升。第四，与 P129（四网络 + 置信度）相比，PREMem 的三分类更接近信息类型而非可信度维度；两者可结合为「类型 × 可信度」的两维结构。第五，与 P024（REMem 保留矛盾事实并显式建模时间）相比，PREMem 主动建立演化关系，代表了更「主动整理」的记忆写入哲学。

## 6. 与相邻工作的关系

与 P024（REMem 的图式情景记忆 + 时间限定符）与 P114（RMM 的前瞻性反思写入）都属「在写入侧做推理」，PREMem 的特色是显式的演化关系类型；与 P129（HINDSIGHT 的事实/信念分离）在分类维度上互补；与 P125（Memora 揭示的失效记忆误用）直接相关——演化关系若建模正确，正是破解「无法调和演化记忆」的手段；与 P131（MCMA 把记忆抽象当作可学习技能）相比，PREMem 的关系体系是人工定义的固定结构，而 MCMA 主张抽象层次应可学习。定位上属于「预存储推理」这一写入侧路线的代表。

## 7. 可迁移点与开放问题

可迁移：(a) 「把跨时间综合前移到写入侧」是可推广的架构原则，适用于任何「一次写入、多次查询」的系统（日志、工单、知识库）；(b) 显式建模记忆演化关系（扩展/转变/蕴含）为记忆系统提供了时间维度的结构，值得作为通用模式。开放问题：写入成本随会话数增长的复杂度控制；关系体系的完备性与判定准确率；与可信度维度（P129）的结合；增量更新的可扩展性；以及在真实长期使用（数月到数年）下的稳定性。
