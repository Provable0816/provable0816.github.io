# P013 ProtoKV: Long-Context Knowledges Are Already Well-Organized Before Your Query

## 一句话贡献

发现 key 嵌入空间中存在两类 token——与邻域高度相似的 PDT 与偏离邻域并自发聚类的 SAT（语义锚点）；据此提出 ProtoKV：对 SAT 用 RFF+LSH 分桶、对 PDT 切连续块，以混合语义原型作为压缩单元，在 LongBench 匹配显存下平均比 SOTA 高 2.11%，NIAH 在约 1.6% 保留率下仍有 97.3% 检索准确率。

## 1. 问题与第一性原理动机

KV 缓存随批量与序列长度线性增长 O(b·n)，而 token 级重要性打分（累积注意力、H2O 类）把 token 当作独立单元，天生会破坏语义完整性；chunk-based 方法则假设"位置相邻 ⇒ 语义相似"，对承担信息传递功能的标点、标签类 token 失效；k-means 聚类虽能识别语义簇，却要迭代收敛（SqueezeAttention 需 20 次以上迭代才超过基线）且严重依赖初始化。于是形成一个结构性张力：语义完整性要求"按语义单元成组保留"，效率要求"不做迭代聚类"。

## 2. 核心洞察

Local Deviation Property。定义 κ-邻域相似度 $S_\kappa(i)=\frac{1}{2\kappa+1}\sum_{j=i-\kappa}^{i+\kappa}\cos(k_i,k_j)$（默认 κ=5），离群度 $\Theta(i)=(S_\kappa(i)-\mathbb{E}[S_\kappa(i)])/\sqrt{\mathbb{V}[S_\kappa(i)]}$。分布呈双峰：多数 token 与邻居相似（PDT，位置决定），少数显著偏离且自发聚成一簇（SAT）。三条证据：① 以聚类度 $\Gamma=S_{intra}/S_{inter}$ 度量，阈值 β 提高时 SAT 簇迅速变紧；② 按 Θ 分 10 组统计累积注意力，深层 top 10% 离群 token 占 60% 以上注意力；③ 按离群度剪 KV 与按累积注意力剪同样导致性能崩塌，随机剪枝无可测影响。机制解释：RoPE 给相邻 token 注入局部相似先验，而各 head 在预训练中分工捕捉特定语言模式，为高效取用相关 value，模型学会把显著 key 聚簇；与 head 无关的 token 因 RoPE 归纳偏置保持局部性。

## 3. 方法机制

整体框架：先用离群度挑出候选 SAT，把 SAT 与其余 token 分别归并成"原型"，再按观察窗口给原型打分、按预算保留整簇。关键设计：① 候选 SAT 取 Θ 最高的 top-p 个；② SAT 原型用随机傅里叶特征 $\phi(k)=\sqrt{2/r}\cos(Wk+b)$ 投影后二值化，按 r-bit 整数对 $u=2^r$ 个桶取模分桶，桶内 key 归一化求均值——换取 O(n) 的免迭代聚簇，代价是 u、r 两个超参；③ PDT 原型把剩余 token 按连续等长切成 v 块并取块内归一化均值，保住细粒度局部知识；④ 分配时每个 token 归到余弦相似度最大的原型，簇分数 $\psi(C_j)=\sum_{i\in C_j}\sum_{m\in\text{窗口}}q_m^\top k_i$，按预算保留 top 簇。相对 k-means 的复杂度从 $O(e\cdot n\cdot t)$ 降到 $O(n\cdot t)$，且不需要注意力矩阵。

## 4. 实验证据

设置：LongBench 16 个任务，预算 64–512；模型 Llama-2-7B-chat、Llama-3-8B-Instruct、Mistral-7B-Instruct-v0.2；基线 StreamingLLM / H2O / SnapKV / PyramidKV / ChunkKV。平均提升 2.11%，各预算下领先 SOTA 0.35%–4.27%。NIAH（8K，budget 128，约 1.6% 保留）：ProtoKV 97.3%，SnapKV 94.2%，H2O 54.8%，SLM 31.1%。RULER（budget 128/512）：NIAH 98.2/99.6、QA 42.8/43.6，对比 SnapKV 97.2/99.6、42.0/43.8。Table 3 在 512 预算下与需动态加载的聚类方法对比：ProtoKV 42.59（decoding）/40.76（prefilling），高于 ClusterKV 41.32/40.45、SqueezeAtt 41.47/40.42、SentenceKV 40.82/40.21。消融：纯 chunk 聚类与全 token LSH 两种变体都掉点（LSH 更差），说明"SAT 分桶 + PDT 分块"的混合是必要的；超参上约 500 个原型最优、SAT 原型仅需 2–4 个、SAT 选 20–40 个即可，κ 影响可忽略；耗时与 SnapKV 相当，聚类类方法最多有 3.9× 开销。
论文自己给出的反例很关键：直接按离群度保留 top-k（SATKV）反而弱于 SnapKV（256 预算下 NrtvQA/HotpotQA/SAMSum/Lcc 为 21.12/40.84/38.06/58.46，SnapKV 为 23.32/42.70/39.78/60.27），原因是 PDT 仍承载约 40% 的注意力。

## 5. 第一性原理再审视

成立依赖三点：(i) 离群度确实对应"语义锚点"而非仅是 RoPE 的数值副产品；(ii) 单紧簇假设在多数 head 成立（论文承认浅层可能无离群、多文档下可能出现多簇）；(iii) 前向观察窗口的 query 能近似推理期累积注意力。理论上没有保证——论文未给出"保留 SAT 簇 ⇒ 输出误差上界"的结果，只有"删 SAT 会掉分"的相关性证据。失效条件：语义高度不连续、分布无清晰双峰、或任务强依赖细粒度局部信息时，原型归并会抹掉局部细节。2.11% 的平均增益相对基线差距并不悬殊，需要更多模型与更长上下文验证。

## 6. 与相邻工作的关系

与 SnapKV/ChunkKV 的差别在"分块依据"：它们按位置，ProtoKV 按 key 空间的原型。与 ClusterKV/SqueezeAttention 同属聚类路线，但用 SAT 性质直接给出簇心，绕开迭代与初始化。与 attention sink 研究是包含关系：sink 通常离群度很高，但论文显示排除 sink 后剩余 SAT 仍不可替代。

## 7. 可迁移点与开放问题

可迁移的是"用嵌入空间局部偏离度做无监督语义单元发现"这一算子，可用于记忆检索、agent 历史裁剪、RAG 证据选择。开放问题：能否把"保留哪些簇"写成输出重构误差的直接目标；SAT/PDT 划分能否自适应而非固定阈值；该分布在 MoE、多模态、超长上下文下是否保持。
