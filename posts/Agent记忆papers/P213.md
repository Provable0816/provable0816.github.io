# P213 SAM2Act: Integrating Visual Foundation Model with A Memory Architecture for Robotic Manipulation

- 会议/来源：ICML 2025（主会）
- 方向簇：AGENT
- 链接：https://proceedings.mlr.press/v267/fang25c.html
- 本地全文：cache/txt/P213.txt

## 贡献

面向机器人操作提出多视角、语言条件的行为克隆策略 SAM2Act（以 SAM2 视觉基础模型为骨干，配合多分辨率上采样与多视角 Transformer 对齐空间坐标与语言指令），并进一步给出带**记忆架构**的 SAM2Act+：借鉴 SAM2 的记忆库—编码器—注意力设计增强**空间记忆**；同时发布 MemoryBench，一个专门评测「依赖记忆的任务」的基准。

## 机制要点

架构见 Figure 3：SAM2Act（上）用 SAM2 图像编码器生成提示条件的多分辨率嵌入，用 LoRA 微调以适配操作任务，多视角 Transformer 对齐空间坐标与语言指令，级联多分辨率上采样模块（Figure 4：三个凸上采样器逐级把特征图分辨率翻倍，并与 SAM2 的多分辨率嵌入做逐元素相加 + LayerNorm）生成精细的空间预测。SAM2Act+（下）在此之上加入记忆库/编码器/注意力，用于需要「记住过去所见」的任务（例如先按蓝色方块附近的按钮、移走方块后再按**同一个**按钮，见论文给出的任务样例）。Stage 1 预训练后冻结 SAM2 编码器与粗分支，仅训练记忆相关部分，这一分阶段设计控制训练成本。

## 关键结果

RLBench 的 18 个任务上平均成功率 **86.8%**；在 Colosseum 基准的环境扰动下平均仅 **4.3%** 的性能落差，说明泛化稳健。MemoryBench 为 CoppeliaSim 中的三个桌面操作任务（每个任务含 2–60 种变体，覆盖物体、位置、颜色变化），要求策略同时具备语义与空间记忆；Figure 2 同时展示仿真与真机（Franka Panda）任务，含分布外扰动测试。Table 报告各方法的平均成功率与平均排名，以及与 RVT-2 等基线的分项对比（含 MO/RO-Color、Texture、Size 等受控变化）。

## 局限与定位

第一，记忆架构的收益主要由 MemoryBench 这类**新提出的、由作者定义**的基准来证明，基准设计与方法设计之间的耦合（哪些任务恰好需要空间记忆）需要独立验证。第二，方法依赖 SAM2 这一分割基础模型的表征质量，向非刚性物体、可变形场景的迁移性未知。第三，真机实验规模有限（四个任务），而机器人领域的泛化主张通常需要更大规模的多环境验证。定位上，它属于「外部记忆用于具身智能」的代表：与本方向中 agent 记忆的研究（P175 ARTEM 的时空情节记忆、P215 A-Mem 的结构化笔记网络）在问题结构上同源——都把「过去的状态」当作需要显式存储与检索的资产，区别在于机器人任务对**空间**记忆的要求更刚性，因此记忆的表示与索引必须与几何对齐。
