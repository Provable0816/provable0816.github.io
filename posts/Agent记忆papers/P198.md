# P198 Learning What to Remember: Adaptive Probabilistic Memory Retention for Memory-Efficient Language Models

## 一句话贡献

把「每个 Transformer 层保留哪些 token」变成**可微的概率选择问题**：用 Bernoulli 门控 + Hard-Concrete 变分松弛学习逐层保留概率，推理时以简单的 top-$M$ 规则执行，在严格全局预算 $M$ 下把注意力成本从 $O(T^2d)$ 降到 $O(M^2d)$（混合方案为 $O(TMd)$），在只保留 30–50% token 时保持 ≥95% 的全模型性能。

## 1. 问题与第一性原理动机

注意力的二次复杂度来自「每个 token 都要与所有 token 交互」。因此压缩的自变量就是**被保留参与交互的 token 集合**。既有做法分两类：稀疏注意力（Longformer、BigBird 等）用**固定模式**（滑窗、全局 token、随机块）限制交互，模式是先验；启发式剪枝（H2O 等）用**观测统计**决定保留，缺少训练信号。两者共同的缺口是：保留决策没有直接针对任务损失被优化。把保留决策写成离散选择，问题即不可微的组合优化——这正是本文用变分松弛要解决的技术障碍。

## 2. 核心洞察

「真值门控 × 可微松弛」把不可微的保留决策变成可训练参数：Hard-Concrete 分布允许采样出近似 0/1 的门控但保留梯度，使任务损失的梯度能传回门控网络，从而让每一层自己学出「哪些表示值得留下」。关键在于保留判据不是外部的（注意力大小、位置），而是**由任务损失反传出来的**——这与 P003（TRIM-KV 的 retention gate）、P170（任务信号驱动的压缩目标）同属一族：把压缩当作带容量约束的学习问题。

## 3. 方法机制

设序列 $X=(x_1,\dots,x_T)$，每层由轻量 gated scorer 为每个 token 输出保留概率，记为 $\{z_t\}\in\{0,1\}^T$，用 Hard-Concrete 松弛（$\beta=0.66$、$\gamma=-0.1$、$\zeta=1.1$）训练；推理时对每层取 top-$M_l$（$M_l=\lfloor\rho T_l\rfloor$）保留，只把保留的 hidden state 送往下一 block（Figure 1）。由于保留集合在层间收缩，后续层的注意力规模随之下降。代价与边界：门控网络引入额外前向开销（Table 4 给出 30% 预算下 12GB GPU 的耗时分解）；需要微调（非免训练）；预算 $\rho$ 是全局旋钮；逐层保留比例并不均匀（Table 5 给出直接证据）。

## 4. 实验证据

模型：短文本用 DistilBERT-base-uncased（SST-2、IMDb、CUAD），长文本用 Longformer-base-4096（ArXiv、QASPER、PubMed RCT）。预算：$M/T\in\{0.5,0.3\}$。Table 1（50%）与 Table 2（30%）给出对照分组：密集/无保留、学习式与启发式剪枝（含 H2O）、稀疏注意力架构、零样本 LLM 参照，以及本方法；Table 3 是消融与效率汇总（论文称 30% 预算下取得最高吞吐与最低显存，单张 12GB GPU）；Table 5 给出 DistilBERT 六层在 SST-2 上 30%/50% 预算下的**逐层平均保留比例**；Figure 2 是三个松弛参数的敏感性扫描。核心数值：保留 30–50% token 保持 ≥95% 全模型性能，峰值显存下降约 35–45%，吞吐最高约 1.8×。

**证据缺口**：(a) 评测使用**编码器**（BERT 系）与判别式/抽取式任务（分类、抽取 QA、摘要），而当前记忆压缩的主战场是**自回归解码**（KV cache）；解码阶段 token 逐个产生且不可回退重排，两者机制不可直接迁移；(b) 「每层保留不同集合」意味着层间表示不再一一对应，论文未讨论这种错位对残差流与层归一化的影响；(c) 训练用采样门控、推理用 top-$M$，存在暴露偏差，论文未报告该差距的规模；(d) 缺少数值型/精确检索任务的验证，而这是 token 丢弃最脆弱之处。

## 5. 第一性原理再审视

该方法的成立条件可以写成一句话：**token 的保留价值可由任务损失在训练分布上学得并稳定迁移到测试分布**。这与 eviction 方法面对的是同一问题，区别在于用梯度而非启发式逼近。由此可推出三条边界：其一，预算越紧，保留的必须越接近「任务充分统计量」；当任务需要逐字精确（数字、ID）时，任何按概率丢弃都会在低概率但高价值的 token 上失效——低概率恰是门控容易丢弃的对象。其二，逐层独立取舍在理论上非最优：层 $\ell$ 丢掉的 token 会影响层 $\ell+1$ 的所有表示，正确的形式化应是**路径级联合选择**，逐层 top-$M$ 是贪心近似。其三，从信息论看，「保留 30% 仍保 95% 性能」意味着这些任务上存在大量冗余（低有效信息率），因此该结论本身是**任务冗余度的测量**，不能外推为「30% 足够」。此外，$O(M^2d)$ 只覆盖注意力本身，门控与索引映射开销在低压缩率下会成为主导项——这正是 Table 4 存在的原因，也提示**压缩的元数据成本必须与压缩收益一起核算**。

## 6. 与相邻工作的关系

与 P003（TRIM-KV）结构几乎一一对应：都是「在 token 创建处学习保留分数 + 容量约束 + 只微调轻量模块」，区别在 P003 作用于解码期 KV、本文作用于编码器每层激活，且本文用变分松弛而非蒸馏 + 容量损失。与 H2O 等启发式剪枝的区别是监督来源（任务损失 vs 注意力统计）。与 Longformer/BigBird 等固定稀疏模式的差别是模式可学习。与 P171（CSR）、P174（QJL）正交：它们在位宽方向压缩，本文在元素个数方向压缩。

## 7. 可迁移点与开放问题

可迁移：(a)「用变分松弛把不可微的保留决策变成可训练的门控」是通用手段，可直接搬到 KV eviction 的预算分配、agent 记忆过滤、多模态 token 剪枝；(b) 逐层保留比例的实测分布提示「按层分配预算」优于均匀分配。开放问题：把逐层贪心升级为路径级联合选择；训练—推理的门控一致性（避免暴露偏差）；解码场景的适配（保留决策必须在生成过程中做，且不可回退）；以及把「冗余度估计」做成任务无关的先验指标，用以预测压缩的安全边界。
