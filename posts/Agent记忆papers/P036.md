## 一句话贡献

把 KV cache 淘汰从「注意力权重排序」改写为带基数约束的稀疏逼近问题（最小化淘汰前后输出的平方误差），由凸松弛的对偶 KKT 条件推出最优解必然落在一族投影型打分函数 $s_i=a_i(\theta^\top v_i+b)$ 上；取锚方向 $\theta=y$（淘汰前输出方向）、$b=0$ 得到 AnDPro，在 LongBench 16 个数据集上以 3.44% 的 KV 预算保持 96.07% 的全量精度，并相对此前 SOTA 再省 46.0% 预算。

## 1. 问题与第一性原理动机

淘汰的本质是：用保留子集的加权和去逼近全量 token 的加权和。设淘汰前输出 $y=\sum_{i=1}^n a_iv_i$（$a_i=\mathrm{softmax}_i(q^\top k_i)$），淘汰后为 $\hat y=\sum_{i\in S}\hat a_iv_i$，其中权重在保留集上被**重新归一化**。正因为这层归一化，淘汰误差并不等于「被删除项贡献之和」：删除某个 token 会让其余 token 的权重整体放大，误差是耦合的。这是结构性缺陷而非工程细节——只依赖 $a_i$ 的打分无法表达「$v_i$ 是否指向输出的关键方向」，而输出是向量，重要性天然是多维的。所以正确的问题形式是带基数约束的加权最小二乘，而不是排序问题。

## 2. 核心洞察

把二值指示 $z_i$ 的 $L_0$ 约束松弛为 $L_1$ 时，直接对 $z_i$ 做连续松弛会退化：目标首项对 $z_i$ 的尺度不变，而 $z_i$ 越小正则项越小，于是只有平凡解。作者引入 $s=\sum_i z_ia_i$ 与 $\beta_i=z_i/s$，固定 $0<s\le1$ 后得到凸问题 (P1)。Slater 条件保证强对偶，对偶 + KKT 给出筛选规则：存在 $\theta,b$ 使得 $a_i(\theta^\top v_i+b)$ 低于阈值时 $\beta_i^*=0$、高于阈值时 $\beta_i^*=1/s$。于是「重要性」被证明可写成**带权符号距离**——$v_i$ 到超平面 $\theta^\top v+b=0$ 的有符号距离再乘 $a_i$。最关键的直觉：$\theta$ 取淘汰前输出 $y$ 时，保留高分 token 等价于保住 $y$ 在锚方向上的投影，也就是保住输出的主要语义分量；而既有的纯注意力打分恰好是 $\theta=0,b=1$ 的特例，全部落入这一族函数中。

## 3. 方法机制

框架沿用 SnapKV 的观测窗口：用 prompt 末尾若干 token 产生查询 $\{q_t\}_{t\in W}$，逐步算出 $a_i^t$ 与淘汰前输出 $y_t$，累加得 $s_i=\sum_{t\in W}a_i^ty_t^\top v_i$；无条件保留观测窗口内 token 与首 token；在同一层的**所有注意力头之间统一做 top-k**，实现头间自适应预算；另用「把相邻 token 合并成 chunk」的技巧，因为 SnapKV/Ada-KV 的 max/mean pooling 会使相邻 token 得分相近，连续选择更稳。代价是每个观测步要多算一次 $y_t^\top v_i$ 的投影，比纯注意力打分多一层内积。作者明确说明 (P0-C) 是 NP-hard、无法精确求解，因此推导的定位是「打分函数形式的动机」，而不是最优性保证。

## 4. 实验证据

Table 1（Mistral-7B-Instruct-v0.2，LongBench 16 数据集平均分）：Full Cache 42.51；预算 128 时 AnDPro 38.96，高于 CriticalKV 38.42、Ada-KV 37.41，SnapKV 35.09、Streaming 27.63；预算 256 时 40.84 对 CriticalKV 40.03、Ada-KV 39.93；预算 512 时继续领先同档基线。Table 3 给出 Llama-3.1-8B-Instruct 的对应结果，Table 4 补 5 个中文 LongBench 数据集；Table 5/6 是 64K 与 128K 序列的运行时分析，结论为与 Ada-KV 相当、接近 SnapKV。摘要的总量结论为：以 3.44% 的 KV 预算保持 96.07% 全量精度，相对此前 SOTA 减少 46.0% 预算。消融（§4.5）覆盖锚方向 $\theta$ 与偏置 $b$：精心选取的 $b$ 有小幅收益，$b=0$ 已足够稳定。

## 5. 第一性原理再审视

理论强度需要降级理解：推导是在**单头、单查询**下完成的，且作者承认目标 NP-hard、只能借「screening rules」的形式去启发式设计打分函数，所以 Corollary 1 保证的是「存在这样一族函数」，而不是「这个具体实例最优」。$\theta=y$ 的理由（保住输出主方向）是直觉而非定理；$b$ 是在纯注意力打分与纯投影打分之间插值的旋钮，最优取值随任务变化且需调参。证据侧有三处缺口：其一，松弛中固定 $s$ 的这一步骤与筛选阈值 $\lambda s$ 在推理时并不显式出现，理论与实现的连接是松的；其二，评测上限为 128K 且集中在 LongBench，未涉及更长的真实上下文，也未覆盖解码期动态淘汰（本文是 prefill 阶段淘汰）；其三，头间统一 top-k 被称作「自适应预算」，但未与 Ada-KV 的逐层/逐头预算方案做正交组合实验，二者收益能否叠加未知。此外，3.44% 预算下 96.07% 是对**全量平均分**的比值，而非逐任务下界——在 PCount 这类全量分极低（2.75）的任务上，相对波动会被显著放大。

## 6. 与相邻工作的关系

与 SnapKV 共享观测窗口与 prefill 淘汰框架，是最直接的模板；与 Ada-KV 共享头间预算分配思想但打分函数不同；与 CriticalKV 最近——后者把注意力分与 value 范数结合，本文给出「得分应为 $a_i$ 乘 value 向量到超平面的带权距离」这一更一般的族，$\|v_i\|$ 型打分是其特例；与 H2O 这类生成阶段累计注意力的方法属于不同阶段。整体脉络是「淘汰打分函数的形式化」，与量化（P034）、低秩 + 稀疏（P035）构成 KV 压缩的三条正交路线。

## 7. 可迁移点与开放问题

最可迁移的是这套建模套路：把启发式排序改写为「保留子集以逼近全量输出」的稀疏优化，用对偶与 KKT 推出打分函数应有的函数形式，再据此挑一个可计算的实例——该流程可直接搬到 MoE 专家选择、检索 top-k、稀疏注意力掩码设计等任何同构问题。开放问题：$b$ 与阈值能否由校准自动确定；prefill 淘汰与解码期动态淘汰能否用同一目标统一；在 GQA/MQA 等 key 头共享的架构下，头间统一 top-k 的语义如何重定义；以及能否给出保留率 $k/n$ 与输出误差上界之间的显式关系，而不只是一个启发式打分函数。
