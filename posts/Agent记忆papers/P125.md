# P125 From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents

- 方向簇：AGENT
- 链接：/2026.findings-acl.1337/
- 本地全文：cache/txt/P125.txt

## 一句话贡献

提出 Memora：一个覆盖**数周到数月**用户对话的长期记忆基准，评估三类记忆相关任务——记住、推理、推荐；数据质量由自动记忆接地检查与人工评估双重保障。论文进一步提出 **FAMA（Forgetting-Aware Memory Accuracy）**指标，在评测中惩罚对**已过时或已失效记忆**的依赖。对四个 LLM 与六个记忆 agent 的评测显示：系统频繁复用失效记忆、无法调和演化中的记忆，记忆 agent 仅带来边际提升。

## 1. 问题与第一性原理动机

既有长期记忆评测几乎都把问题定义为「从过去对话中检索事实」，这隐含了一个错误前提：**记忆的正确性不随时间变化**。但在真实个性化场景中，用户的状态会变化（换了工作、搬了城市、偏好改变），此时「记得清楚」反而可能导致错误——模型准确回忆起三个月前的地址并据此推荐，是检索成功、任务失败。因此评测必须同时考察「记住」与「**忘掉**」，后者才是长期记忆系统与普通检索系统的分界线。这与 P117（记忆随时间衰减、存在类别偏好）互为补充：一个测衰减，一个测过时信息的危害。

## 2. 核心洞察

洞察是**把「依赖失效记忆」变成可量化的惩罚项**。FAMA 的设计前提是评测数据中标注了哪些记忆已被后续交互使之失效；有了这一标注，就能区分「答错」与「答对但依据过时」两类失败，从而暴露现有系统的真实短板。评测结论（频繁复用失效记忆）指向一个结构性缺陷：当前记忆系统普遍把写入当作追加，缺少**基于时间与来源的失效机制**——这与 P024（REMem 刻意保留矛盾事实以供历史查看）形成有价值的张力：保留全部历史在可审计性上正确，但若不配备冲突消解机制，就会在决策时误用旧信息。

## 3. 方法机制

(1) 构造跨周/月的用户对话，配以三类任务（记住、推理、推荐）；(2) 用自动记忆接地检查 + 人工评估保证数据质量；(3) 定义 FAMA 指标对依赖失效记忆的行为施加惩罚；(4) 在四个 LLM 与六个记忆 agent 上做系统评测。局限在于：失效标注由构造过程决定，真实场景中的失效往往是**渐进且模糊的**（偏好缓慢漂移），基准用离散标注简化了这一点。

## 4. 实验证据

核心发现：现有系统频繁复用失效记忆、无法调和演化中的记忆；记忆 agent 相对普通 LLM 只取得边际改进。这一负面结论对领域价值很高——它说明当前记忆系统的能力提升主要发生在「召回」维度，而「遗忘/更新」维度几乎是空白。

## 5. 第一性原理再审视

第一，「记忆 agent 仅有边际提升」需要在指标口径下理解：若主要增益来自 FAMA 这类惩罚过时信息的指标，而现有 agent 的设计目标本就不含遗忘，则结论是「评测揭示了方向缺口」而非「agent 无用」；论文应分别报告「记忆准确度」与「过时依赖率」两类指标的变化。第二，失效标注的离散化（某记忆在某个时间点被显式更新）与真实的渐进漂移有差距，因此 FAMA 可能高估系统在真实场景中的问题，也可能低估（若用户未明确否定旧信息，系统无从知道其已失效）。第三，推荐任务引入了个性化系统的评价难题（何为「好推荐」），其指标设计会影响结论方向。第四，与 P117（LOCCO）相比，二者都在补「时间」这一维度，但 Memora 更进一步引入了失效概念；与 P094（SCBench 以 KV cache 生命周期为轴）相比，Memora 关注的是**信息生命周期**（写入—演化—失效），更适合作为记忆系统的评测标准。第五，人工评估的规模与一致性对结论可信度影响大，需核实。

## 6. 与相邻工作的关系

与 P117（LOCCO 的长期记忆评测）互补：LOCCO 测记忆衰减与类别偏好，Memora 测过时依赖与演化调和；与 P027（BEAM，10M token 级对话基准）在长度上不同、在能力维度上更聚焦「遗忘」；与 P094（SCBench 的 KV cache 生命周期视角）在「生命周期」这一概念上呼应，但对象是语义记忆而非缓存；与 P024（REMem 保留矛盾事实）构成直接张力——Memora 的结论提示单纯保留历史并不足够，需要显式的失效与消解机制。

## 7. 可迁移点与开放问题

可迁移：(a) 「记忆正确性随时间变化」应成为长期记忆评测的默认假设，FAMA 式的失效感知指标值得推广到个性化推荐与助理系统；(b) 把「遗忘了什么」与「记住了什么」分开度量，是发现系统性缺陷的有效手段。开放问题：渐进式偏好漂移的建模与标注；失效检测的信号来源（用户反馈、时间衰减、冲突检测）；保留历史与避免误用之间的机制设计；以及推荐类任务的评价标准。
