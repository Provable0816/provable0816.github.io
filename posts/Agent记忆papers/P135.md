# P135 Stability Implies Redundancy: Delta Attention Selective Halting for Efficient Long-Context Prefilling

- 会议/来源：ACL 2026
- 方向簇：CTX
- 链接：/2026.acl-long.1235/

## 贡献

提出 DASH（Delta Attention Selective Halting）：长上下文预填充的计算成本是 LLM 与多模态模型的显著瓶颈，而既有的 token 剪枝方法依赖启发式、破坏与 FlashAttention 等高效 kernel 的兼容性。论文的观察是 **token 会演化到「语义固定点」**，此后的继续处理是冗余的；据此设计一个**免训练**策略：监控自注意力机制的逐层更新动态，对已稳定的 token 选择性地**停止计算（halt）**，从而在保持精度与硬件效率的同时显著加速预填充。

## 机制要点

标题的判断很有力：**稳定性意味着冗余**。其逻辑是，如果某 token 的表示在若干层之间几乎不再更新，那么继续让它参与后续层的计算（含注意力与 FFN）就只是重复劳动。这为「跳过计算」提供了与重要性打分完全不同的依据——它不判断 token 有多重要，而判断 token 是否「已经定型」。这一视角的好处是：它不需要读取注意力矩阵（因此与 FlashAttention 兼容，回应了 P042、P090、P107 都遇到的同一工程约束），也不需要训练额外模块（免训练）。代价是判定阈值与跳过策略成为新的设计面，且「提前停止」意味着该 token 不再接收后续层的信息——若后续层本会对其做出关键修正，就会产生错误。

## 关键结果

论文报告 DASH 在语言与视觉基准上均可泛化，取得显著的预填充加速，同时保持模型精度与硬件效率；代码将开源。这一结论的价值在于它同时满足了三个常被权衡的目标（加速、精度、kernel 兼容性），这在 token 剪枝文献中并不常见。

## 局限与定位

第一，「语义固定点」是经验观察，其存在性与普适性需要更强的证据：固定点是否在所有层深出现、在需要长程修正的任务（如指代消解、跨段推理）上是否仍成立，直接决定方法的安全性；若某些 token 在前层看似稳定、后层才需要被修正，提前停止会造成难以定位的错误。第二，加速集中在**预填充**阶段，而解码阶段（尤其是长生成）的计算与访存开销不在优化范围内；端到端收益取决于两者的占比，摘要未给出分解。第三，免训练与 kernel 兼容是显著优点，但「选择性停止」意味着 batch 内不同 token 的计算路径不同，实际实现是否真能保持高效（无 warp 分歧、无负载不均）需要实测数据；论文主张「保持硬件效率」，但应给出 kernel 层面的证据。第四，与 P118（按句间相似度动态切块）、P134（并行精读/略读）等「预填充阶段优化」的方法相比，DASH 的判据是表示稳定性而非内容相关性，二者是否可叠加（先按相关性选段、再对稳定 token 停止）值得探索。定位上属于免训练、kernel 友好的预填充加速方法。
