# P012 PM-KVQ: Progressive Mixed-precision KV Cache Quantization for Long-CoT LLMs

- 会议/来源：ICLR 2026（主会）
- 方向簇：KV

- 本地全文：cache/txt/P012.txt

## 一句话贡献

提出 PM-KVQ：面向长 CoT 推理模型的**渐进式混合精度** KV 量化——(1) 按 block 逐步降低位宽并用 block-wise 内存分配把高位宽留给敏感层，(2) 用带位置插值的短上下文标定数据近似长上下文分布，在同等显存预算下把推理基准提升最多 8%，并给出相对 16-bit 原始模型 2.73–5.18× 的吞吐。

## 1. 问题与第一性原理动机

长 CoT 模型可生成 128K token 的推理链，KV 缓存开销从约 10GB 到 100GB 量级，成为部署的主要瓶颈。训练后 KV 量化在短上下文中已相当成熟，但直接迁移到长 CoT 会明显掉点，原因有两条结构性的：(1) **累积误差**——每个 decoding step 都对缓存做一次量化，误差在数千步上叠加，而现有方法没有充分利用可用显存去换取更低误差；(2) **标定失配**——由于 RoPE，Key 缓存中不同通道的频率不同，用短上下文标定无法覆盖长上下文中那些「出现频率低」的通道的分布，量化尺度因此设错。这两点都不是调参问题，而是「压缩决策的时间粒度」与「标定数据的长度尺度」两个维度的结构性错配。

## 2. 核心洞察

把量化从「一步定终身」改成**渐进过程**：位宽按 block 从高到低逐级下降（16→8→4→2 的顺序逐步降低），让误差在已有较高精度的缓存基础上缓慢累积；同时在层与层之间做非均匀分配——对量化更敏感（误差影响更大）的 block 给更高位宽，把有限的显存预算当作可分配资源而非统一约束。第二条洞察针对标定：既然 RoPE 让长上下文主要改变低频通道的覆盖，那么可以用**位置插值**把短标定数据映射到更长的位置尺度上，免费获得接近长上下文的统计。

## 3. 方法机制

三部分：(1) progressive quantization——按 block 逐步降低 KV 位宽，缓解累积误差；(2) block-wise memory allocation——按敏感度给不同 transformer block 分配不同位宽，敏感 block 保留更高精度；(3) positional-interpolation calibration——用短数据加位置缩放（按比例 $s$ 放大位置索引，无需额外计算与显存）来近似长上下文数据分布。方法作用于已有模型（post-training），不需重训主干。代价是：需要标定与敏感度估计流程；极端低位宽（如 2-bit）仍属激进设置；且论文报告的「性能结果使用 fake quantization 在 8×A100-80G 上测量」，即量化算子为模拟实现，真实内核下的端到端收益需另行验证。

## 4. 实验证据

模型：7B–70B 长 CoT 模型（含 DeepSeek-R1-Distill-Qwen-7B 等）；基准：AIME-2024/2025、CMIMC-2024 等数学推理基准；设置上对小于 10B 的长 CoT 模型采用更激进的低位宽（Table 2 的配置列），其余模型用较高位宽，并在相同显存预算下与 SOTA 量化基线对比。

关键数字：摘要给出「同显存预算下推理基准最高提升 8%，相对 16-bit 吞吐 2.73–5.18×」；正文指出在 AIME-2024 上相对基线最高提升 6.5%，在部分设置下甚至优于原始模型（Table 2 附近的讨论）。Table 1 给出长 CoT 模型在不同 batch/上下文下的显存开销，用以说明问题的严重性；附录给出更多模型与配置。

证据缺口与疑点：(a) 吞吐数字建立在 fake quantization 的性能测量上，缺少真实低位宽内核的实测；(b) 评测集中在数学推理（AIME/CMIMC），对长文检索、代码、多语言没有证据，而 KV 量化的误差在不同任务族上分布差异很大；(c) 「优于原始模型」这类结论通常需要多种子与置信区间支撑，论文未提供统计检验。

## 5. 第一性原理再审视

PM-KVQ 的两条设计都可以从误差传播的角度理解：量化的总误差近似为「每步误差 × 步数」与「各层误差经后续层放大的和」。渐进量化降低前半段误差（早期缓存更准，后续步骤的输入分布偏移更小），block-wise 分配把位宽投到误差放大系数最大的层——这本质上是一个**误差预算分配问题**，而不是均匀压缩问题。论文给出了启发式分配，但没有给出最优性论证，也没有测量「敏感度」的定义（是梯度、量化误差方差，还是输出扰动）与最终性能的相关性。标定侧的洞察更优雅：RoPE 下「上下文长度」在频域上等价于通道覆盖率，因此位置插值是一种零成本的分布增广；但它假设插值后的位置分布能代表真实长上下文的分布，这两者只在「位置对注意力衰减的作用近似平移不变」时等价，对需要在极长距离上保持精确位置的检索任务可能不成立。此外，位宽压到 2-bit 时，KV 的表示误差已接近信息论意义上的下限，此时方法收益更多来自「分配」而非「压缩本身」，论文缺少与「同等平均位宽下的简单均匀量化」的严格对照来分离这两个效应。

## 6. 与相邻工作的关系

与 KIVI、KVQuant 等训练后 KV 量化的区别在于面向长 CoT 的两个新失效源（累积误差与标定失配）做针对性设计；与 eviction（H2O/SnapKV）、检索（P005/P011）、频域压缩（P006）、变换编码（P009）同属缓存压缩的不同维度，量化路线与它们最适合叠加（例如先淘汰后量化、或对低频分量用更低比特）；与 P010、P003 这类需要训练/标定的方法相比，PM-KVQ 同样属于「需要标定但不动主干」的一类。

## 7. 可迁移点与开放问题

可迁移：(1) 「渐进降精度」作为通用误差控制手段，可用于 KV 量化的在线调度、模型权重逐层降比特、乃至 agent 记忆的分级压缩；(2) 「用位置插值构造长上下文标定集」这一免费增广技巧，可迁移到任何受 RoPE 影响的量化/剪枝标定流程。开放问题：敏感度分配的度量与最优性；真实低位宽内核下的端到端收益（当前为模拟测量）；在其他任务族（检索、代码、多语言）上低比特是否仍稳健；量化误差与淘汰误差的联合预算如何最优分配。
