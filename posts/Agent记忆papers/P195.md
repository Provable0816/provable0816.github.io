# P195 MemCoE: Learning How and What to Memorize — Cognition-Inspired Two-Stage Optimization for Evolving Memory

- 会议/来源：ACL 2026（主会）
- 方向簇：AGENT
- 链接：https://aclanthology.org/2026.acl-long.2084/
- 本地全文：cache/txt/P195.txt

## 一句话贡献

把 agent 长期记忆的更新拆成「**怎么组织**」与「**更新什么**」两阶段学习：第一阶段用对比反馈当作文本梯度，归纳出一份全局 Memory Guideline（MGI）；第二阶段用该 guideline 定义结构化过程奖励，做 Guideline-Aligned Memory Policy Optimization（RL），从而在稀疏结果奖励下获得稳定的长时程记忆演化。

## 1. 问题与第一性原理动机

个性化 agent 需要跟踪用户偏好演化，而上下文窗口有限，因此必须有记忆的构造与更新。既有做法的两条路都走不通：**手工规则**（何时写入、何时覆盖）无法覆盖真实对话的多样性；**端到端 RL 学记忆更新**受制于奖励稀疏——用户是否满意往往很久后才知道，且这个标量无法告诉策略「哪一步记忆操作错了」。这构成结构性问题：记忆更新是**长时程、稀疏反馈、组合动作空间**的决策问题，直接用结果奖励学习必然方差爆炸。人类记忆的启发在于分工：前额叶负责「按什么规范组织」，海马负责「具体写什么」，两者分而治之。

## 2. 核心洞察

把「规范」与「执行」解耦后，规范层可以不必依赖 RL 的稀疏奖励。关键技巧是把**对比反馈解释为文本梯度**：不需要数值奖励，只要有「这样组织比那样更好」的比较性语言反馈，就能迭代改进一份自然语言 guideline。规范一旦成立，它就把稀疏结果奖励**稠密化**为过程奖励——第二阶段 RL 因此获得可用的监督。这一「先学规范、再学执行」的顺序，等价于把不可解的长时程信用分配问题转化为可解的「规范归纳 + 规范对齐」两级问题。

## 3. 方法机制

第一阶段 **MGI**：采集对比反馈，把「哪次记忆组织更好」的文本信号当作梯度方向，迭代更新全局 guideline。第二阶段 **GAMPO**：以 guideline 构造结构化过程奖励（消融中的 GR 组件），训练记忆策略决定何时写、写什么、覆盖什么。框架见 Figure 1（上：窗口受限导致偏好丢失；下：前额叶→海马的分工解耦）。代价：需要可获得且高质量的对比反馈，反馈质量决定 guideline 上限；两阶段训练增加管线复杂度；guideline 以自然语言承载，迭代中可能漂移。

**证据缺口**：(a) 对比反馈的来源与获取成本未被量化——若依赖强模型生成反馈，「两阶段学习」的收益应与该生成的算力成本一并核算；(b) guideline 是自然语言文本，论文未报告其随迭代的**漂移/退化**情况（多轮诱导后是否稳定、是否自我强化）；(c) 评测集中于个性化偏好任务，对需要事实精确性的长期记忆（日程、数值）缺少验证；(d) 记忆规模的绝对增长与压缩率未报告，因此它解决了「更新什么」，但未直接回答「记忆如何变小」。

## 5. 第一性原理再审视

MemCoE 的成立依赖一个关于反馈的假设：**存在可比性信号**。在真实产品中，反馈常是「最终不满意」这类稀疏且归因不明的信号；「把对比反馈当文本梯度」这一步实际上把最难的部分（获得可比较的偏好判定）外包给了数据采集环节。第二个更深层的假设是：**记忆组织的「正确规范」稳定且可被自然语言表达**。这与信息论视角存在张力——什么记忆值得保留，本质上依赖未来查询的分布（见 P170 的分析）；静态 guideline 只能近似这一分布，一旦用户偏好发生**类型转换**（而非程度变化），guideline 会成为偏置来源。第三，从「记忆压缩」角度看，该工作关注**写入策略**（what to update），而压缩关注**存储表示**（how much to keep）；两者可组合——用 guideline 决定保留粒度，用压缩技术决定单位成本——但论文未做这类组合实验，其自适应压缩潜力仍属推测。

## 6. 与相邻工作的关系

与基于手工规则的长时记忆系统（MemoryBank 一类）相比，它把规则学习化；与直接用 RL 学记忆更新的工作相比，它通过 guideline 把稀疏奖励稠密化。与 P170（CMT）在「记忆的写入/组织必须由任务信号决定」这一点上同源，但 CMT 面向持续知识学习、MemCoE 面向个性化偏好演化。与 P175（ARTEM）、P176（GSW）相比，后两者关注记忆的**表示结构**（时空坐标、语义工作区），MemCoE 关注记忆的**更新规范**，三者构成「表示—结构—策略」三个互补层次。与 P210（LightMem）同属「降低记忆系统自身开销」的一支。

## 7. 可迁移点与开放问题

可迁移：(a)「**先归纳规范、再用规范构造过程奖励**」的两级范式，可推广到任何长时程决策但只有稀疏结果反馈的场景（工具使用策略、多轮检索、agent 规划）；(b) 文本梯度（用语言反馈直接改进自然语言规范）是与参数梯度互补的优化通道，适合低成本持续改进。开放问题：反馈获取的成本与质量下界；guideline 的长期稳定性与防漂移；把「保留什么」的规范与「保留多少」的压缩预算联合优化；偏好类型转换下的重诱导机制。
