# P174 QJL: 1-Bit Quantized JL Transform for KV Cache Quantization with Zero Overhead

- 会议/来源：AAAI 2025（主会）
- 方向簇：KV
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/34773
- 本地全文：cache/txt/P174.txt

## 一句话贡献

用「Johnson–Lindenstrauss 变换 + 符号位」取代传统量化：先做随机投影把向量压到 $m$ 维，再只取符号（1 bit/坐标），彻底消除 per-block 的 scale/zero-point 常数开销；同时给出一个**非对称内积估计器**（一侧用 QJL 量化、另一侧用不量化的 JL 变换），证明其无偏且失真最小，实测 3 bit 下 KV 显存 >5× 降低且不损精度，并实现为零开销 CUDA kernel。

## 1. 问题与第一性原理动机

注意力的核心运算是内积 $q^\top k$，因此压缩 KV 的**唯一目标是保住内积**，而不是保住向量本身的数值。传统量化（per-block scale + zero point）是「按数值重建」的思路，它的开销随块变小而相对变重——论文指出这部分常数开销可达 1–2 bit/数值，等于在 2 bit 量化的名义码率上再加 50%–100%，这解释了为什么低位宽量化很快触底。换一个目标函数（保住内积）就能换一套工具：**随机投影的保距性（JL 引理）**天然保证内积近似，而取符号是极限压缩下的自然选择；常数开销则通过不对称设计被彻底消除。

## 2. 核心洞察

(1) 把「估计内积」本身作为压缩目标，可绕开数值重建的精度要求；(2) 需要一个**不对称**的估计器：如果两侧都取符号，会引入系统性偏差，而让一侧保持 JL 变换的连续值（不量化）、另一侧取 QJL 的符号位，能得到无偏估计且方差更小（摘要明确「applying QJL to one vector and a standard JL transform without quantization to the other provides an unbiased estimator with minimal distortion」）；(3) 无偏 + 无常数，意味着误差只来自投影维度 $m$ 的选取，而理论给出 $m \sim 1/\varepsilon^2$ 的缩放（Ablation 中与 Figure 3 吻合）。

## 3. 方法机制

流程（Figure 1）：对 key 向量做随机投影 → 取符号位得到 QJL sketch（1 bit/投影维）；query 侧保留 JL 变换后的连续表示；内积由非对称估计器计算。存储上只需要 sketch 本身，**不存任何 scale/zero-point**，因此名义码率即实际码率。实现上提供两个 CUDA kernel（量化与批量内积），wrapper 用 PyTorch。论文给出 Theorem 3.6 刻画失真随维度的 Scaling。代价：随机矩阵与投影需要实现上的配合；估计器虽有理论保证但方差随投影维数下降，存在「码率—估计方差」的硬权衡；此外 CUDA 侧的完整实现被列为未来工作。

## 4. 实验证据

硬件为单张 A100-80GB。模型为 longchat-7b-v1.5-32k 与 Llama-3.1-8B-Instruct，基准为 LongBench 的多任务子集（Table 1 上下两表分别为两个模型），另在 LM-eval 标准长度任务上补测（Table 2，论文称 3-bit QJL 与 16-bit 基线「comparable」）。效率上，Figure 4 给出不同量化方法在单注意力层内的编码/解码 wall-clock 对比（输入长度 1k–64k），Figure 5 给出峰值显存。消融（Figure 3）：失真随 bits-per-token 与 $m/d$ 的变化与理论 $m\sim1/\varepsilon^2$ 一致；一个值得注意的观察是**第一层的失真明显高于其它层**，说明浅层最难量化，需要差异化的比特分配。

**证据缺口**：(a) 摘要的「without compromising accuracy」落在 LongBench 平均分上，缺少**逐任务最差值**的呈现——尤其长程精确检索类子任务对 KV 误差最敏感，平均分会掩盖它；(b) 「零开销」是相对于 per-block 常数而言，但 sketch 的**随机矩阵与元数据**（种子、维度）本身的存储与调度成本未做端到端计量；(c) 与同样主张低比特的耦合量化方法（如「1 bit per channel」路线）缺少直接对照实验，读者难以判断 QJL 的位宽优势在同等实现成熟度下是否保留。

## 5. 第一性原理再审视

QJL 的成立依赖一个比「量化」更弱的假设：只需要内积的无偏估计，而不需要逐元素保真。这在注意力场景下是对的方向，但有两个边界条件必须指出。第一，**无偏低比特 ≠ 任务无损**：注意力分布经 softmax 后对误差的敏感度不均，$q^\top k$ 的小扰动在大 logits 处可能改变 top-1 的检索结果，而长程检索任务恰恰依赖这一 top-1 的正确性；因此「平均精度不掉」与「精确召回不掉」是两件事，论文的评测设计没有区分。第二，非对称估计器把「精度负担」转移到了 query 侧——query 不量化意味着这个方案压缩的是 **KV 而非激活**，在被复用为「在线推理加速」时（query 每步都要重算 JL 变换）需要额外的算力预算，论文的 wall-clock 图说明实现层面这件事是可控的，但需要读者注意它并非免费。第三，从信息论看，1 bit/投影维之所以够用，是因为随机投影已经把信息「均摊」；代价是想要更高精度必须增加维度（即增加实际存储），因此该方法真正的调节旋钮是维度而非位宽，这与传统量化的直觉相反，这一点对系统设计者很重要。

## 6. 与相邻工作的关系

与 KIVI、KV cache 耦合量化、WKVQuant 等量化路线共享目标但换了数学工具（随机投影 + 符号位 vs 数值重建 + scale）；与 P171（CSR）是同一问题的两种「结构性压缩」解法：CSR 用共享字典的稀疏编码，QJL 用随机投影的符号位，前者学数据分布，后者用与数据无关的随机基，QJL 的泛化性更好但无法利用数据低维结构。与 eviction（H2O、StreamingLLM）正交，可与 Sketching 类 prefill 加速（SubGen 等）共享同一套投影技巧。

## 7. 可迁移点与开放问题

可迁移：(a)「压缩的目标不是数值而是下游算子」这一原则，可直接推广到 agent 记忆库的相似度检索（用内积估计保真度而非向量保真度）；(b) 随机投影 + 符号位是**与数据无关**的压缩器，适合冷启动或需要跨模型复用的场景；(c) 层间失真不均衡（第一层最难）支持「按层分配比特」的差异化压缩。开放问题：把无偏性升级为**面向任务的失真度量**（对 softmax 后的检索正确率有界）；与 eviction、稀疏编码的组合；以及随机矩阵在高并发 serving 中的调度成本如何摊销。
