# P165 VecAttention: Vector-wise Sparse Attention for Accelerating Long Context Inference

- 会议/来源：CVPR 2026
- 方向簇：VLM
- 链接：/content/CVPR2026/html/Liu_VecAttention_Vector-wise_Sparse_Attention_for_Accelerating_Long_Context_Inference_CVPR_2026_paper.html

## 贡献

面向视频模型的长上下文推理，指出既有稀疏注意力采用**粗粒度模式**，因此带来冗余计算与次优性能；提出 VecAttention：一个**向量级（vector-wise）稀疏注意力**框架，以获得更优的准确率—效率权衡。论文观察到视频的注意力图呈现强烈的**垂直向量稀疏模式**，并进一步证明该模式相对既有粗粒度模式在准确率—稀疏度权衡上**一致更优**。

## 机制要点

设计的关键在于**稀疏单元的粒度**：粗粒度模式（块、窗口、行）要么保留过多冗余（效率不足），要么一次性删掉整块（精度受损）；向量级模式把稀疏性定义在更细的单元上，因此能在相同预算下更贴近真实注意力分布。这一「粒度决定权衡曲线」的论断在本批工作中反复出现——P039（chunk 级 vs token 级）、P057（token→chunk 相关性）、P157（结构化的层级粒度）都指向同一规律。第二个要点是「垂直向量」这一结构性发现：视频注意力的稀疏性沿某一固定方向呈现规律，说明可以利用**几何结构**而非仅靠打分阈值，这与 P163（频域主成分）、P081（模态感知置换）在「先找到结构再稀疏化」上同源。

## 关键结果

论文报告向量级模式在准确率—稀疏度权衡上一致优于粗粒度模式，从而在视频模型上取得更好的效率—精度平衡；具体加速倍数与基准需回看正文。判断价值的关键在于：在**同等实测延迟**下与粗粒度方法比较精度（而非在同等名义稀疏度下比较），因为细粒度稀疏的实际 kernel 效率可能不如粗粒度。

## 局限与定位

第一，细粒度稀疏的**硬件友好性**是最大疑问：块稀疏易于映射到 GPU 的规则计算，向量级稀疏需要不规则访存与 gather，实际加速可能显著低于名义稀疏度带来的理论收益——这正是 P047（非结构化稀疏需配套 bitmap 格式与专用 kernel）所证明的关键教训，论文必须给出 kernel 级证据。第二，「垂直向量稀疏模式」是在视频注意力上观察到的结构，其成因（帧内 token 的组织方式、位置编码）与普适性需要说明；换到图像或音频模态是否仍成立未知。第三，该发现与 P081（模态感知置换）有潜在联系：若稀疏方向取决于 token 排列方式，那么可以通过置换把稀疏性变得规则（P081 正是如此），二者结合可能比单纯的向量级稀疏更高效。第四，评测集中在视频模型，未涉及语言长上下文，而后者是稀疏注意力的主战场。定位上属于利用注意力几何结构的细粒度稀疏化工作。
