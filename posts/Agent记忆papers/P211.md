# P211 ∞-Video: A Training-Free Approach to Long Video Understanding via Continuous-Time Memory Consolidation

## 一句话贡献

把「长期记忆」引入视频理解：用一个**连续时间**的长期记忆（LTM）巩固机制增强已有的 Video Q-former，使其能处理任意长度视频且**无需额外训练**；连续注意力会动态地把更高粒度分配给最相关的视频片段，形成随时间演化的「黏性记忆（sticky memories）」。

## 1. 问题与第一性原理动机

长视频理解的两难是：帧采样太稀会丢信息，太密则超出上下文。根本原因在于现有做法把「看多少」当作一个**全局常量**（均匀采样 $N$ 帧），而视频中的信息密度是**高度不均匀**的——大部分时间步对任何查询都无关，少数片段承载了全部证据。因此正确的形式化不是「用多少帧」，而是「在时间轴上如何分配有限的注意力预算」。第二个结构性问题是采样是**离线固定**的：一旦选定帧就无法根据查询回溯，这与「先看一遍、问题来了再回忆」这一自然过程相反。

## 2. 核心洞察

论文把 LTM 建模成**连续时间上的记忆状态**（而非离散的帧集合）：记忆按时间累积（Figure 2 的记忆巩固机制），并允许按查询动态重分配时间分辨率。这带来两个性质：其一是**无界上下文**——因为记忆是压缩后的连续状态，视频长度不再受上下文窗口限制；其二是**黏性**——被证明相关的片段会在记忆中保留更高分辨率并在后续交互中持续存在。二者结合，使「无需训练」成为可能：不需要为长视频重新训练模型，只需在 Q-former 层面替换注意力/记忆的读取方式。

## 3. 方法机制

框架见 Figure 1：把视频切分为帧块，先用既有视频模型（Video-LLaMA 的空间 Q-former 或 VideoChat2）逐块计算，Video Q-former 把「单块的短期注意力（STM）」与「跨块的长期记忆（LTM）」做加权组合（$X_{past}=[x_1,\dots,x_T]^\top$ 形式的过去状态矩阵，见 Figure 2 附近的形式化）。代价与边界：不改动预训练模型意味着该机制的表达能力受限于原 Q-former 的接口；连续记忆的更新频率与保留长度是隐含超参；「训练-free」也意味着无法针对任务调整记忆的归纳偏置。

## 4. 实验证据

模型为 Video-LLaMA 与 VideoChat2；基准覆盖 NeXT-QA 与 EgoSchema（Table 1，多选题）、VideoMME 的 Medium/Long 分档（Table 2，与 ST-LLM、Video-LLaVA 等对照）、MovieChat（Table 3，报告 Score 及信息正确性 CI、细节导向 DO、上下文理解 CU 等分项）。Figure 7 给出定性对比：在超长视频上，均匀采样会给出与事实不符甚至幻觉的答案，而「黏性记忆」能定位到正确片段——这类定性证据对展示机制有效性很重要，但也提示需要更系统的定量验证。

**证据缺口**：(a) 基线多为较早期的视频模型（Video-LLaMA / VideoChat2），与当前强基线（Qwen-VL 系列等）的差距未呈现，因此「无训练增强」的绝对竞争力需谨慎解读；(b) VideoMME 的表只给出 Medium/Long 档，而方法的核心主张是「任意长」，缺少小时级以上的证据；(c) 「黏性记忆」的粒度分配是启发式，缺少对「分配错误」的鲁棒性分析（例如把高分辨率给了无关片段会损失多少）；(d) 评测以多选题为主，对开放式的细粒度时序问答（先后关系、计数）覆盖不足。

## 5. 第一性原理再审视

该方法的深层命题是：**记忆的粒度应当是查询条件的函数，而不是预先固定的采样率**。这与本方向在文本侧的结论完全同构——P172 用查询注意力决定保留哪些 token、P180 用注意力演化决定何时剪枝、P198 用任务损失学保留概率。三者共同指向一个统一判据：在预算受限的记忆系统中，「保留什么」必须由使用模式决定。第二个值得审视的是「连续时间」这一形式化的实际收益：把时间离散化为帧块后，连续时间记忆与「带时间衰减权重的分层缓存」在实现上未必有本质差异；论文需要通过消融证明连续性（而非仅仅是「有 LTM」）是收益来源，否则该形式化更接近一种优雅的叙述而非必需的设计。第三，无界上下文的记忆必然有**累积衰减**问题：连续状态在长时程上会被反复压缩，早期细节的损失速度是关键而未刻画的量。

## 6. 与相邻工作的关系

与视频侧的 token 压缩方法（P168 FrameFusion、P169 VFlowOpt 一类，压缩的是视觉 token 而非记忆状态）不同，本文作用在记忆层；与 P197（MM-MEM 的金字塔多模态记忆 + SIB-GRPO 动态管理）相比，MM-MEM 依赖训练与任务奖励，本文坚持免训练与查询驱动，两者构成「训练式记忆管理」与「免训练记忆巩固」的对立设计；与 P191（DigimonGPT 的陈述/程序记忆）相比，本文更强调时间维上的连续巩固。与文本侧的 P173（句级压缩）思路相同——都是在语义单位上做预算分配。

## 7. 可迁移点与开放问题

可迁移：(a) **按查询动态重分配时间/空间分辨率**这一原则，可直接用于 agent 的长历史管理（近期详细、远期摘要，但摘要层可按查询临时升采样）；(b) 「黏性」机制——对已证明相关的片段保持高保真——是任何分层记忆系统都应具备的性质，可避免反复重新压缩导致的细节反复丢失。开放问题：连续状态在超长时程上的细节衰减曲线；黏性记忆的容量回收策略（旧的高保真片段何时降级）；与新一代强基线的结合效果；以及把「免训练」升级为「轻量适配」的性能上限。
