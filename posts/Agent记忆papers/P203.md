# P203 FlashDLM: Accelerating Diffusion Language Model Inference via Efficient KV Caching and Guided Diffusion

## 贡献

用两项**免训练**技术加速扩散语言模型（DLM）：(1) **FreeCache**——利用「干净 token 的 KV 投影在后续去噪步中变化很小」这一性质，跨去噪步复用 KV 近似，减少重复计算；(2) **Guided Diffusion**——用一个轻量的预训练自回归模型监督 token 去掩码的选择，缓解并行生成带来的 token 不一致与激进去掩码导致的质量崩塌。

## 机制要点

成本结构（Table 1）：AR 每生成一个 token 只处理长度为 $l$ 的前缀，而 DLM 每一步去噪都要处理**全长 $L$**，因此 DLM 的主要开销是「重复的全序列前向」。FreeCache 的合理性由 Figure 2 的热图证明：纵轴为去噪步、横轴为 token 位置、颜色为 V 投影的余弦相似度——干净 token 的 K/V 在后续步中变化很小。据此设计**缩减窗口（reducing window）缓存策略**：随去噪推进逐步缩小需要重算的范围。Guided Diffusion 则针对 Figure 1(a) 展示的「激进去掩码 → 质量骤降」问题，用 AR 模型充当判官来指导哪些 token 可以解锁。

## 关键结果

Table 2：在 Dream-7B-Instruct 与 LLaDA-8B-Instruct 上分别取得 **4.42×** 与 **6.32×** 加速。GSM8K（8-shot）示例对照：Dream-7B-Instruct baseline 精度 79.68%、原始延迟 48.05s；加入 FreeCache 后精度 77.40%、延迟 10.87s（对应于加速比列的提升）。Figure 1(b) 给出「精度 vs 延迟（对数刻度）」的 Pareto 前沿，说明优化后的方法支配了常见缓存基线。

## 局限与定位

第一，精度确有下降（GSM8K 79.68→77.40，约 2.3 个百分点），属于**有损加速**而非无损；论文的定位是移动 Pareto 前沿，读者应按任务容错度决定是否采用。第二，「干净 token 的 KV 稳定」是经验规律，在**高噪声/高不确定**的早期去噪步上未必成立，缩减窗口的激进程度需要按任务调节，论文缺少该超参的敏感性分析。第三，Guided Diffusion 引入一个外部 AR 模型，其额外显存与调度成本应计入端到端收益。定位上，它与 P185（Sparse-dLLM 的动态淘汰）、P202（Fast-dLLM v2 的层级缓存）、P217（dKV-Cache）并列，四者共同覆盖了扩散 LLM 缓存的「复用、淘汰、训练、近似」四种手段；本文的独特性在于**复盘了「KV 在迭代去噪中近似不变」这一时间维稳定性的直接测量**。
