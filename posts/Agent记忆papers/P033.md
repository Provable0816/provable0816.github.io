# P033 Learning is Forgetting: LLM Training as Lossy Compression

- 会议/来源：ICLR 2026
- 方向簇：THEORY
- 链接：/paper_files/paper/2026/hash/9521209996f5a0e375b3d4f1878c42b9-Abstract-Conference.html

## 贡献

把 LLM 预训练解释为**有损压缩**的实例：模型在训练中只保留与目标相关的信息，从而在信息平面上趋近 Information Bottleneck（IB）给出的最优压缩边界 $I(X;Z)=I(Y;Z)$。论文在此框架下给出可扩展到 LLM 尺度的互信息估计方法，并证明「压缩最优性」可预测下游性能。

## 机制要点

方法上用软熵估计器替代传统分箱互信息估计：把每层表示归一化到单位球面，用随机采样的方向做余弦相似度加 softmax 得到软量化分布，再取 Shannon 熵并按层平均，从而在任意模型规模上计算 $I(X;Z)$ 与 $I(Y;Z)$。通过改变 source/target 的 back-off 阶数（token、bigram、trigram、quadgram），可分解出模型信息中「token 级」与「上下文级」各占多少。

## 关键结果

OLMo2 7B 的预训练轨迹高度贴合 IB 的两阶段预测：先扩张 $I(Y;Z)$（拟合），随后压缩 $I(X;Z)$ 并逼近边界，转折点与下一 token 预测损失饱和同步（Figure 1/2）。规模效应显著：7B 与 32B 都走完扩张—压缩两阶段，而 1B 在第二阶段不再靠近最优压缩，反而震荡并缓慢远离。back-off 实验显示上下文阶数越高、压缩越接近边界；模型的信息大部分编码**局部上下文**（token 到 quadgram），1B 相较更大模型保留更多 token 级信息、更少上下文信息。跨多个开源权重模型，压缩最优性可预测六类基准上的下游表现。

## 局限与定位

需保留的限定：作者明确指出所研究的模型都远未达到饱和点，因此文中把边界简化为线性关系；语言建模中 source 与 target 采样自同一分布，「输入/输出」的区分带构造性，论文也承认这解释了为何高阶 back-off 下复杂度与表达力同时下降。互信息数值依赖球面采样数与温度 $\epsilon$ 的可比性设定，超参敏感性未系统报告。「压缩最优性预测下游性能」是相关性证据，未给出因果干预。定位上，这是把「LLM 学习 = 压缩」操作化为可测量量的理论工作，与 KV/上下文压缩的工程路线形成呼应：两者都在回答「哪些信息与目标无关」。
