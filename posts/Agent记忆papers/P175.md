# P175 ARTEM: Enhancing Large Language Model Agents with Spatial-Temporal Episodic Memory

## 一句话贡献

把「情节记忆」从向量检索栈里拆出来，交给一个可增量自组织的神经网络 STEM（基于自适应共振理论的空间—时间情节记忆），LLM 只负责事件抽取与回答生成，从而在需要**时序意识**（谁先谁后、最近发生什么、信息不足时拒答）的任务上超过 ICL/RAG/微调。

## 1. 问题与第一性原理动机

LLM 的记忆缺陷不是「记不住」而是「记不住**结构**」。RAG 用稠密向量相似度检索，本质上是把时间轴压平成一个无序集合：它擅长回答「X 是什么」，但无法回答「X 之后发生了什么」「上一条相关信息是不是已经过期」。而时序恰恰是情节记忆的定义性属性——情节（episode）由 when/where/who/what 绑定在一起，丢失任一维就不再是情节。更根本地，RAG 没有**拒答机制**：相似度检索永远返回 top-$k$，即使库中根本没有相关记忆，模型也会基于噪声作答（confabulation）。因此论文的动机可归结为两条第一性原理要求：(1) 记忆表示必须显式携带时间与空间坐标；(2) 检索必须能判「无匹配」。

## 2. 核心洞察

用 ART（Adaptive Resonance Theory）式自组织网络做记忆存储，天然满足上述两条：ART 的「警戒参数（vigilance）」决定输入必须以多高的相似度才能认领/新建一个记忆节点，把阈值调高就等于「宁缺毋滥」；多通道并行编码（时间、空间、实体、内容各一通道，Figure 2）则让每一维独立参与匹配。换句话说，**拒答能力不是额外加的模块，而是自组织记忆的固有参数**；时间维度也不是附加元数据，而是参与共振的一条通道。

## 3. 方法机制

ARTEM 由 STEM 与 LLM 双角色协作，四步流水线（Figure 1）：(1) **事件抽取**：LLM 从输入文档中抽出事件的 temporal / spatial / entitative / semantic 四类要素；(2) **多通道编码**：四类要素分别编码成向量，通过基于实例的增量学习「快而稳」地写入 STEM（fast-and-stable，指新知识立即写入而不破坏旧记忆）；(3) **警戒引导检索**：以可配置的相似度阈值做匹配，阈值即拒答门槛；(4) **记忆增强生成**：LLM 基于检索到的事件作答。代价是：事件抽取依赖 LLM，抽取质量成为整条链路的上限；STEM 的网络规模随事件数增长，增长速率未被量化；多通道相似度与阈值的设定需要按域调参。

## 4. 实验证据

评测遵循 Episodic Memory Benchmark（EpBench）的四类任务：partial cue retrieval、epistemic uncertainty detection、recent event identification、chronological recall，语料为叙事序列（如 "Synaptic Echoes"），对照基线为 ICL、RAG 与微调，覆盖多个主流 LLM。关键结果：Table 1/2 报告在事件检索任务上 STEM 对空查询（null query）取得近乎满分的正确拒答、ARTEM 为 0.95 量级；Table 3 的跨记忆架构对照显示 STEM/ARTEM 在多事件场景占优，且 STEM 在 null query 上达「perfect accuracy」；Table 4 的简单召回与时序任务上两者同样领先。Discussion 给出分项：partial cue retrieval 下 STEM 对 entity-based 查询 F1 = 0.77。

**证据缺口**：(a) 评测语料是**合成叙事**（模板化生成），事件边界清晰、时间戳显式，这与真实对话/日志中事件需要推断的难度不同，外推性存疑；(b) 「优于 RAG」的对照中，RAG 的检索器配置（切块大小、top-$k$、是否带时间元数据）会显著影响结论，论文未给出调参公平性的充分证据；(c) 未报告 STEM 在事件数达到万级/十万级时的检索延迟与内存占用，而自组织网络的规模增长正是其工程风险所在；(d) LLM-as-a-Judge 参与了评测（Figure 1 注明非核心组件），需注意评判者与被评者同源的偏置。

## 5. 第一性原理再审视

ARTEM 的隐含假设是：**事件可以被稳定地切分并参数化**。这在模板化叙事里成立，但在模糊边界场景（持续数天的谈判、渐进式状态变化）中，「一个事件」的边界本身需要推断，抽取器一旦切错，后续的时间推理就在错误的前提上进行——这类误差不会在合成基准上暴露。第二，警戒阈值把「拒答」与「漏检」绑在同一个旋钮上：阈值调高提升拒答可靠性但会拒绝掉表述差异大的正确记忆（词汇鸿沟问题），论文给出了阈值可配置性，但没有给出 precision–recall 随阈值的完整曲线，因此「拒答能力」的代价没有被量化。第三，从记忆理论看，情节记忆与语义记忆（抽象知识）应当互相支撑——反复出现的同类事件会被抽象成语义规则——而 ARTEM 只有纯情节层，没有抽象/巩固过程，这意味着它存储的成本随经历线性增长，缺少人类记忆的压缩机制（这一点正是「记忆压缩」方向最应该追问的）；与 P176（GSW）同样借用神经科学蓝本，两者的差异可以理解为「记忆的动力学 vs 记忆的结构」。

## 6. 与相邻工作的关系

与 RAG 的区别在于表示：RAG 是无序稠密向量，ARTEM 是带时空坐标的多通道结构化节点。与 Key-Value Memory Networks、Differentiable Neural Computers 同属「外部可微/结构化记忆」传统，但论文指出前者时序依赖建模弱、后者扩展性差，STEM 走的是**非梯度、实例式**的第三条路。与 P176（GSW，生成式语义工作区）同为 2026 年的情节记忆工作但取向不同：GSW 用 LLM 生成可解释的语义图并做一致性调和，ARTEM 用自组织网络做增量写入与警戒拒答。与 MemoryBank 等长期对话记忆系统的差别是它显式建模时间轴。

## 7. 可迁移点与开放问题

可迁移：(a) **把「能否拒答」作为记忆系统的第一等指标**，用警戒/阈值机制而不是事后校验来实现，这对任何 RAG 类记忆都适用；(b) 多通道（时间/空间/实体/内容）分别编码再联合匹配，是可以直接搬到对话记忆、代码库记忆、日志记忆的表示设计。开放问题：情节→语义的巩固与压缩（把重复情节抽象成规则以抑制库增长）；事件边界的自动推断；真实（非合成）长时程数据上的评测；以及在事件库规模达到 $10^5$ 以上时的检索效率。
