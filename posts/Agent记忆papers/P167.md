# P167 Explore with Long-term Memory: A Benchmark and Multimodal LLM-based Reinforcement Learning Framework for Embodied Exploration

- 会议/来源：CVPR 2026
- 方向簇：AGENT
- 链接：/content/CVPR2026/html/Wang_Explore_with_Long-term_Memory_A_Benchmark_and_Multimodal_LLM-based_Reinforcement_CVPR_2026_paper.html

## 贡献

面向具身探索提出「长期记忆具身探索」任务：理想的具身 agent 应具备终身学习能力以应对长时程复杂任务；为此论文 (1) 构建了一个在**多目标导航**过程中采集情景记忆的基准，并引入**基于记忆的问答（Memory-based Question Answering）**来统一并评估模型的认知与决策能力；(2) 提出一个基于多模态 LLM 的强化学习框架。

## 机制要点

方法上的关键设计是**用「记忆问答」作为认知能力的代理评测**：具身任务的成功率既受决策能力影响，也受环境随机性影响，直接用任务完成率评估记忆质量会被噪声淹没；把记忆抽出来单独提问，就得到一个更纯净的度量，同时又能与决策任务共享同一份记忆。这与 P093（EM-LLM 用事件记忆支撑长文问答）、P157（AriGraph 把记忆图用于规划）在「记忆既是认知对象也是决策基础」这一认识上一致。第二个要点是用多模态 LLM + RL：把视觉观察直接纳入策略学习，而非依赖文本化的观察摘要（后者会丢失空间信息）。

## 关键结果

论文报告基准与框架的设计及其在具身探索任务上的验证；具体指标（导航成功率、记忆问答准确率）与基线需回看正文。评估时应关注**记忆问答与任务成功之间的相关性**——若两者不相关，说明该代理指标未能捕捉对决策有用的记忆。

## 局限与定位

第一，仿真环境中的具身探索与真实机器人存在显著差距（感知噪声、动态障碍、动作不可逆性），因此框架的可迁移性需要在真实平台上验证。第二，RL 训练在具身任务上样本效率通常很低，而多模态输入进一步加大成本；论文需要给出训练规模与收敛情况。第三，长期记忆在具身场景的核心难点是**空间与时间的联合索引**（「我三分钟前在哪个房间看到它」），这与 P157（AriGraph 的语义 + 情景图）面对的问题一致；论文的记忆结构设计决定了其上限。第四，与 P024（REMem 的图式情景记忆）、P146（THEANINE 的时间线）等纯语言记忆系统相比，具身记忆还需处理视角变化与遮挡，难度更高，但目前的方法成熟度更低。定位上属于具身 agent 长期记忆的基准与训练框架。
