# P032 PERK: Long-Context Reasoning as Parameter-Efficient Test-Time Learning

- 会议/来源：ICLR 2026
- 方向簇：CTX
- 链接：/paper_files/paper/2026/hash/1179c561a4efc77fbfda76aa1addce33-Abstract-Conference.html

## 贡献

把长上下文推理重述为测试时学习：推理时用梯度更新把长上下文编码进一个 LoRA 适配器，回答阶段直接丢弃原始上下文，只依赖参数化的记忆。为训练这一能力，PERK 采用双层优化——内层把上下文分段批量编码进 LoRA（也是推理时使用的同一过程），外层学习「使用更新后的适配器去召回并推理」。

## 机制要点

两个降本取舍是关键：把上下文压缩进 LoRA 而非全部模型参数；外层反向传播只截取内层最后若干步的轨迹，避免为完整多步优化过程保存计算图。因此训练显存可随模型与上下文规模扩展，而不像常规双层优化那样不可行。推理阶段上下文以「若干短段构成的批次」被消费，而非逐 token 处理整条序列，这同时绕开了长上下文模型的位置偏置。

## 关键结果

相比标准的长上下文微调，PERK 在 Qwen-2.5（0.5B 与 7B）上取得平均最高 20% 的绝对提升；与专门的长上下文 LLM 相比达到持平或更好。论文报告其对推理复杂度、长度外推（BabiLong 上外推到 64K/128K，超出 32K 训练长度）以及关键信息位置更鲁棒，并用 NIAH、注入检索干扰项的 HotpotQA/TriviaQA 做验证；消融覆盖 LoRA 秩、内层适应步数与截断长度。

## 局限与定位

丢弃原始上下文意味着模型无法引用原文、也无法在编码出错时回退，这是「参数化记忆」路线的固有代价，论文未给出可引用性评估。测试时梯度更新带来每个新上下文一次的额外优化开销，正文未报告其绝对量级与端到端延迟。泛化结论主要建立在 Qwen-2.5 家族上，规模上限 7B。定位上与 Cartridges（P020）同属「把上下文固化为参数」，区别是 PERK 用 LoRA 且**在推理时**做编码；与 MemAgent（P023）等 agent 式记忆相比，PERK 不保留可检索的显式记忆。
