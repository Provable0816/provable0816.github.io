# P123 Dynamic Long Context Reasoning over Compressed Memory via End-to-End Reinforcement Learning

- 会议/来源：ACL 2026（主会）
- 方向簇：AGENT
- 链接：/2026.acl-long.365/
- 本地全文：cache/txt/P123.txt

## 一句话贡献

提出 LycheeMemory：一个受认知启发的框架，通过**分块压缩 + 选择性记忆回忆**实现高效长上下文推理，而不处理全部原始 token。它把输入切块后用 Compressor 编码成压缩的 KV-cache 式表示；Gate 动态选择相关的记忆块；Reasoner 带着不断演化的工作记忆迭代处理这些块以完成任务。Compressor 与 Reasoner 通过端到端强化学习联合优化，Gate 则单独作为分类器训练。实验显示其在多跳推理基准（如 RULER-HQA）上取得有竞争力的准确率（消融变体最高 82%），可把上下文从 7K 外推到 1.75M，并在准确率—效率上给出优于强长上下文基线的权衡。

## 1. 问题与第一性原理动机

论文把长上下文的困难归纳为三点相互独立的障碍：**二次计算成本、信息遗忘、以及 RAG 固有的上下文碎片化**。第三点尤其值得注意——RAG 把文档切成互不关联的片段送入模型，破坏了对整体语境的把握；而分块压缩 + 迭代回忆的设计正是要在保留「分块带来的效率」的同时，通过工作记忆的逐轮演化重建片段间的联系。这实际上把「碎片化」从 RAG 的结构缺陷转化为可学习的回忆策略问题。

## 2. 核心洞察

洞察在于**分工与联合优化的搭配**：Gate（选哪些块）作为分类器单独训练，因为「相关性判断」相对稳定、可用监督信号直接学习；而 Compressor 与 Reasoner（怎么压、怎么用）通过端到端 RL 联合优化，因为二者的最优形态互相依赖——压缩器的表示形式应当便利推理器的使用，这个耦合关系无法用分离训练表达。这一分离与 P122（把学习集中在利用侧）形成互补：P122 固定压缩器因而结论纯粹，LycheeMemory 让压缩器也参与学习因而上限更高但训练更复杂。第二层洞察是工作记忆的「演化」——Reasoner 不是一次性读入所有被选块，而是带着状态迭代，这与 P023（MemAgent 的覆写式记忆）与 P025（ReMemR1 的回调）在处理方式上同族。

## 3. 方法机制

(1) 输入分块，Compressor 把每块编码为压缩 KV 式表示；(2) Gate 动态选择相关记忆块；(3) Reasoner 结合演化中的工作记忆迭代处理；(4) Compressor 与 Reasoner 端到端 RL 联合优化，Gate 独立训练为分类器。代价是：分块与压缩引入信息损失（Gist 压缩的失效模式见 P111）；Gate 的独立训练意味着其判据不随下游任务端到端调整，可能成为瓶颈；RL 训练成本高；迭代处理增加推理延迟。

## 4. 实验证据

多跳推理基准（RULER-HQA 等）上准确率有竞争力，消融变体最高 82%；上下文长度从 7K 外推到 1.75M；相对强长上下文基线给出更好的准确率—效率权衡；论文明确指出与 MemAgent（P023）的对比。

## 5. 第一性原理再审视

第一，82% 被标注为「消融变体」的结果，说明完整配置的表现另有数值；读者需要区分主结果与消融结果，避免把最好数字当作默认设置。第二，Gate 独立训练与其余部分端到端优化的**混合范式**是本文的一个潜在弱点：如果 Gate 误选了块，后续再强的 Reasoner 也无法补救，而 Gate 的监督信号来自何处、是否覆盖长尾查询，决定了系统上限；这一环节的误差分析应当是重点，但摘要未展开。第三，7K→1.75M 的外推幅度惊人，需要明确评测任务（若为 needle 式检索，则与 P023 的情况相同——低信息密度、单针任务不能代表需要全局聚合的场景）。第四，与 P023（MemAgent）的对比是自然的（两者都做分段压缩 + RL），但要注意参数规模、训练数据与评测集合是否对齐；论文若只强调优势而未说明这些条件，结论的可比性打折。第五，分块是固定还是自适应（P118 用句间相似度做动态切分）会影响碎片化程度，摘要未说明。

## 6. 与相邻工作的关系

与 P023（MemAgent）是最近的对照：都做分块 + 压缩记忆 + RL 训练策略，差别在于 LycheeMemory 显式引入 Gate 做块级选择并让压缩器参与训练；与 P121（AgeMem 把 LTM/STM 管理并入策略）、P122（用 RL 训练「隐式展开」）共同构成 ACL 2026 上「用 RL 打通压缩与利用」的一组工作；与 P025（ReMemR1 的密集奖励 + 回调）在训练问题上呼应；与 P093（EM-LLM 的事件级记忆 + 双通道检索）相比，本方法的分块由压缩器学习而非由惊奇度发现。定位上属于「压缩 + 选择 + 迭代推理」三件套的端到端版本。

## 7. 可迁移点与开放问题

可迁移：(a) 「选择环节单独训练、压缩与使用环节联合训练」这一分工原则，适用于任何「先筛后用」的系统，可降低端到端训练难度；(b) 用工作记忆的逐轮演化重建分块之间的关联，是把 RAG 碎片化问题转化为可学习策略的有效思路。开放问题：Gate 的监督来源与长尾覆盖；分块方式对碎片化的影响；1.75M 外推在全局聚合任务上的表现；RL 训练成本与稳定性；以及与 P122 的「固定压缩器 + 学习利用」路线在同等预算下的对比。
