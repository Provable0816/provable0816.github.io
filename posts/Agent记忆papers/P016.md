# P016 ThinKV: Thought-Adaptive KV Cache Compression for Efficient Reasoning Models

## 一句话贡献

观察到 LRM 的注意力稀疏度呈三峰分布、可据此把 CoT 划为 Reasoning/Execution/Transition 三类"思维"，并提出思维自适应的混合量化—淘汰框架 ThinKV（按思维类型定精度、按思维段渐进淘汰）＋可复用被淘汰槽位的 Continuous Thinking 内核，在数学/代码任务上以不足 5% 的原始 KV 缓存达到接近无损精度，吞吐最高提升 5.8×。

## 1. 问题与第一性原理动机

长输出推理让 KV 缓存迅速膨胀：GPT-OSS-20B 生成约 32K token、batch 32 时需要 50GB 缓存 + 40GB 权重，超过 A100 的 80GB；由于 decode 阶段是 memory-bound，缓存成为核心瓶颈。已有压缩方法大多针对长输入的 prefill，不适配长输出；少数 decode 期方法（recency 淘汰、统一量化）忽略推理动态。更深层的结构性缺陷是"token 级决策"：逐 token 淘汰/量化看不见 CoT 的语义结构，会误删推理关键 token，也压不出高压缩率；同时非连续淘汰造成显存碎片，需要 gather 式压实——实测顺序 gather 可让 TPOT 慢 37×，并行重叠版又因 HBM 带宽争用拖慢注意力最多约 35%。

## 2. 核心洞察

三条经验观察。① 注意力稀疏度（阈值设行最大值的 1%）沿 decode 步呈三峰分布，对应 R（系统推理）、E（计算/代码）、T（不确定与回溯）；T 最稀疏，E 最不稀疏。② 用反事实重要性（删掉该思维段后答案分布的 KL，50 次 rollout 平均）得到层级 R > E > T；且存在少量高重要 T 段（回溯），删掉会让模型无限循环。③ 每出现一个 T 段，此前所有思维段的影响力都下降——T 是"轨迹切换点"。合起来意味着压缩不该按 token 计数，而应按思维段的角色与生命周期来做。

## 3. 方法机制

① 思维划分：离线用 KDE 在标定集上求 $|T|-1$ 个稀疏度阈值 Θ，选出呈现 |T| 个模态的层子集 $L^*$；在线按 $L^*$ 上的平均稀疏度查表分类，刷新周期 τ=128 步。② TBQ（Think Before You Quantize）：$\rho(R)=2>\rho(E)=1>\rho(T)=0$ → 8/4/2 bit（2-bit 用 ternary、4-bit 用 NVFP4、8-bit 用 FP8），组量化 g=16，key 逐通道、value 逐 token 量化，组满前用全精度 buffer。③ TBE（Think Before You Evict）：保留率表 $R=\{64,32,16,8,4\}$，每遇到一个 T 段就把之前所有思维段退火到下一档；若无 T 段但超预算则淘汰最旧最不重要的段；在 post-RoPE key 上做 k-means，簇心对应的 key 留下。④ Continuous Thinking：扩展 PagedAttention 的 block table，新增思维类型、段起始、segment mask、eviction mask 字段；淘汰只做软标记，新 token 到来时原地覆写槽位，从而取消压实、消除碎片。

## 4. 实验证据

模型 R1-Distill-Llama-8B/70B、R1-Distill-Qwen-14B、GPT-OSS-20B/120B、QwQ-32B、AceReason-14B、MobileLLM-R1-950M；任务 MATH-500、AIME、GSM8K、LiveCodeBench；基线 H2O、RaaS、R-KV、LazyEviction 与 KIVI、PM-KVQ。Table 1：R1-Qwen-14B 的 AIME/LiveCodeBench，16-bit 基线 53.33/47.90，KIVI(2-2) 40.00/34.56，PM-KVQ(3.2-3.2) 43.33/41.97，ThinKV(k=1024, 3.5 bit) 50.00/45.84；QwQ-32B 为 73.33/55.45、60.56/40.75、67.86/46.68、70.28/50.47。Table 2 吞吐（A100）：FullKV 297.5 tok/s、R-KV(seq) 1450.5、ThinKV 8412.2，显存占用分别为 100%、5.48%、2.51%。混合的合理性由 Figure 2 的 Pareto 曲线支撑：单纯量化（a↓）会因生成长度被拉长而侵蚀收益，单纯淘汰（b→0）精度崩，混合可在极高压缩率下留住精度。

## 5. 第一性原理再审视

方法的基础是"思维类型可由注意力稀疏度在线判别"，这是经验假设而非定理：|T|=3 是固定的，论文自己承认某些层出现多于三种稀疏模式或边界模糊，用的是"固定 3 类 + 选最优层子集"的工程折中；阈值由 100 条 s1K 标定 prompt 的 KDE 决定，跨模型/跨领域迁移性未系统检验。TBQ 假设"重要性 → 精度"单调且可用 8/4/2 三档近似；TBE 假设"轨迹切换后旧思维段价值单调衰减"，这与"回溯需要重读旧段"存在张力（论文用少量高重要 T 段间接说明，但没量化冲突频率）。淘汰本身不可逆，k-means 簇心代表整段是又一次有损近似，论文未给误差界。精度上 ThinKV 仍低于 16-bit 基线（AIME 50.00 vs 53.33），"near-lossless" 在高难任务上应谨慎表述。

## 6. 与相邻工作的关系

与 R-KV/RaaS/LazyEviction 的差别是决策粒度从 token 上升到思维段；与 PM-KVQ 同属"渐进降精度"，但精度按语义角色而非时间均匀分配；与 PagedAttention/vLLM 的关系是系统层扩展，可与连续批处理共存。本文最紧的对照是 R-KV 与 PM-KVQ，两者同时被其用作基线与前身。

## 7. 可迁移点与开放问题

可迁移的是"用注意力稀疏度做免训练语义分段"这一廉价探针，可复用到 agent 轨迹切分、多轮对话状态识别；以及"软标记淘汰 + 槽位复用"的显存管理技巧，适用于所有非连续淘汰方法。开放问题：思维类型数与其阈值能否随模型/领域自适应；量化与淘汰的最优配比能否在线求解；在长文档、多轮对话等非推理任务上三峰假设是否仍成立。
