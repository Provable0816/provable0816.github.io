# P155 AccKV: Towards Efficient Audio-Video LLMs Inference via Adaptive-Focusing and Cross-Calibration KV Cache Optimization

- 会议/来源：AAAI 26
- 方向簇：VLM
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/37467

## 贡献

面向音视频大语言模型（AV-LLM）：视频与音频引入了更长的时间维度，使 KV cache 远大于静态图像场景。论文指出一个看似自然的优化策略（**按任务选择性地保留音频或视频的 KV**）并不成立——实验发现 **AV-LLM 在高层对模态的注意力并不严格依赖任务，而是更多地偏向视频模态**。此外论文发现，**直接把音频的时序 KV 与视频的时空 KV 拼接会导致信息混淆与显著性能下降**；而不加区分地统一处理又会导致过度压缩。据此提出 AccKV：以「自适应聚焦」与「跨模态校准」两项机制优化 KV cache。

## 机制要点

论文的两条发现本身就有独立价值。第一，「高层注意力偏向视频」意味着**基于任务的模态选择会误判**——任务可能需要音频信息，但模型的注意力分配并不随之调整，因此按任务裁剪会误删关键模态信息。第二，音视频 KV 的拼接引起信息混淆，说明**两种模态的 KV 表示在统计上不兼容**（时间轴的采样率、语义粒度都不同），直接混在一起会互相干扰。AccKV 的「跨校准」正是针对这一点：在合并前先让两模态的表示可比，这与 P030（MixKV 用重要性 + 多样性联合优化）、P081（MMInference 用置换处理模态边界）面对的是同类「模态异质性」问题。

## 关键结果

论文报告 AccKV 在音视频理解任务上改善了效率与性能的权衡（相对朴素模态选择与统一处理两种极端）。具体基准与数值需回看正文；判断价值的关键是它与 **P030/P081 等同类多模态 KV 压缩方法**的比较，以及是否包含需要真正融合双模态的任务（而非单模态即可回答的问题）。

## 局限与定位

第一，「高层偏向视频」是观察到的现象，其普遍性依赖被测模型与数据；在不同 AV-LLM 上是否一致需要证据，否则据此设计的策略会失准。第二，跨模态校准的机制细节（如何对齐两种表示）决定效果上限，而摘要未给出，需核实它是否只是线性投影或含更实质的对齐训练。第三，评测若以「视频为主、音频为辅」的任务为主，结论可能偏向视频模态；真正考验在于音频信息决定性（如「背景音乐的情绪」「说话人的语气」）的任务。第四，音视频之外的模态（如文本指令与图文混合）是否同样存在表示不兼容，决定了该发现的一般性——P030 在 LVLM 上观察到模态特异的冗余模式，可与此互相印证。定位上属于多模态 KV 压缩中强调**模态异质性**的工作。
