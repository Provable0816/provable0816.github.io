## 一句话贡献

同时给出一个更难的评测与一个更强的基线：BEAM 基准由自动生成的**最长可达 10M token、叙事连贯、主题多样**的对话构成，含 100 段对话与 2,000 个经校验的问题，覆盖矛盾消解、信息演化、指令遵循等记忆能力；LIGHT 框架模仿人类认知，为 LLM 装上长期情景记忆、短期工作记忆与显著事实暂存（scratchpad）三套互补系统，在 BEAM 上相对最强基线平均提升 3.5%–12.69%。

## 1. 问题与第一性原理动机

已有长期记忆基准存在三条结构性缺陷。第一，**构造方式削弱了任务难度**：多数数据集靠拼接不同用户的短会话延长对话，导致话题突变、叙事不连贯，分段之间容易被切分识别，从而把「真正的长程推理」退化成「在若干独立片段里各找一句」。第二，**领域狭窄**：多集中于个人生活场景，不覆盖法律、科研、工程等真实应用。第三，**能力维度单薄**：几乎只测上下文召回，不测矛盾消解、信息随时间演化、指令遵循等更贴近真实使用的记忆能力。这三条合起来意味着，模型在旧基准上的高分并不代表它具备长期记忆，而恰恰是因为基准可以被「切碎后分别检索」绕过。

## 2. 核心洞察

洞察在于：**要测长程记忆，就必须让上下文不可切分**。因此论文用叙事生成器 + 会话规划器（先出全局 plan，再展开为 subplan 与批次）来保证对话自始至终围绕同一批主题演化，而不是拼接独立片段；同时让问题答案依赖跨批次、跨会话的信息，并显式加入需要处理前后矛盾与追踪信息更新的题项。第二个洞察来自认知类比：人类长期记忆不是单一存储，而是情景记忆（发生了什么）、工作记忆（当前在加工什么）与暂存区（把显著事实挑出来单独放）三者协作——既然如此，单一检索管线在结构上就无法覆盖全部需求，应该给 LLM 配三套互补记忆。

## 3. 方法机制

BEAM 的构造：由领域、标题、主题、子主题出发生成会话计划，按批生成长对话（最长 10M token），再由问题生成器针对不同记忆能力产出探测问题，最后经人工/流程校验，得到 100 段对话与 2,000 个已验证问题；统计信息见 Appendix Table 3，能力维度拆解见 Table 2。LIGHT 的构造：长期情景记忆（跨会话事件）、短期工作记忆（当前会话上下文）与 scratchpad（累积显著事实）并行维护，配合按能力分层的评测指标（先按 nugget 打分再求平均，以避免长答案被单一粗粒度指标掩盖）。

## 4. 实验证据

在 BEAM 上，即使拥有 1M token 上下文窗口的 LLM（无论是否叠加检索增强）也会随对话变长而显著退化；LIGHT 则在各种骨干模型上稳定提升，相对最强基线平均提升 3.5%–12.69%（幅度取决于骨干 LLM）。消融验证三套记忆组件各有贡献。论文另用 nugget 级评分对答案做细粒度归因，以便区分「答案整体对但漏要点」与「答案错」。

## 5. 第一性原理再审视

三点保留意见。第一，**生成器与被测对象同源的风险**：BEAM 由 LLM 自动生成对话与问题，其语言分布、难度梯度与「可被哪些方法解出」都受生成模型本身影响；论文通过校验流程控制质量，但未给出与人类撰写长对话的对照实验，因此基准的难度是否有偏、是否系统性偏袒某些检索范式，无法完全排除。第二，「最长 10M token」是上界而非典型值，而主表按对话长度分层报告（Table 1）——阅读时必须区分「在 10M 上仍然有效」与「在 10M 上平均有效」。第三，LIGHT 的三套记忆组件与「按能力分层的指标」是同时引入的，二者对提升的贡献未完全解耦；此外 LIGHT 需要额外的记忆维护计算，论文未给出与上下文长度相关的开销曲线，而这类 agent 的实际瓶颈常在延迟与成本。第四，相对最强基线 3.5%–12.69% 的跨度较大，说明提升幅度高度依赖骨干模型，最弱一档的 3.5% 在基准噪声范围内是否显著需要看置信区间。

## 6. 与相邻工作的关系

与 LoCoMo、LongMemEval、REALTALK 等长期记忆基准相比，BEAM 的差异在**长度（最高 10M）与叙事连贯性**——前者通过拼接获得长度，本工作通过叙事规划获得长度；与 P024 评测使用的 Complex-TR、Test of Time 相比，那些更偏时序阅读理解，BEAM 更偏多会话交互记忆。LIGHT 与 MemGPT 的层级记忆、Mem0 的图式记忆同属「为 LLM 外挂记忆」路线，区别是显式对齐了三类认知记忆并配套分层评测。整体上，这篇工作提供了该方向的「难度标尺 + 强基线」组合。

## 7. 可迁移点与开放问题

可迁移：(a) 「用叙事规划保证长上下文不可切分」是构造长上下文基准的关键技巧，可推广到长文档、长代码库、长交互日志的评测集设计；(b) 「按 nugget 拆分再聚合」的细粒度评分方式，能显著提升对长答案质量的判别力；(c) 三套记忆分工（事件 / 当前 / 显著事实）是一个简洁可实现的工程模板。开放问题：自动生成基准与人类任务之间的难度对齐；三套记忆是否可以统一成一个可学习的结构；在 10M 规模下记忆维护的成本与延迟如何控制；以及基准是否会随被测模型的迭代而饱和，需要怎样维护。
