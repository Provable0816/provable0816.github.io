## 一句话贡献

发现 top 层 KV 缓存的重建存在键值不对称——value 主要来自最底层、key 更多来自中低层；据此提出 FusedKV（top 层缓存为底层与中层缓存的逐维可学习加权融合）与 FusedKV-Lite（直接取中层 key、底层 value），在 332M–4B 模型上把缓存减半的同时取得比全缓存 vanilla 更低的验证 loss 与更高的下游平均分。

## 1. 问题与第一性原理动机

跨层共享（CLA 相邻层共享、YOCO 上半层复用后半层缓存）能省显存，却一贯弱于层内的 GQA/MQA。真正的问题不是"能不能共享"，而是"共享哪一层的什么信息"。若共享关系选错，重建出的缓存会丢失该层特有的表示，性能必然低于不共享但省显存的层内方案。

## 2. 核心洞察

先做密度融合实验：1B、16 层模型，top 8 层用所有底层缓存的标量融合重建，训练 loss 低于 vanilla，说明 top 层缓存可由早期层重建。再看融合权重（Fig. 2）：value 的重建权重集中在第 0–1 层，key 的权重更分散但集中在第 6–7 层。即"value 早、key 晚"——两种缓存的信息来源系统性不同。这一观察若成立，就意味着任何把 K 与 V 同等对待的跨层方案都在浪费预算。

## 3. 方法机制

把层划分为存储层 $L_S$ 与重建层 $L_R$；重建层不存缓存，用 $(K^i,V^i)=F_i(\{(K^j,V^j)\mid j\in\Phi(i)\};\theta_i)$ 现场生成。FusedKV 取 $\Phi(i)=\{1,n\}$：$K^i=a_{i,1}\odot K^1+a_{i,n}\odot K^n$，$V^i=b_{i,1}\odot V^1+b_{i,n}\odot V^n$（$i>n$），权重为可学习向量的 Hadamard 逐维门控——用"底层基础特征 + 中层抽象特征"覆盖两种信息源，代价是融合带来的额外 cache I/O。FusedKV-Lite 直接 $K^i=K^n$、$V^i=V^1$，无融合开销。核心工程点是 RoPE 兼容性：把 attention score 在 2D 子空间展开可见，若权重在同一 2D 对内不等（$w_{2j}\neq w_{2j+1}$），分数会多出依赖 $m+n$ 的绝对位置项；因此必须约束 $w_{2j}=w_{2j+1}$。满足该对称性时，多个 post-RoPE key 的加权融合仍保持纯相对位置依赖，存储层即可原样保留 post-RoPE 缓存，推理时无需重算 RoPE。复杂度见 Table 1；实测 TTFT 在 ≥8K 时约减半，FusedKV 在 memory-bound 下 TPOT 约慢 1.5×，在 compute-bound（GQA，$H_q=128$/$H_{kv}=2$，额外开销仅 $3/256$）下被计算掩盖，FusedKV-Lite 与 vanilla 持平。

## 4. 实验证据

自训练 332M/650M/1.5B 稠密模型（Qwen3 架构，128K 词表、8,192 上下文、16 头），FineWeb-Edu 上分别 200B/200B/400B token；4B 模型 800B token。基线 Vanilla、CLA、YOCO、GQA。1.5B：FusedKV 验证 loss 2.221 / WikiText PPL 13.33 / 平均下游 55.82；Vanilla 2.241/13.67/54.55；GQA 2.245/13.74/54.58；FusedKV-Lite 2.225/13.45/55.30——缓存减半但优于全缓存。4B：FusedKV 1.978/8.94/60.01，Vanilla 2.002/9.18/59.07。缩放实验（332M→4B）显示 FusedKV 的 loss 随规模下降更快。消融：反序分配（$K^i=K^1$、$V^i=V^8$）显著变差，直接验证不对称方向为真；把固定权重换成可学习通道权重（FusedKV-Lite-Learnable）在 WikiText/LAMBADA/HellaSwag 上继续提升，说明逐维重加权有真实增益。

## 5. 第一性原理再审视

该方法的本质是"用两层缓存作为低秩先验重建被省略层"，前提是"被省略层的 KV 信息被这两层充分覆盖"。这一前提在 16 层、8K 上下文的模型上被验证，但缺乏理论刻画：论文没有给出重建误差上界，也没有给出"哪些层可安全省略"的判据，分界层 n 的选择更像实验约定。风险在于更深的模型或更强的层间专业化（如中段检索头）可能让两层不够；需要精确长程检索的场景（长上下文结果放在附录 A.7）是否受损需单独检验。所有模型均为作者从零训练、规模 ≤4B，"对已训练大模型微调改造是否同样有效"未验证；小模型上 MMLU、ARC-C 接近随机水平，使"平均分更高"的说服力受限。

## 6. 与相邻工作的关系

与 CLA（相邻层共享、K 与 V 同源）、YOCO（top 半层全部复用最后一层）共同构成跨层共享谱系，本文的贡献是"选哪个源层"以及"键值分开选"。与层内 GQA/MQA、MLA 正交，可与它们叠加（附录给出与 MLA/GQA/MoE/SWA 的组合结果）。与 KV 淘汰/量化相比属于训练期架构改造，不依赖推理期打分。

## 7. 可迁移点与开放问题

可迁移的是"键值不对称"这一诊断方法：用稠密融合权重可视化来定位表示的信息来源，可直接用于分析其他跨层、跨模态共享结构。开放问题：分界层 n 与源层集合能否自动搜索；能否在预训练后增量适配而非从头训练；与稀疏注意力/检索式注意力的组合是否会抵消长上下文收益。
