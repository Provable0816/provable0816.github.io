# P221 Value-Guided KV Compression for LLMs via Approximated CUR Decomposition

- 会议/来源：NeurIPS 2025（主会）
- 方向簇：KV
- 链接：https://openreview.net/forum?id=721b0b930cae88656b0f71a8f6097ee4
- 本地全文：cache/txt/P221.txt

## 一句话贡献

指出主流 KV 淘汰方法的判据错位——它们按 **query-key 注意力分数**排序并淘汰，而真正决定输出的还有 **value 向量**；据此提出以 value 为中心、用 **CUR 矩阵分解**的 leverage score 选择保留 token 的 CurDKV，并证明「注意力分数近似并不保证输出保真，而 CUR 选择最小化端到端注意力重构损失」。

## 1. 问题与第一性原理动机

注意力输出是 $\mathrm{softmax}(QK^\top)V$——一个复合运算。只优化 $QK^\top$ 的近似，不必然保证复合结果 $\mathrm{softmax}(QK^\top)V$ 被保留，因为 $V$ 的加权组合会重新混合误差。Figure 1 直接展示这一点：平均注意力值高的 key 未必在淘汰后带来更好的 $\mathrm{softmax}(QK^\top)V$ 重构。这就把问题从「谁被看得多」变成了「谁对输出矩阵的子空间贡献大」——后者是一个**数值线性代数**的问题，而不是启发式打分问题。CUR 分解（用少量实际列/行张成矩阵的主导子空间）恰好是为「选出最具代表性的行列」设计的工具，因此与该问题的结构天然匹配。

## 2. 核心洞察

**选择保留哪些 token 等价于选择一个子矩阵以逼近全矩阵**，而 CUR 的 leverage score 正是「该行/列对主导子空间的贡献」的度量。这一视角带来两重好处：其一，理论上有明确的最优性目标（最小化端到端注意力重构损失），不再依赖「注意力即重要性」这一未经检验的假设；其二，它显式地把 value 纳入判据，弥补了 query-centric 方法的系统偏差（Figure 2 给出不同压缩策略下 $QK^\top$ 与 $\mathrm{softmax}(QK^\top)V$ 的保持程度，CurDKV 的 eviction loss 最低）。

## 3. 方法机制

对每层的 $\mathrm{softmax}(QK^\top)V$ 计算 CUR 分解的 leverage score，据此选择要保留的 key/value 子集；为降低计算成本，用**随机投影**近似 leverage score；另提供自适应变体 AdaCurDKV。方法保持与 FlashAttention 与 GQA 的兼容性。代价与边界：选择发生在 **prefill 阶段**且是静态的——论文的 Limitations 明确承认这可能无法响应生成过程中动态浮现的信息需求；随机投影近似会引入打分误差；每层的 CUR 计算带来额外开销（需要与节省的访存权衡）。

## 4. 实验证据

模型为 LLaMA-3.1-8B-Instruct 与 Mistral-7B-Instruct；基准为 LongBench 与 RULER。Table 1 给出全 KV（0% 压缩）基线，Table 2 给出 30% 与 90% 两档压缩率下与 SnapKV、ChunkKV 等基线的对照（论文注明「compression ratio 是缓存预算的补集，如预算 30% 对应压缩率 70%」，并给出 Friedman 统计量 45.2/35.7 以支撑排序显著性）。核心结论：在激进压缩预算下准确率最高高出 **9.6%**，同时在高压缩率下把生成延迟降低最多 **40%**，并保持与 FlashAttention/GQA 的兼容。

**证据缺口**：(a) 理论保证是**重构损失**层面的（保留子矩阵对全矩阵的逼近），而下游关心的是**预测行为**的保持；两者之间的差距（重构好但答案错）需要额外的证据桥接，论文未提供任务级的误差分析；(b) 静态 prefill 选择与 P178/P214 所揭示的「注意力随时间漂移」直接冲突，论文在 Limitations 中承认但未量化损失；(c) 计算开销的核算：CUR + 随机投影的额外算力是否在小模型/短序列上抵消收益，需要按规模分档的净收益曲线；(d) 评测集中于 LLaMA/Mistral 两个家族，跨架构（尤其 MoE 与 GQA 极端分组）验证不足。

## 5. 第一性原理再审视

CurDKV 的方法论价值大于其具体指标：它把「压缩的判据」从**启发式代理**（注意力分数）推进到**可证明的目标函数**（输出重构损失）。这是本方向近年最重要的范式转变之一——与 P177（Judge Q 学更好的打分器）不同，CurDKV 改变的是**优化对象**本身：不再问「如何更好地预测注意力」，而问「如何直接最小化我们真正关心的重构误差」。由此可推出一条判据：压缩的每一次进步，都可归因于「代理指标 → 目标指标」的又一次对齐；这也解释了为什么 P199（MatryoshkaKV 用蒸馏而非 PCA 重构）、P003（TRIM-KV 用任务信号而非注意力统计）能取得超出同类方法的收益。第二，必须指出 CUR 的重构目标是**中间张量**而仍非**任务输出**：$\mathrm{softmax}(QK^\top)V$ 的重构误差是任务误差的上界而非等价物，因此「最小化重构损失」只是必要条件；真正的终点应是以任务损失（或对任务敏感度加权的范数）作为选择目标，这一方向与 P199 的蒸馏目标汇流，是下一步的自然演进。第三，value-centric 这一视角还有一个未被充分挖掘的含义：既然 value 直接决定输出，那么**value 的压缩方式**（而非仅其被选择的概率）也值得单独设计——例如对 value 做低秩或量化而与 key 的选择解耦，这与当前多数方法「KV 同策略处理」的做法不同。

## 6. 与相邻工作的关系

与 H2O、SnapKV、ChunkKV 等注意力启发式淘汰方法直接对立（并在实验中全面对比）。与 P199（MatryoshkaKV）在「用更正确的目标替代重构/启发式」这一点上同源：P199 用蒸馏对齐注意力输出、CurDKV 用 CUR 逼近注意力输出，两者都在特征维/选择维上接近「输出保真」这一目标。与 P178（KeepKV 的注意力守恒校正）互补：KeepKV 修正合并后的注意力归一化，CurDKV 优化选择本身的保真度。与 P183（SPARK，通道维可恢复剪枝）正交：CurDKV 在 token 维选择、SPARK 在通道维剪枝。与 P205（KVComm 在层维选择）共同说明「选择」可以发生在 token/通道/层/特征四个轴上。

## 7. 可迁移点与开放问题

可迁移：(a) 「**压缩判据应最大化下游算子的保真度，而不是任何中间统计量**」这一原则，应成为评估与设计记忆压缩方法的第一准则，可迁移到 agent 记忆筛选、多模态 token 压缩、检索摘要；(b) 用 leverage score（或等价的敏感度度量）替代启发式打分，是把压缩问题数值线性代数化的可复用工具。开放问题：把重构目标升级为任务损失（或其对选择的敏感度）；把静态 prefill 选择扩展为随生成演化的动态选择；value 与 key 的分离压缩策略；CUR/随机投影的额外开销与收益的规模依赖；以及在 MoE、极端 GQA 等架构上的泛化。
