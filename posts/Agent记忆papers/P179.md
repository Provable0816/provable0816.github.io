# P179 KVmix: Gradient-Based Layer Importance-Aware Mixed-Precision Quantization for KV Cache

- 会议/来源：AAAI 2026（主会）
- 方向簇：KV
- 链接：https://ojs.aaai.org/index.php/AAAI/article/view/40422
- 本地全文：cache/txt/P179.txt

## 贡献

用**梯度**而非权重幅值来度量各层 K/V 投影矩阵对损失的敏感度（KVmix profiler），据此为每层分配不同比特位宽；再叠加一个长上下文动态策略：近期关键 token（RPC）保精度、旧 token 激进压缩。在 Llama/Mistral 上以 Key 2.19 bit / Value 2.38 bit 的配置实现约 4.9× 显存压缩与 5.3× 吞吐提升，同时保持接近无损。

## 机制要点

动机来自一个观察（Figure 2）：各层 K/V 投影矩阵的 L2 范数与数值范围差异明显，因此靠权重幅值无法判断层的重要性；由链式法则可得 $\partial L/\partial W_k^i$ 之类的梯度敏感度，用它给每层打分并映射为位宽预算。论文给出配置可视化（Figure 6：不同模型的两档配置），并说明静态「一刀切」位宽在低比特下必然在少数敏感层崩掉。动态部分（Figure 4）：prefill 与 decoding 两阶段中按 RPC 比例动态调整全精度 KV 的数量，避免长上下文下全精度项无限膨胀；同时提供低比特量化与 CUDA kernel 以控制开销。

## 关键结果

模型为 Llama-2-7B-hf、Llama-3-8B-Instruct、Llama-3.1-8B、Mistral-7B-Instruct-v0.3、Falcon-7B；评测分三路——LongBench（长上下文，受显存限制序列上限 4096）、Wikitext-2 困惑度、GSM8K 数学推理。Table 1 给出四模型在 LongBench 上多档量化配置的对照，包含 KVmix-k2.19v2.38、全层 2-bit、以及「随机选 20% 层做 3-bit」的对照——最后一项是关键的机制验证：随机分配位宽劣于梯度分配，说明增益确实来自重要性排序而非配置本身。Table 2 给出逐数据集细节（如 FP16 平均值 33.839 作为参照）。Figure 1、Figure 5 展示不同配置下的精度变化。

## 局限与定位

第一，梯度敏感度是在**校准数据**上估计的，方法继承了「校准集代表下游任务」这一脆弱假设；在域外任务上，层重要性排序可能反转，而论文未报告跨域一致性。第二，评测序列长度被限制在 4096（受硬件限制），而混合精度方案的收益本应在极长上下文更明显，这一限制削弱了对「长上下文最优」主张的支撑。第三，RPC 动态策略引入了「近期更重要」的先验，这与 P177/P178 观察到的「注意力时变」同源，但论文未讨论被压缩掉的旧 token 在后文重新变重要时的补救手段。定位上，它属于量化路线中「按重要性分配位宽」的一支，与 P174（QJL，按估计器设计换位宽）、P171（CSR，按稀疏表示换位宽）构成三种不同的降位宽机理，且与 eviction/合并方法正交可叠加。
