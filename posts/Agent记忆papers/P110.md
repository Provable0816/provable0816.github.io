# P110 Efficient Large Multi-modal Models via Visual Context Compression

- 会议/来源：NeurIPS 2024
- 方向簇：VLM
- 链接：/paper_files/paper/2024/hash/871ed095b734818cfba48db6aeb25a62-Abstract-Conference.html

## 贡献

研究多模态 LLM 中**视觉 token 的冗余**与高效训练：初步实验显示，在测试阶段用简单的平均池化去掉最多 70% 的视觉 token，仅使 GQA 上的视觉问答准确率下降约 3%，说明视觉上下文存在大量冗余。据此提出 Visual Context Compressor 以减少视觉 token 数量，并设计 LLaVolta——一种轻量的分阶段训练方案，在训练过程中**按阶段对视觉 token 做由重到轻的压缩**，从而在测试阶段无需压缩也能不损失信息；在图像语言与视频语言理解上同时提升性能并显著降低训练成本与推理开销。

## 机制要点

两处设计值得注意。第一，用「直接池化掉 70% 仍只掉 3%」这样一个**极简的对照实验**来量化冗余，比复杂的归因分析更有说服力，也直接确定了压缩的可行空间。第二，LLaVolta 的训练策略是一个有意思的思路：训练时让模型适应「重度压缩的视觉输入」、测试时给它「未压缩（或轻压缩）的输入」，等价于把压缩当作**训练时的正则/课程**而非推理时的近似——因此推理质量不会因压缩而受损，反而因为模型学会了在信息稀缺条件下提取要义而受益。这与常见的「训练全量、推理压缩」范式正好相反。

## 关键结果

移除最多 70% 视觉 token（平均池化）时 GQA 仅下降约 3%；Visual Context Compressor 与 LLaVolta 在图像与视频理解任务上提升性能，同时显著降低训练成本并改善推理效率。

## 局限与定位

第一，「训练重压缩、测试不压缩」意味着**推理阶段并没有省下视觉 token**，节省主要发生在训练侧与（相对基线模型的）推理效率上；若部署目标是降低单次推理成本，需要确认该方案在推理时是否也启用压缩以及压缩率多少。第二，冗余结论基于 GQA 的准确率，而 GQA 以对象级关系问答为主，对细粒度视觉细节（小字、精确计数、图表数值）的要求不高；在这类任务上 70% 压缩很可能带来远超 3% 的损失，这一边界未被检验。第三，平均池化是不可学习的压缩算子，能取得如此低损失本身说明视觉编码器输出高度冗余；但冗余是否均匀分布在所有输入类型上（自然图像 vs 文档图像 vs 视频）值得细分。第四，分阶段压缩的调度（何时由重到轻）是新的超参，其敏感性未在摘要中体现。定位上，LLaVolta 与 P028（MARC 用查询相关检索 + RL 蒸馏）、P029（VideoChat-Flash 的层级压缩）同属视觉 token 压缩，但思路独特：把压缩放在**训练课程**里而非推理路径上。
