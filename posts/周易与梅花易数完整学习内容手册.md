## 开篇：这份文档怎么用

梅花易数看着招式很多，其实只有三层结构：

| 层次 | 内容 | 作用 |
|---|---|---|
| **底层：象数语言** | 阴阳、五行、八卦、干支、卦气、爻位 | 没有它，读什么都是猜 |
| **中层：取象与推演** | 起卦法、本互变、体用生克、万物类占、外应 | 断卦的主体框架 |
| **上层：断与验** | 分类占、应期、断语组织、事后核验 | 决定你最后准不准 |

学的时候**自下往上走**，断的时候**自上往下用**。

本文的第二部分「转换原理」是整份文档的核心——理解了它，你能自己生成类象，不再依赖背表。第三部分用十个方向完整演示这套原理如何落到实际断语上。

## 第一部分　象数底座：必须先装进脑子的知识

### 1.1 阴阳与爻

- 阳爻 ⚊（称「九」）、阴爻 ⚋（称「六」）
- 三爻成**经卦**（八卦），六爻成**别卦**（六十四卦）
- 爻位自下往上数：初、二、三、四、五、上
- 命名方式：爻性 + 爻位，如「初九」「六二」「九五」

### 1.2 五行

- **相生**：木 → 火 → 土 → 金 → 水 → 木
- **相克**：木 → 土 → 水 → 火 → 金 → 木
- **八宫五行**：乾兑金、坤艮土、震巽木、坎水、离火

### 1.3 八卦（必须背到条件反射）

**卦形歌**（最经典的记忆口诀）：

> 乾三连，坤六断，震仰盂，艮覆碗，离中虚，坎中满，兑上缺，巽下断。

**先天卦数**（起卦用）：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8

**后天方位**（断方位、找物用）：坎北、艮东北、震东、巽东南、离南、坤西南、兑西、乾西北

| 卦 | 卦形 | 卦德 | 自然 | 人伦 | 身体 | 动物 | 五行 |
|---|---|---|---|---|---|---|---|
| 乾 ☰ | 三连 | 健 | 天 | 父 | 首、骨 | 马 | 金 |
| 兑 ☱ | 上缺 | 悦 | 泽 | 少女 | 口、舌 | 羊 | 金 |
| 离 ☲ | 中虚 | 丽 | 火 | 中女 | 目 | 雉 | 火 |
| 震 ☳ | 仰盂 | 动 | 雷 | 长男 | 足 | 龙 | 木 |
| 巽 ☴ | 下断 | 入 | 风 | 长女 | 股 | 鸡 | 木 |
| 坎 ☵ | 中满 | 陷 | 水 | 中男 | 耳 | 豕 | 水 |
| 艮 ☶ | 覆碗 | 止 | 山 | 少男 | 手、指 | 狗 | 土 |
| 坤 ☷ | 六断 | 顺 | 地 | 母 | 腹 | 牛 | 土 |

### 1.4 天干地支

- **十天干**：甲乙东方木、丙丁南方火、戊己中央土、庚辛西方金、壬癸北方水
- **十二地支**：子水鼠、丑土牛、寅木虎、卯木兔、辰土龙、巳火蛇、午火马、未土羊、申金猴、酉金鸡、戌土犬、亥水猪
- **数序**：甲1…癸10；子1…亥12（起卦时直接当数字用）

### 1.5 卦气旺衰（断卦的总开关）

- **旺**：震巽木旺于春，离火旺于夏，乾兑金旺于秋，坎水旺于冬，坤艮土旺于辰戌丑未月
- **衰**：春坤艮，夏乾兑，秋震巽，冬离，辰戌丑未坎

**用法**：体卦当令则吉者更吉、凶者减轻；体卦休囚又被克且无生扶，凶险加重。旺衰**只改程度，不改方向**。

### 1.6 爻位术语（读注本的地基）

| 术语 | 含义 |
|---|---|
| **得位（得正）** | 阳爻居初、三、五；阴爻居二、四、上 |
| **得中** | 居二爻、五爻（上下卦之中），多吉 |
| **承** | 下爻承托上爻 |
| **乘** | 上爻凌驾下爻，多不吉 |
| **比** | 相邻两爻 |
| **应** | 初与四、二与五、三与上，阴阳相应为「有应」 |

## 第二部分　转换原理：象是怎么变成断语的

梅花易数所有断语，都是通过下面**六条通道**把卦象翻译成人事。每次断卦，你都在同时用其中几条。这是整份文档最重要的一节。

### 通道一：卦德直取（最根本）

《说卦传》给八卦定了八种性质，叫**卦德**：乾健、坤顺、震动、巽入、坎陷、离丽、艮止、兑悦。

看到任何一个卦，第一反应应该是它的**性质**，不是它代表什么东西。

| 卦德 | 推导出的判断 |
|---|---|
| 乾＝健 | 刚健、主动、上行、速、圆满、贵重 |
| 坤＝顺 | 柔顺、被动、承载、缓、包容、众 |
| 震＝动 | 起动、突发、惊、躁、进、有声 |
| 巽＝入 | 渗透、进退不定、潜移默化、营商 |
| 坎＝陷 | 险、隐伏、阻滞、暗、下沉 |
| 离＝丽（附着） | 光明、显现、文书、虚、外实内空 |
| 艮＝止 | 停止、守住、界限、门阙、终 |
| 兑＝悦 | 和悦、口舌、缺损、毁折 |

**为什么「离＝文书」？** 因为离＝丽＝附着，文字是附着在载体上的；又离为火为明，文书是「显明」之物。这就是从卦德一路推下来的。

### 通道二：卦形取象（最容易被忽略，却最有用）

八卦的**线条形状**本身就是一张象形图。这是《说卦传》之外的第二条取象通道，也是类象能无限扩展的原因。

| 卦 | 卦形 | 形状特征 | 推出的物象 |
|---|---|---|---|
| 乾 ☰ | 三连 | 三阳不断、圆满无缺 | 圆物、完整之物、金玉、宝珠、天 |
| 坤 ☷ | 六断 | 三阴全虚、分散 | 方物、布帛、瓦器、众、地、柔软物 |
| 震 ☳ | 仰盂 | 下实上虚，如仰口之盂 | 竹木（中空有节）、仰承之物、乐器 |
| 艮 ☶ | 覆碗 | 上实下虚，如倒扣之碗 | 覆盖物、门阙、果蓏（外硬内软）、山 |
| 离 ☲ | 中虚 | 外实内空 | 有壳之物（龟蟹蚌螺）、网、目、炉、槁木 |
| 坎 ☵ | 中满 | 外虚内实 | 带核之物（桃杏李）、水、弓轮、心、隐伏 |
| 兑 ☱ | 上缺 | 上爻开口 | 带口之器（瓶罐杯）、毁折之物、缺口、泽 |
| 巽 ☴ | 下断 | 下爻虚、有缝隙 | 可入之物（绳、扇、帆）、长物、直物、风 |

**关键洞察**：坎为什么是「带核之物」？因为坎中满——外面软、中间硬，就是果核。兑为什么是「毁折之物」？因为上缺——顶部有缺口。

**这不是死记，是从卦形推出来的。** 理解了这条，你能自己生成类象，不用背完一千条。

### 通道三：五行属性推（关系判断用）

八宫五行：乾兑金、震巽木、坎水、离火、坤艮土。

这条通道不直接告诉你「是什么」，而是告诉你**两个卦之间是什么关系**——生、克、比和。整个体用断法都建立在这一条上。

五行配八卦的依据是后天方位配季节：震巽在东属春为木，离在南属夏为火，兑乾在西属秋为金，坎在北属冬为水，坤艮土居中央四隅寄旺四季末。

### 通道四：方位与时序（时空定位用）

- **后天方位**：坎北、艮东北、震东、巽东南、离南、坤西南、兑西、乾西北
- **时序**：乾秋（戌亥）、坤辰戌丑未月、震春（卯）、巽春夏之交、坎冬（子）、离夏（午）、艮冬春之交、兑秋（酉）

找东西、断方位、定应期全靠它。**方位只用于时空定位，吉凶仍看生克。**

### 通道五：爻位与卦名卦义（给过程定性）

梅花易数与六爻最大的差别是：**梅花直接读卦名**。

| 卦名 | 卦义 | 断卦时的含义 |
|---|---|---|
| 需 | 等待 | 事有等待，不可躁进 |
| 讼 | 争讼 | 有是非、口舌、争执 |
| 蹇 | 蹇难 | 过程有阻滞 |
| 解 | 缓解 | 困难会解开 |
| 剥 | 剥落 | 削减、损失、层层去掉 |
| 复 | 复返 | 去而复返、反复 |
| 贲 | 文饰 | 表面之美，非实质 |
| 颐 | 养 | 需要培养、守正、等待 |
| 遁 | 退隐 | 退、隐藏、延迟 |
| 夬 | 决 | 决断、决裂，需快刀斩乱麻 |
| 姤 | 遇 | 不期而遇 |
| 归妹 | 归于 | 有归宿，但宜守正 |
| 井 | 井养 | 安稳、通达、不动、原处 |
| 睽 | 乖离 | 意见分歧、不一致 |
| 升 | 上升 | 往上走、渐进 |
| 大畜 | 畜养 | 积蓄、暂止、待发 |
| 咸 | 感 | 相感、感应 |
| 革 | 变革 | 去故、改变 |
| 未济 | 未成 | 事了而未了，需再一轮 |

**爻位**：初爻为始、为民、为足；二五为中、为得位之要；三爻多凶、四爻多惧；上爻为终、为退位。

### 通道六：旺衰调幅（调音量，不换频道）

| 情形 | 效果 |
|---|---|
| 体卦当令（旺） | 吉者更吉，凶者可减，抗克能力强 |
| 体卦休囚 | 吉者打折，凶者加重 |
| 体衰又被克且无生扶 | 凶险显著，需特别谨慎 |
| 体旺而被克 | 有力承受，凶中有救 |

### 断卦的六步标准动作

每一步都对应上面某条通道，走完才算断完：

| 步骤 | 动作 | 对应通道 |
|---|---|---|
| ① 排卦 | 本卦、互卦、变卦 | 除法与爻变 |
| ② 定体用 | 动爻所在为用，另一为体 | 纯规则 |
| ③ 判生克 | 五行关系定吉凶方向 | 通道三 |
| ④ 调旺衰 | 卦气修正程度 | 通道六 |
| ⑤ 填类象 | 卦德、卦形、方位、时序、卦名填具体内容 | 通道一、二、四、五 |
| ⑥ 定应期 | 卦数、旺衰、变卦取时 | 通道四 |

**断语公式**：

> 体用生克（吉凶方向）＋ 旺衰（程度）＋ 类象（何人何事何物何方）＋ 互卦（中间过程）＋ 变卦（最终走向）＋ 应期（何时）

### 起卦与推演的两条基础规则

**两条除法**（一切起卦的基础）：

- **卦以八除**：数 ÷ 8，余数定卦（1乾 2兑 3离 4震 5巽 6坎 7艮）；**能整除取 8（坤）**
- **爻以六除**：总数 ÷ 6，余数定动爻（从下往上数）；**能整除取 6（上爻动）**

> ⚠️ 这是最常见的起卦错误：8 ÷ 8 余 0，必须取 8（坤），不是取 0。

**五种起卦法**：

| 方法 | 上卦 | 下卦 | 动爻 |
|---|---|---|---|
| 年月日时 | 年+月+日 ÷8 | 年+月+日+时 ÷8 | 年月日时总数 ÷6 |
| 数字 | 第一数 ÷8 | 第二数 ÷8 | 两数之和 ÷6 |
| 物数 | 可数之物件数 ÷8 | 时辰数 ÷8 | 物数+时数 ÷6 |
| 声音 | 声音次数 ÷8 | 时辰数 ÷8 | 相加 ÷6 |
| 字数 | 字的上半笔画 ÷8 | 下半笔画 ÷8 | 总笔画 ÷6 |

一字至十一字占、丈尺占、尺寸占、为人占、自己占同理，核心都是「取两个数 + 取动爻」。

**三卦的含义**：

- **本卦**：起卦所得，事情的初始状态
- **互卦**：去掉初爻和上爻，中间四爻分两卦——二三四爻为下互，三四五爻为上互；**乾坤无互，互其变卦**。代表中间过程与隐情
- **变卦**：动爻阴阳反转后所得。代表最终结果

**体用**（断卦的总纲）：

- **动爻所在的经卦为「用」**，另一经卦为「体」
- 体 = 问卦者、主体、内因；用 = 所问之事、对方、外部环境
- 无动爻时，以本卦为体、变卦为用

**体用生克五格**（背熟）：

| 关系 | 含义 | 吉凶 |
|---|---|---|
| 用生体 | 外力助我 | 大吉，得人相助 |
| 体用比和 | 五行相同 | 吉，顺遂平稳 |
| 体克用 | 我克事 | 小吉，能成但需努力 |
| 体生用 | 我生事 | 小凶，耗神耗财 |
| 用克体 | 事克我 | 大凶，阻力大、难成 |

**三要灵应与十应（外应）**：

- 三要：耳（听）、目（观）、心（感）
- 十应：天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色、写字之应
- **定位**：外应只能**微调**判断，不能反客为主替代体用生克

## 第三部分　十个方向的完整推演示例

每个示例都完整走一遍：**起卦算式 → 三卦 → 体用 → 生克 → 旺衰 → 类象溯源 → 互变作用 → 应期 → 完整断语**。

---

### 示例一　天时占（问明日天气）

**设定**：起卦取两数 36、28，占于秋月（金旺、木囚）。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 36 ÷ 8 = 4 余 **4** | 震 ☳ |
| 下卦 | 28 ÷ 8 = 3 余 **4** | 震 ☳ |
| 动爻 | (36+28)=64，64 ÷ 6 = 10 余 **4** | 四爻动 |

**三卦**

- **本卦：震为雷**（上震下震）
- **互卦**：二三四爻＝六二阴、六三阴、九四阳 → 阴阴阳＝**艮**；三四五爻＝六三阴、九四阳、六五阴 → 阴阳阳＝**坎** → 上坎下艮＝**水山蹇**
- **变卦**：四爻是上卦震的下爻，阳变阴 → 上卦由震变坤 → 上坤下震＝**地雷复**

**体用与生克**：四爻动在上卦 → 上卦震为用，下卦震为体。体震木，用震木 → **比和**。

**类象溯源**

| 取象 | 来源通道 | 依据 |
|---|---|---|
| 震＝雷 | 卦德＋自然象 | 震为雷，《说卦传》 |
| 坎＝雨、云 | 自然象 | 坎为水，天时为雨、雪、月 |
| 坤＝阴云、雾气 | 自然象 | 坤为地气上升，天时为阴云、雾 |
| 艮＝山云、止 | 卦德 | 艮止，云聚不动 |

**推理链路**

1. 比和 → 天气平稳，无剧烈灾变
2. 本卦震＝雷 → **有雷**
3. 互卦见坎＝水，且坎在上互（代表过程的中段偏后）→ **中途有雨**
4. 坤为体之变卦方向，坤为阴云 → **转阴**
5. 时值秋月，金旺木囚，体震木囚 → 雷势不猛，雷声不大

**应期**：天时占一般不定应期，看变卦复（反复）可知天气会反复。

**完整断语**

> 明日有雷雨，但比和主平稳、又值秋月木囚，雷不烈。天气走势是先雷、中途落雨、后转阴云。震为动，雨来得快去得也快；变卦地雷复，复有「反复」之象，可能一阵晴一阵雨，反复两三轮。

**转换要点**：天时占的关键在**本卦定主体天气、互卦定中间变化、变卦定收尾**，几乎不看体用吉凶——因为天气没有吉凶。

### 示例二　求财占（问这笔生意能不能赚）

| 乾＝官贵、官方 | 人伦象 | 乾为君、为官 |
| 乾＝西北、秋 | 方位与时序 | 后天八卦方位 |

1. 用克体 → **求财不利，破耗之象**
2. 体巽为商贾、为求财之人 → 主体确实是经商求利
3. 用乾为金、为官方 → **压力来自「金」或「官方」**：可能是硬性成本、官方收费、强势甲方、或一位「贵人」反成压力
4. 互卦乾为天，纯阳刚健 → 中间过程**阻力持续、没有缓冲**
5. 变卦巽为风，上下皆巽 → 终局比和（巽与体同气），**不至于大损**，但也就是「持平」
6. 巽为进退不果 → 你会犹豫要不要继续投入

**完整断语**

**转换要点**：求财占里，**体克用为财、用生体为财，用克体为破财**。同时要看「财从哪来、压从哪来」——答案就在用卦的类象里（此例乾＝官方/金玉/贵人）。

### 示例三　失物占（找东西在哪）★ 方位推导重点

**设定**：取数 8、15，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 8 ÷ 8 = 1 余 **0** → **整除取 8** | 坤 ☷ |
| 下卦 | 15 ÷ 8 = 1 余 **7** | 艮 ☶ |
| 动爻 | (8+15)=23，23 ÷ 6 = 3 余 **5** | 五爻动 |

> ⚠️ **易错点**：8 整除时余数为 0，必须取 **8（坤）**，不是取 0。

**三卦**

- **本卦：山地剥**（上坤下艮）
- **互卦**：剥六爻为初六至六五皆阴、上九阳。二三四皆阴＝**坤**，三四五皆阴＝**坤** → **坤为地**
- **变卦**：五爻在上卦坤的中爻，阴变阳 → 上卦变坎 → 上坎下艮＝**水山蹇**

**体用与生克**：五爻动在上卦 → 上卦坤为用，下卦艮为体。体艮土，用坤土 → **比和**。

**失物占的转换原理**：**比和＝东西没被转移走，还在原处附近。** 这是失物占的第一判断，先定「丢没丢远」，再谈「在哪」。

**类象溯源 → 方位推导**

| 取象 | 来源 | 推出位置 |
|---|---|---|
| 艮＝门阙、门 | 卦形（覆碗，如门楣） | 门口、门后、门槛附近 |
| 艮＝止 | 卦德 | 卡住不动、被挡住 |
| 艮＝东北 | 后天方位 | 偏东北方位 |
| 艮＝手、指 | 身体象 | 手够得到的地方 |
| 艮＝果蓏、土石 | 卦形（上实下虚） | 与器物、土、食物放在一起 |
| 坤＝方物、布帛、瓦器 | 卦形（六断，分散柔软） | 方形容器、布包、陶瓷器 |
| 坤＝腹 | 身体象 | 中空可容之物 |
| 坤＝西南、矮处、地 | 方位＋自然象 | 低处、地面、西南角 |
| 坎＝隐伏、沟渎、暗 | 卦德（陷） | 被盖住、压住、看不见 |

**推理链路**

1. 比和 → **东西没丢，就在原处附近**
2. 体卦艮＝门阙 → 就在**门附近**：门口、门后、玄关、柜门后
3. 艮＝止 → 它**卡住了**，不是平放，是被卡在缝隙或两物之间
4. 用卦坤＝方物、瓦器、腹 → 在一个**方形容器/布包/陶瓷器皿**中或旁边
5. 坤为地、为低 → **位置偏下**（地面层、柜子下层、桌底）
6. 互卦坤为地 → 中途无变化，没被人动过
7. 变卦坎＝隐伏 → 最终确认：**被遮挡着**，上面盖了东西，所以找不到
8. 方位：艮东北（体，主物之所在）＋坤西南（用，主环境）→ 优先搜**房间的东北角低处**，其次是西南

**完整断语**

> 东西没丢。体用比和，互卦也为坤，说明没被人移动过，就在原地附近。体卦艮为门阙、为止，重点搜门口、门后、玄关柜——它是「卡」进去的，不是平放的。用卦坤为方物、为腹、为低处，多半掉进了方形容器里或柜子下层。变卦坎为陷、为隐伏，说明被东西盖住或压住了，所以你翻了两遍都没看见。方位先搜东北角的低处，再看西南。

**转换要点**：失物占的公式——**体用比和＝未失；体克用＝可寻回；用克体＝难寻；变卦定最终找得到否**。方位从体卦（物的位置）和用卦（环境）的方位象里取，**体卦方位优先**。

### 示例四　出行占（问此行是否顺利）

**设定**：取数 22、9，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 22 ÷ 8 = 2 余 **6** | 坎 ☵ |
| 下卦 | 9 ÷ 8 = 1 余 **1** | 乾 ☰ |
| 动爻 | (22+9)=31，31 ÷ 6 = 5 余 **1** | 初爻动 |

**三卦**

- **本卦：水天需**（上坎下乾）
- **互卦**：需为初九阳、九二阳、九三阳、六四阴、九五阳、上六阴。二三四＝阳阳阴＝**兑**；三四五＝阳阴阳＝**离** → 上离下兑＝**火泽睽**
- **变卦**：初爻在下卦乾的下爻，阳变阴 → 下卦变巽 → 上坎下巽＝**水风井**

**体用与生克**：初爻动在下卦 → 下卦乾为用，上卦坎为体。体坎水，用乾金 → **金生水，用生体，大吉**。

**旺衰**：秋月金旺，用卦乾金当令生体 → **助力更强**。

**卦名卦义入断（本例核心）**

| 卦 | 卦义 | 在出行占中的含义 |
|---|---|---|
| **需** | 等待、须也 | 出行有等待、会延期或需候时 |
| **睽** | 乖离、违和 | 途中有小的不一致、意见分歧 |
| **井** | 井养、安稳通达 | 终局安稳，井井有条 |

**推理链路**

1. 用生体 → **大吉，外力相助**，此行有人帮、有便利
2. **但本卦为「需」** → 需者等待也，**出发前必有耽搁**（等票、等人、等审批、等天气）
3. 体坎为险、为陷 → 途中**有一点小波折**；但坎得乾金之生，险中有援
4. 互卦「睽」→ 过程有**小分歧**：可能是同行者意见不合、或行程临时变更
5. 变卦「井」→ 井养不穷、**终局安稳**，到达后一切顺遂
6. 乾为西北、为远行 → 目的地偏**远或偏西北**方向有利

**应期**：用生体为吉，看体卦坎水当令之时（冬月、子亥日）或生体的乾金当令（秋月、庚辛申酉日）。此占正处秋月，可断**近期（申酉日或庚辛日）可成行**。

**完整断语**

> 此行可去，用生体且得秋月金旺相生，外部条件配合，路上会有人帮。但本卦是「需」，需者等待——出发前一定有一段耽搁，别指望说走就走。体卦坎为险，途中会有小波折；互卦「睽」提示同行者可能有分歧、或行程要临时调整。好在变卦是「井」，井养安稳，到了之后一切就顺了，结果很好。若问方向，乾为西北，往西北走更利。

**转换要点**：出行占要**同时读三样**——体用生克（安全与助力）、卦名卦义（行程性质）、变卦（到达后的状态）。本例最妙的点是：**吉凶是吉的，但卦名说「等」**。生克管安危，卦名管体验，两者不矛盾。

### 示例五　婚姻占（问这段姻缘走向）

**设定**：取数 31、44，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 31 ÷ 8 = 3 余 **7** | 艮 ☶ |
| 下卦 | 44 ÷ 8 = 5 余 **4** | 震 ☳ |
| 动爻 | (31+44)=75，75 ÷ 6 = 12 余 **3** | 三爻动 |

**三卦**

- **本卦：山雷颐**（上艮下震）
- **互卦**：颐为初九阳、六二至六五皆阴、上九阳。二三四皆阴＝**坤**，三四五皆阴＝**坤** → **坤为地**
- **变卦**：三爻在下卦震的上爻，阴变阳 → 下卦变离 → 上艮下离＝**山火贲**

**体用与生克**：三爻动在下卦 → 下卦震为用，上卦艮为体。体艮土，用震木 → **木克土，用克体，凶**。

**旺衰**：秋月金旺、木囚，用卦震木无力，克土之力减弱 → **凶中有缓**。

**类象溯源**

| 取象 | 来源 | 婚姻占含义 |
|---|---|---|
| 艮＝少男、止 | 人伦＋卦德 | 男方（或己方）静止、保守、有顾虑 |
| 震＝长男、动 | 人伦＋卦德 | 对方主动、有变动、性情急躁 |
| 坤＝母、柔顺、包容 | 人伦＋卦德 | 长辈、需要包容、母亲因素 |
| 离＝中女、丽、文饰 | 人伦＋卦德 | 女方、外表、仪式 |
| **颐＝养** | 卦名卦义 | 需要培养、守正、不能急 |
| **贲＝文饰** | 卦名卦义 | 有仪式之美，但「饰」非「实」 |

**推理链路**

1. 用克体 → **有阻力，不宜强推**
2. 体艮＝止 → 己方（或这段关系本身）**停滞、卡住**
3. 用震＝动、为长男 → 对方有变动、或性格躁动，这是压力的来源
4. 但秋月木囚，震木无力 → **阻力在减弱**，不是死局
5. 本卦「颐」＝养 → **这段关系需要养**：先相处、先培养，不宜谈定论
6. 互卦坤＝柔顺、为母 → 中间环节有**长辈因素或需要包容忍让**
7. 变卦「贲」＝文饰 → 最终会走向**仪式化、表面和合**，但贲是「饰」，提示**别只看表面功夫**
8. 离为火、为丽、为中女 → 终局女方（或美感、形式）占主导

**完整断语**

> 这段姻缘眼下推不动。体艮为止、用震克体，压力在对方那边——可能是对方心思不定、或有现实变动牵扯。好在你占时值秋月木囚，克者无力，阻力正在衰退，不是死局。本卦「颐」是养的意思，这段关系现在最该做的是养，不是定：先相处、先积累，别急着要结果。中间（互卦坤）会有长辈介入、或需要一方多包容。变卦「贲」为文饰，最终会有仪式、有个好看的形式，但贲字本身是「装饰」——提醒你别被表面和气蒙住，实质问题还得谈。

**转换要点**：婚姻占最忌只看生克就下「成不成」的结论。**卦名卦义往往比生克更贴近真实体验**：此例生克说「凶」，卦名说「养」和「饰」，合起来是「有阻力但可成，只是要慢、要看实质」。

### 示例六　求名占（问这次求职/晋升）

**设定**：取数 12、20，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 12 ÷ 8 = 1 余 **4** | 震 ☳ |
| 下卦 | 20 ÷ 8 = 2 余 **4** | 震 ☳ |
| 动爻 | (12+20)=32，32 ÷ 6 = 5 余 **2** | 二爻动 |

**三卦**

- **本卦：震为雷**（上震下震）
- **互卦**：二三四＝六二阴、六三阴、九四阳 → **艮**；三四五＝六三阴、九四阳、六五阴 → **坎** → 上坎下艮＝**水山蹇**
- **变卦**：二爻在下卦震的中爻，阴变阳 → 下卦变兑 → 上震下兑＝**雷泽归妹**

**体用与生克**：二爻动在下卦 → 下卦震为用，上卦震为体。体震木，用震木 → **比和**。

**旺衰**：秋月木囚，体用皆囚 → 双方力量都不强，事态平淡。

**类象溯源**

| 取象 | 来源 | 求名占含义 |
|---|---|---|
| 震＝雷鸣 | 自然象 | **声名远播**、有名气、引人注意 |
| 震＝动、起动 | 卦德 | 有新起点、开始运转 |
| 震＝长男、将帅 | 人伦 | 男性贵人、主管、领导岗 |
| 坎＝隐伏、陷 | 卦德 | 过程被遮蔽、有暗阻 |
| 艮＝止 | 卦德 | 卡住、暂停审批 |
| **蹇＝蹇难** | 卦名 | 过程必有阻滞 |
| **归妹＝归于** | 卦名 | 有归宿，但《易》戒「守正」 |
| 兑＝口舌、讲说 | 卦形（上缺） | 面试、面谈、口头沟通 |

**推理链路**

1. 比和 → **事可成，但需借力**，不会自己掉下来
2. 体用皆震，震为雷鸣 → **名声之象很明确**，这个位置/机会确实能带来声名
3. 但秋月木囚 → 现在**时机未至**，雷在秋冬是「收声」的，声名未显
4. 互卦「蹇」→ 过程**必有阻滞**：可能是流程卡住、有竞争对手、或材料被压
5. 变卦「归妹」→ 最终**有归宿**（会得到结果），但归妹卦戒「守正」 → 得到之后要**稳住、守规矩**，不可得意忘形
6. 兑为口 → 关键环节是**面谈、沟通**，不是材料

**应期**：比和，看体卦震木当令之时：木旺于**春**（寅卯月/日）。秋月木囚不利，故应期推到**来春**；或取震数 4、8 → 四或八（周/月）。

**完整断语**

> 这个机会能拿到名声，震为雷鸣，是有声响的位置。但眼下不成——体用比和，比和的意思就是「得靠借力、靠主动」，不会自动来；又值秋月木囚，雷在秋天收声，时机未到。互卦是「蹇」，蹇难，中间一定卡：流程、审批、或半路杀出竞争者。变卦「归妹」，最终有归属，能成，但归妹卦最大的戒是「守正」——拿到之后别飘。关键在兑，兑为口，成败在面谈而不在简历。时间上看明年春天。

**转换要点**：求名占里，**震、离两卦最有「名声」意味**（震为雷鸣、离为火为明为显）。比和不等于成，比和＝**势均力敌、需主动**。这两者的区别是新手最容易搞混的地方。

### 示例七　行人占（问人何时回）

**设定**：取数 25、13，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 25 ÷ 8 = 3 余 **1** | 乾 ☰ |
| 下卦 | 13 ÷ 8 = 1 余 **5** | 巽 ☴ |
| 动爻 | (25+13)=38，38 ÷ 6 = 6 余 **2** | 二爻动 |

**三卦**

- **本卦：天风姤**（上乾下巽）—— 注意，与示例二同卦，但动爻在二爻，结果完全不同
- **互卦**：姤九二、九三、九四皆阳＝**乾**；九三、九四、九五皆阳＝**乾** → **乾为天**
- **变卦**：二爻在下卦巽的中爻，阳变阴 → 下卦变艮 → 上乾下艮＝**天山遁**

**体用与生克**：二爻动在下卦 → 下卦巽为用（行人），上卦乾为体（等候者/家）。体乾金，用巽木 → **金克木，体克用**。

**行人占的转换原理**

| 体用关系 | 行人占含义 |
|---|---|
| 用生体 | 人主动归来，速 |
| 体克用 | 人被困在外，**归期延迟**，需催促 |
| 用克体 | 人不愿归，或有事缠身 |
| 比和 | 归期平顺，按原计划 |

**推理链路**

1. 体克用 → **归期延迟**，人在外被事情拖住
2. 用卦巽＝入、为进退不果、为风（行踪不定）→ 行人在外**犹豫不决、行踪不定**
3. 本卦「姤」＝遇 → 他在外**有新的际遇/约会**，所以不急着回
4. 互卦乾为天、纯阳刚健 → 在外的事务**正处强势、正忙**
5. 变卦「遁」＝退、隐 → 归期**往后推**，且人有点「躲」的意思（可能不想被催）
6. 秋月金旺，体乾金当令克木 → 催促**有效**（体克用，主动方能推动）
7. 乾为西北、为远 → 人在**较远的西北方向**

**应期**：体克用，成期看**体卦当令之日**（乾金旺于秋、庚辛申酉日）；巽数 5、8，乾数 1、4、9。合参可断**申酉日或四、五日前后**，但需主动联系催。

**完整断语**

> 人一时半会儿回不来。体克用，人被困在外；用卦巽为进退不果、为风，他自己也拿不定主意、行踪飘忽。本卦「姤」是遇，他在外面有新的事、新的人，被绊住了。互卦纯乾，在外的事正在劲头上，忙。变卦「遁」，遁就是退、就是隐——归期要往后延，而且他有点躲催的意思。好消息是现在秋月金旺，体卦当令克用，你主动联系、明确催一下是管用的。方位看乾，偏西北、路途较远。

**转换要点**：**同一卦、不同动爻，结果天差地别**——示例二和示例七本卦都是天风姤，一个动在四爻（用克体，求财凶），一个动在二爻（体克用，行人迟归）。所以**动爻位置比本卦更重要**。

### 示例八　交易占（问这笔买卖谈不谈得成）

**设定**：取数 40、7，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 40 ÷ 8 = 5 余 **0** → **整除取 8** | 坤 ☷ |
| 下卦 | 7 ÷ 8 = 0 余 **7** | 艮 ☶ |
| 动爻 | (40+7)=47，47 ÷ 6 = 7 余 **5** | 五爻动 |

**三卦**

- **本卦：山地剥**（上坤下艮）
- **互卦**：二三四皆阴＝**坤**，三四五皆阴＝**坤** → **坤为地**
- **变卦**：五爻在上卦坤的中爻，阴变阳 → 上卦变坎 → 上坎下艮＝**水山蹇**

**体用与生克**：五爻动在上卦 → 上卦坤为用（对方/买方），下卦艮为体（我方/卖方）。体艮土，用坤土 → **比和**。

**推理链路**

1. 比和 → **双方势均力敌，交易基础成立**，能谈
2. **但本卦是「剥」** → 剥者，剥落也 → **价格会被一层层削掉**，利润要打折
3. 用卦坤＝柔顺、为众、为吝啬（《说卦》坤为吝啬）→ 对方**态度软但出手紧**，会反复压价
4. 体卦艮＝止 → 我方会**卡在某个底线上不让**
5. 互卦坤为地 → 中间**反复磨、拖时间**，没有爽快的转折
6. 变卦「蹇」→ 蹇难，最后**仍有阻碍**，可能卡在付款或条款
7. 艮土、坤土皆比和，秋月土相（土生金，土处「相」位）→ 双方都还有余力，谈得下去

**完整断语**

> 能成，但不好谈。体用比和，双方条件对等，不存在谈不拢的根本矛盾。问题在本卦「剥」——剥是剥落、削减，价格一定会被一层一层往下削。对方（坤）态度不硬，但坤为吝啬，出手很紧，会反复磨价。你这边艮为止，卡在自己的底线上不会松。互卦又是坤，中间就是拖、就是磨，没有干脆的转折。变卦「蹇」，最后还有一道坎，多半卡在付款方式或售后条款上。建议：开价留出被砍的余地，把条款写死，别只谈价格。

**转换要点**：交易占里，**比和＝能成交，但卦名告诉你「成交的质量」**。此例比和＋剥＋蹇＝「能成，但利润薄、过程累」。如果只看比和就报喜，你就漏掉了最重要的信息。

### 示例九　人事占（问这段合作关系）

**设定**：取数 18、33，占于秋月。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 18 ÷ 8 = 2 余 **2** | 兑 ☱ |
| 下卦 | 33 ÷ 8 = 4 余 **1** | 乾 ☰ |
| 动爻 | (18+33)=51，51 ÷ 6 = 8 余 **3** | 三爻动 |

**三卦**

- **本卦：泽天夬**（上兑下乾）
- **互卦**：夬为初九至九五皆阳、上六阴。二三四皆阳＝**乾**；三四五皆阳＝**乾** → **乾为天**
- **变卦**：三爻在下卦乾的上爻，阳变阴 → 下卦变兑 → 上兑下兑＝**兑为泽**

**体用与生克**：三爻动在下卦 → 下卦乾为用（对方），上卦兑为体（我方）。体兑金，用乾金 → **比和**。

**推理链路**

1. 比和 → **势均力敌，合作基础在**，谁也吃不掉谁
2. **本卦「夬」** → 夬者，决也 → **这段合作正站在一个「要决断」的关口**
3. 夬的结构是五阳决一阴 → 阳刚过盛，**需要有个了断**，拖着反而生变
4. 兑为悦、为口舌 → **关键在沟通**，事情是谈得开的
5. 互卦乾为天、纯刚 → 中间双方都**很强硬、互不相让**
6. 变卦兑为泽（两兑相叠）→ 《易》象「丽泽兑，君子以朋友讲习」 → **终局是和悦的**，谈开就好
7. 秋月金旺，体用皆金当令 → 双方力量都足，**但金过刚易折**，更需要柔化处理

**完整断语**

> 合作基础没问题，两金比和，势均力敌，谁也压不倒谁，这正是长期合作该有的样子。但本卦是「夬」——夬就是决断，这段关系现在正卡在一个必须拍板的关口上。夬的结构是五阳决一阴，阳太盛，意思是**该决断了，再拖就生变**。中间（互卦乾为天）你们双方都很硬，谁也不让，这就是卡住的真正原因。好在变卦是兑为泽，两泽相丽，《象传》说「君子以朋友讲习」——最后是能谈开、能和悦收场的。关键就在兑，兑为口、为言说：把话摊开讲，别硬碰硬。

**转换要点**：比和在合作里是**好事**（对等），但在需要决断时是**坏事**（僵持）。判断标准就是看卦名——卦名给「势」定性，生克给「力」定量。

### 示例十　求谋占（问这件事能不能办成）

**设定**：取数 5、24，占于秋月（金旺、木囚）。

**起卦**

| 步骤 | 算式 | 结果 |
|---|---|---|
| 上卦 | 5 ÷ 8 = 0 余 **5** | 巽 ☴ |
| 下卦 | 24 ÷ 8 = 3 余 **0** → **整除取 8** | 坤 ☷ |
| 动爻 | (5+24)=29，29 ÷ 6 = 4 余 **5** | 五爻动 |

**三卦**

- **本卦：风地观**（上巽下坤）
- **互卦**：观为初六至六四皆阴、九五阳、上九阳。二三四＝六二、六三、六四皆阴＝**坤**；三四五＝六三、六四阴、九五阳 → 阴阴阳＝**艮**。上艮下坤＝**山地剥**
- **变卦**：五爻在上卦巽的中爻，阳变阴 → 上卦巽（阴阳阳）中爻阳变阴 → 阴阴阴＝**坤**。上坤下坤＝**坤为地**

**体用与生克**：五爻动在上卦 → 上卦巽为用（所谋之事），下卦坤为体（我方）。体坤土，用巽木 → **木克土，用克体，凶**。

**旺衰**：秋月金旺、木囚，用卦巽木无力 → 克土之力大减，**凶中有缓**。

**推理链路**

1. 用克体 → **事情压人，办起来吃力**
2. 体坤＝顺、为承载 → 我方**能扛、有耐心**，但坤为迟缓，进度慢
3. 用巽＝入、为进退不果 → 这件事本身的性质就是**反复、不定、需要渗透**
4. 本卦「观」→ 观者，观仰、观望 → **眼下是观望期，不宜强行动手**
5. 互卦「剥」→ 中间会被**一层层削减**（条件被改、资源被削）
6. 变卦坤为地，与体同气（比和）→ **最终回到平稳**，能落地，但要退让
7. 秋月木囚，克者无力 → 阻力有限，**事能成，只是过程磨人**

**应期**：变卦坤与体比和，看体卦坤土当令之时（辰戌丑未月、或四季末）；坤数 8、5、10 → 八或十（日/周）。

**完整断语**

> 这件事能办成，但过程磨人。体坤土被用巽木所克，事压人，办起来吃力。好在你占时值秋月木囚，克者无力，阻力有限。体卦坤为顺、为承载，你自己有耐心扛得住，但坤主迟缓，进度不会快。用卦巽为入、为进退不果，这件事本身就反反复复，需要慢慢渗透。本卦是「观」，观望之意——现在不是动手的时机，先看。互卦「剥」，中间会被削：条件改动、资源缩水，要有心理准备。变卦坤为地，与体同气回到比和，最终能落地，但代价是让步。时间上看土旺的辰戌丑未月，或八、十日前后。

**转换要点**：求谋占看的是**「事与我的力量对比」**。用克体不等于办不成——要看克者是否有力（旺衰）。此例克者囚，就是「难但能成」。

## 第四部分　一卦三问：同一卦，不同问法

这是检验你是否真懂转换原理的最好测试。**下面三问用完全相同的卦**，看断语如何随「所问之事」改变。

### 设定

取数 6、29 → 上卦 6（坎）、下卦 29÷8 余 5（巽）→ 本卦**水风井**；6+29=35，35÷6 余 5 → 五爻动。

- **本卦：水风井**（上坎下巽）
- **互卦**：井为初六阴、九二阳、九三阳、六四阴、九五阳、上六阴。二三四＝九二阳、九三阳、六四阴 → 阳阳阴＝**兑**；三四五＝九三阳、六四阴、九五阳 → 阳阴阳＝**离**。上离下兑＝**火泽睽**
- **变卦**：五爻在上卦坎的中爻，阳变阴 → 上卦变坤 → 上坤下巽＝**地风升**
- **体用**：五爻动在上卦 → 上卦坎为用，下卦巽为体。体巽木，用坎水 → **水生木，用生体，吉**
- **旺衰**：秋月金旺木囚，体巽木囚 → 虽得生扶，自身仍弱

### 问一：求财

> 用生体，外力助我，财上有贵人。巽为商贾、为近利市三倍，体卦本身就有营商之象。坎为水、为流动之财、为暗中相助。互卦「睽」提示中间有个不一致（可能是账目或双方理解偏差），变卦「升」是上升——**财是往上走的，但来得慢**。秋月木囚，体弱，得生也有限。
>
> **断**：有利，但不是暴利，是稳步上升的财；注意中途一次账目或条款的核对。

### 问二：出行

> 用生体，路上有人帮、有便利。但本卦是「井」——井的特点是**不动、稳定、在原处**。出行占遇井，主**迟滞、走不远、或原地打转**。互卦「睽」为乖离，行程有变。变卦「升」是上升、往前行。
>
> **断**：能走成，但前期会拖（井主静），中途行程有变（睽），最终还是往前行（升）。建议把出发时间往后放，别赶。

### 问三：问健康（仅作技法演示）

> 体巽木，秋月木囚，体气偏弱。坎水为用生体，是有滋养之源。巽为股、为肱、为气、为肝胆；坎为耳、为血、为肾、为水。互卦见离火（水火相激）与兑（兑为口、为肺、为缺损）。变卦「升」，升是往上、往上逆。
>
> **断（仅演示取象链路）**：体气偏弱，注意肝气、筋骨与气血方面；互卦离火与坎水相激，提示心肾、水火不交之象；变卦升，宜防上逆之症。
>
> ⚠️ **这一问只用于说明「类象如何随所问之事切换」，不构成任何健康建议。任何身体不适请就医，梅花易数不替代诊疗。**

### 从这三次对比得到的原理

**卦是死的，问是活的。** 同一个「用生体」：

| 所问 | 落点 |
|---|---|
| 问财 | 财有贵人 |
| 问行 | 路有助力 |
| 问身 | 体有滋养 |

**变的不是生克，变的是「类象往哪个方向落」。** 所以断卦前第一件事必须是**把所问之事锁定清楚**——同一卦，问法不同，答案就不同。这也是为什么断语必须写成「问 A 则如何」，不能笼统说「吉」。

## 第五部分　断语组织与六个高频错误

### 断语五要素（缺一不算断完）

1. **方向** — 体用生克给出（吉/凶/平）
2. **程度** — 卦气旺衰修正（大吉/小吉/凶中有救）
3. **内容** — 类象填充（何人、何事、何物、何方）
4. **过程与结局** — 互卦看过程、变卦看结局
5. **时机** — 应期（何时）

### 应期的三种常见取法

| 取法 | 用法 |
|---|---|
| **卦数法** | 乾1兑2离3震4巽5坎6艮7坤8，单取或相加，按事之远近断日/月/年 |
| **旺衰法** | 吉卦断体卦当令之时（如体为震巽，应寅卯日/月）；凶卦待克用之期缓解 |
| **变卦法** | 以变卦卦数定最终应验之期 |

> ⚠️ 应期是梅花易数里公认最不统一的环节，各家取法不一。不要迷信任何单一说法，用你自己的核验记录去校准——哪套取法在你手上应验率高，就用哪套。

### 六个高频错误

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 只看生克不看卦名 | 比和就报喜，漏掉「剥」「蹇」的削减与阻滞 | 生克定**力**，卦名定**势**，两者都要读 |
| 整除取 0 | 8÷8 余 0 就取 0 | **整除取 8（坤）**；6 整除取 6（上爻动） |
| 体用定反 | 把静卦当用 | **动爻所在为用**，另一为体 |
| 外应喧宾夺主 | 听见一声响就推翻体用 | 外应只**微调**，不替代生克 |
| 忘了旺衰 | 判完生克就出结论 | 旺衰改**程度**，体衰被克要特别谨慎 |
| 事后附会 | 准的记住、不准的忘掉 | 断语**事前写定、到期核验**，用记录表校准 |

### 断语三原则

1. 写「倾向于」「需注意」，不写「必然」
2. 给方向不给宿命
3. 写完立刻记进断卦记录表，到期打勾

## 第六部分　三个月学习大纲

### 阶段划分

| 阶段 | 时间 | 目标 | 出口标准 |
|---|---|---|---|
| **一 筑基通识** | 第 1—2 周 | 象数底座与术语一次装完，起卦不出机械错误 | 默写先天八卦数、卦形、五行、干支全对；混合起卦 30 例 ≥ 90% |

| **五 验收巩固** | 第 13 周 | 用可观察结果验收，收成断案集 | 盲测 10 例应验 ≥ 5；讲卦录音 8 分钟；错题重做通过 |

### 模块优先级

| 排序 | 模块 | 结论 |

### 十二个核心卦

| 卦 | 核心意象 | 一句话要义 |
|---|---|---|
| 乾 | 六龙时位 | 从「潜龙勿用」到「亢龙有悔」，讲进取的分寸与警戒 |
| 坤 | 顺承载物 | 直方大、含章可贞，讲配合与守位 |
| 屯 | 初生艰难 | 事物初创，宜建侯而不宜躁进 |
| 蒙 | 启蒙 | 匪我求童蒙，童蒙求我——问学者主动 |
| 需 | 等待 | 需于郊、需于沙，讲「待时」 |
| 讼 | 争讼 | 讼不可成，中和为上 |
| 师 | 用众 | 师出以律，讲纪律与统帅 |
| 比 | 亲辅 | 亲比之道在择善而从 |
| 泰 | 通泰 | 天地交而万物通，上下交则志同 |
| 否 | 闭塞 | 天地不交，宜守不宜进 |
| 谦 | 谦虚 | 谦谦君子，卑以自牧；六爻皆吉 |
| 豫 | 悦乐 | 顺以动，讲行动的时机与人心和乐 |

### 十翼读法

- **《说卦传》**：梅花取象的直接源头，务必精读——它是你类象的「出处」
- **《系辞传》上下**：哲学总纲，「一阴一阳之谓道」「生生之谓易」「穷则变，变则通，通则久」
- **《彖传》**释卦辞、**《象传》**分大象（卦象）与小象（爻象）、**《文言》**专解乾坤
- **顺序建议**：先读若干卦再读传，否则容易空泛

## 第八部分　认知边界与考据

### 三条硬边界

1. **定位**：梅花易数是决策参考与思维训练工具，不是预测确定结论的依据。断语一律写成「倾向于」「需注意」，不写「必然」。
2. **不越界**：
   - 疾病类只做趋势描述，不下诊断、不替代就医
   - 官讼、投资、重大人事决策不作为唯一依据
   - 不替他人断生死、下吉凶定论
3. **防自欺**：术数最大的坑是「事后附会」——应验的记住、不验的忘掉。断语必须**事前写定、事后核验**，否则三个月后你根本不知道自己准不准。

### 一条影响选书的考据

《梅花易数》是元明间**托名邵雍**之作，不是邵雍亲撰：

- 《宋史·邵雍传》只录《皇极经世》《观物内外篇》《渔樵问对》《伊川击壤集》，朱熹遍研邵氏之学却从未提及此书
- 书中「乾三连、坤六断」等卦歌直接袭用朱熹《周易本义》（南宋淳熙年间成书），故成书不可能早于南宋中后期
- 五卷本体系到明代中后期才基本定型，清代续有增饰

**结论**：把它当**技法手册**读，不把它当邵雍哲学读。凡宣称「邵子神数」「秘传口诀」「改运秘法」的内容一律不采信。

### 三个最容易犯的错

1. 一上来通读 64 卦，第 3 周放弃——本期只读 12 个核心卦
2. 只看断语、不记录、不事后核验——学完永远不知道自己准不准
3. 把《梅花易数》当邵雍亲笔，被「神数」「秘传」类宣传带偏
